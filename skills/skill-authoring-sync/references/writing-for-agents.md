# 面向代理的文档写作

本文件维护“怎么写”这一层：`SKILL.md` 正文、`AGENTS.md`、以及任何通过指针按需加载的文档。目录、命名、README 索引与分发仍按 [skill-authoring-sync](../SKILL.md)；内容边界与语言风格按 [内容与语言规范](skill-content-guidelines.md)。两处冲突时以正文规范为准。

代理每次执行的是**过程**，不是固定输出。文档的作用是让这个过程稳定、可预测，而不是把模型当成只会照抄的脚本。

## 上下文指针

**指针**是常驻上下文的一行引用：它说明材料是什么，并列出应该去读它的**分支**。指针的措辞，而不是目标内容，决定代理能否在正确的时机找到材料。

- **前置主词**：把最能触发的那句话放在最前，不要先铺垫背景。
- **一个分支一个触发**：同义改写不增加分支，只会稀释每个词的权重；删掉重复。
- **删掉正文已经承载的身份说明**：指针不是摘要。
- 关键材料经常不命中时，先改指针措辞；措辞改不动再考虑内联，不要用更长的正文补偿弱指针。

## 两种负载

- **上下文负载**：每轮都占用窗口的内容，例如 `AGENTS.md` 的一行、skill 的 description。花的是 token 和注意力，无论是否命中。
- **认知负载**：人需要记住“有哪些文档、什么时候用哪份”。它不是越低越好，而是把人的判断力花在真正需要人的地方。

按需材料通过指针逃离常驻上下文，但指针本身仍常驻。判断标准不是“能不能下沉”，而是“这条分支是否每次都需要”。

## 信息层级

1. **文件内步骤**：代理按顺序执行的动作。
2. **文件内参考**：执行时按需查阅的规则、定义、事实。
3. **下沉参考**：放进 `references/`，由指针在特定分支触发加载。

三个操作：

- **渐进披露**：所有分支都要的材料放顶部；只有部分分支要的材料下沉。分支是最清晰的判断线。
- **同地放置**：一个概念的定义、规则、例外放在同一标题下，读一处能带出邻居；不要散落在全文。
- **控制篇幅**：长到注意力变薄时，用层级拆，不要靠删字硬压。按序列拆（后续步骤会诱导提前完成）或按调用拆（不同 harness 的入口差异）。

## 步骤与完成标准

每个步骤都要有**完成标准**，它有两个属性：

- **清晰**：代理能判断“做完了”还是“没做完”。模糊的边界（“理解达成”）会招来**提前完成**。
- **要求**：它要求多少工作量。“每个改动过的模型都已交代”比“给出改动清单”更能逼出实际检查。

最强的标准同时**可检查**和**穷尽**。边界模糊时先锐化；如果仍然模糊，并且确实观察到代理抢着结束，再用子代理或交接把后续步骤移出当前上下文。仅靠同一次调用里“别看后面”没有用，后面的步骤仍在窗口里。

## 主词

**主词**是一个模型预训练里已经存在的紧凑概念，用一个词承载一片行为，例如 _red_、_seam_、_tracer bullet_、_frontier_。做法是重复词，不是重复句子。

- 它在正文里锚定执行：同一个词出现时，代理容易回到同一套动作。
- 它在指针里锚定调用：用户的说法、文档、代码使用同一个词时，代理更容易把材料和任务连起来。
- 自造词要付定义成本；优先用已有词，再考虑造词。

**否定**是主词旁边的失败模式。写“不要 X”会把 X 拉进上下文，禁用它反而提高它的可用性。优先写正面目标（“写一行注释”），只有无法正面表达的硬护栏才用禁止，并同时给出正确动作。

## 修剪

- **单一真源**：一个意思只在一个地方维护。重复不仅增加维护成本，还会把该意思在层级里的权重抬高到超过它的真实地位。
- **环境也是真源**：`package.json`、`--help`、目录结构、配置本身就是可查事实。文档只写查不到的东西：未写下的约定、选择背后的理由、配置不会承认的坑。把一眼能查的东西抄进文档，等于缓存，迟早过期。
- **逐行看相关性**：这一行还影响哪个决策？如果没有，删掉。没有修剪纪律的默认结局是**沉积**：旧层不断落下，最后要钻透才能找到仍然有效的内容。
- **逐句找 no-op**：不改变模型默认行为的句子，整句删，不要只删几个词。判断是模型相对的：两个人争论某句是否 no-op，实际上是在争论默认行为，应该用实际运行来判定，而不是辩论。

## harness 调用差异

- 自动触发只依赖 `description`；正文里的“何时使用”不参与冷启动检索。
- **OpenCode**：`metadata.opencode/autoinvoke: "false"` 让技能不出现在自动选择里；`metadata.opencode/slash: "true"` 暴露为 `/name` 命令。
- **Claude Code**：`disable-model-invocation: true` 表示只允许人工触发。
- **Codex**：用 `agents/openai.yaml` 的 `policy.allow_implicit_invocation: false`。
- 跨 harness 的 skill 不写死某一家的字段；按 harness 追加元数据，正文保持通用。

## 写作复核

- [ ] 指针前置主词、覆盖真实分支，没有同义重复？
- [ ] 所有分支都需要的材料在文件内，只有部分分支需要的已下沉？
- [ ] 每个步骤都有可判定的完成标准，关键处的要求足够具体？
- [ ] 是否存在重复定义、缓存环境可查的信息、或整句 no-op？
- [ ] 是否用正面目标替代了不必要的禁止？
- [ ] 主动词与项目现有词汇一致，没有为文风制造新标签？
