## 文档模板

新建对应文件时裁剪并替换占位符，沿用项目现有结构，代码围栏语言随实际命令调整；无对应读者任务的章节删除，不留空占位。模板不扩大 [正文的条件式文档集合](../SKILL.md#先定规模再定集合)，也不默认创建文档站或改用某种版本方案。

### README

先按 [README 编写指南](readme-guide.md)核对要做、推荐做与不要做的事项。以下是程序仓库骨架；资料、模板或 skill 仓库按其真实使用方式替换快速开始，不硬套安装与运行。


### 配置参考表

| 变量 | 类型 | 默认值 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `<PREFIX>_DATABASE_URL` | URL | 无 | 是 | 连接串，含密码，不得提交到仓库 | `postgres://<user>:<password>@<host>:5432/<db>` |
| `<PREFIX>_LOG_LEVEL` | 枚举 | `info` | 否 | `debug`、`info`、`warn`、`error` 之一 | `debug` |

"必填"指不设置时程序拒绝启动；默认值必须与代码一致；说明列写副作用与安全注意事项，而不只是把名字展开成一句话。

### 命令行用法符号

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `[ ... ]` | 可选项 | `[-k <days>]` |
| `< ... >` | 占位符，需替换 | `<dest_dir>` |
| `...` | 可重复 | `<source_dir>...` |
| <code>a &#124; b</code> | 互斥，二选一 | <code>--json &#124; --yaml</code> |
| <code>{a &#124; b}</code> | 必选其一 | <code>{start &#124; stop &#124; status}</code> |
| 不加括号的字面量 | 原样输入 | `-o`、`backup` |
