# 文档模板

新建对应文件时复制并替换占位符；模板是最小骨架，不要求逐项填满。

## README

````markdown
# <项目名>

<一句话：做什么、解决什么问题、给谁用。>

## 特性

- <3~7 条，写清能力边界>
- <明确不支持什么>

## 快速开始

前置：<运行时最低版本、系统依赖、权限、端口>。

```bash
<可复制的安装与运行命令>
```

验证：<命令与预期输出>。

## 配置

<最关键的几项，完整清单链接到配置参考。>

## 文档

- 教程：<链接>
- 操作指南：<链接>
- 参考：<链接>
- 解释：<链接>

## 已知限制

- <当前不支持或未验证的场景>

## 贡献

<链接 CONTRIBUTING.md；安全问题链接 SECURITY.md。>

<许可证名称，链接 LICENSE。>
````

## 配置参考表

| 变量 | 类型 | 默认值 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `<PREFIX>_DATABASE_URL` | URL | 无 | 是 | 连接串，含密码，不得提交到仓库 | `postgres://<user>:<password>@<host>:5432/<db>` |
| `<PREFIX>_LOG_LEVEL` | 枚举 | `info` | 否 | `debug`、`info`、`warn`、`error` 之一 | `debug` |

"必填"指不设置时程序拒绝启动；默认值必须与代码一致；说明列写副作用与安全注意事项，而不只是把名字展开成一句话。

## 命令行用法符号

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `[ ... ]` | 可选项 | `[-k <days>]` |
| `< ... >` | 占位符，需替换 | `<dest_dir>` |
| `...` | 可重复 | `<source_dir>...` |
| `a \| b` | 互斥，二选一 | `--json \| --yaml` |
| `{a \| b}` | 必选其一 | `{start \| stop \| status}` |
| 不加括号的字面量 | 原样输入 | `-o`、`backup` |
