## 渲染与结果排障

仅在静态提取失败、内容不全或确需渲染时读取对应章节。正常提取路径见[主文件](../SKILL.md)，网络选路与状态码分流见 [network-access](../../network-access/SKILL.md)，参数取值以当前工具帮助为准。

## 渲染分工与前提

htmlmini 的静态抓取与正文提取是本职；浏览器由 `resilient-browser-fetch` 的 `save_page` 通路提供，同路线、同解释器传入。只有找不到该能力时才退到零依赖 Chrome `dump-dom`，它只渲染，不求解挑战或开窗。增强采集能力应改渲染提供方，不在提取工具里重建浏览器层。

- **触发条件**：静态200但正文依赖水合时用 `--render=always`；确认需要浏览器的静态403／5xx才用 `--render`，不是见状态码就渲染。`--headful` 只决定开窗，不改变何时触发渲染。
- **引擎与解释器**：自动阶梯优先已安装的挑战求解能力，纯渲染作为兜底。未指定解释器时会扫描更强环境；显式指定就尊重该选择，强环境失败时可回退默认环境一次。不要仅因默认Python缺依赖就认定无法抓取。
- **求解预算**：求解引擎需要至少60秒预算；更短预算只渲染不求解，显式点名求解引擎而预算不足会报错。工具会传递等待上限，检查日志以免半渲染快照被当完整结果。
- **浏览器品牌**：同出口仍可能因客户端品牌被拒。可按帮助切换浏览器；点名品牌是严格语义，未安装不静默换另一品牌。普通浏览器可开、自动化被拒时按[晚接入案例](usage-cases.md#13-自动化全被拦但普通浏览器能打开)处理。
- **接管现有会话**：CDP接管可复用现有浏览器的profile、Cookie与放行凭据，只读取已渲染页面，不关闭用户浏览器。目标页未打开时报错提示，不擅自导航或操作。

相关选项和可用引擎使用工具当前帮助／列表查询，不在参考里维护另一份枚举表。

## 按症状处理

| 症状 | 判断与动作 |
| --- | --- |
| 只剩区块标题／正文空 | 先判断客户端渲染；按[水合案例](usage-cases.md#4-静态-200正文要水合)渲染。仍为空再按[内嵌内容案例](usage-cases.md#5-输出只剩区块标题)核对JSON-LD与状态；提取结果不含脚本不等于原页无内容 |
| 动态下拉框或列表缺项 | 查实际渲染引擎、等待状态和目标选择器；若仍被静态层短路才钉渲染引擎。按[异步控件案例](usage-cases.md#16-动态块由异步数据填充下拉框与清单)等待或断言，快照后再本地提取 |
| 导出缺少控件选项或折叠结构 | 导航／页脚控件可能被正文引擎剔除；需要完整结构用 `html`，保留值、原生控件或details的参数查帮助。见[控件案例](usage-cases.md#17-导出后下拉框--单选选项全丢表单选项) |
| Windows参数含尖括号报错 | `.cmd`可能把尖括号当重定向，改不含尖括号的断言，或直接用Node调用 `src/cli.js` |
| `ui`清单截断／长正文丢失 | 查[界面预算案例](usage-cases.md#3-面板仪表盘设计稿)，换正文模式或本地按锚点切片，不重复抓URL |
| 确认挑战或403／5xx需渲染 | 按[挑战案例](usage-cases.md#6-静态-4035xx-或挑战特征)进入渲染通路；仍是挑战壳就换适用引擎，不反复切模式。需要用户登录态时可请其导出HTML，第三方读取需授权 |
| 渲染失败且解释器似乎不对 | 先查自动升档与回退日志，再用渲染提供方的环境检查入口定位可用解释器；全面资源盘点才读 [resource-inventory](../../resource-inventory/SKILL.md) |
| “There was an error processing your request.”等软错误壳 | 不当成短正文；按[晚接入案例](usage-cases.md#13-自动化全被拦但普通浏览器能打开)取完成挑战后的DOM |
| Access Denied／Forbidden／Error 1020 | 是明确拒绝而非正文少或挑战未跑完；按[拒绝页案例](usage-cases.md#15-waf-直接拒绝的商城页拒绝页不是正文出口才是变量)区分出口与客户端身份，不绕过限流 |
| “Unable to connect to the Internet”等站内错误态 | 应用接口未取到数据或仍在加载；查实际出口、跨域接口与渲染等待，不把错误态当正文 |
| 定价／计量与页面观感不符 | 按[营销与定价案例](usage-cases.md#2-营销--产品--定价页)核对JSON-LD、结构化字段或页面自身接口；CSS生成文字可能不可见于提取结果 |
| 后端供数页面只有展示值 | 按[接口侦查案例](usage-cases.md#11-后端接口--xhr-数据源)核对页面自身请求的JSON，不猜路径或整份逆向脚本 |

图表数字仍缺失时直接报告缺口，不凭截图估值或按首个脚本匹配填值。编写选择器与字段契约才定点回原始DOM核验，普通摘要不为形式重复读取原文。
