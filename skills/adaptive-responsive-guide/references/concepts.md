# 概念辨析与选型（先分清，再谈技术）

> 何时读：需求说“做个自适应”但讲不清要什么时。来源：opus `responsive-css-guide.md` 概念章 + `index.html:793` 六概念表。
> 原则：**先问连续还是离散，再选技术**。

## 六个概念（沟通时追问用）

| 术语 | 核心思想 | 典型技术 | 变化方式 |
|---|---|---|---|
| 响应式 RWD | 一套代码随视口连续变化 | 流式网格、弹性图片、媒体查询 | 连续+断点微调 |
| 自适应 AWD（严格） | 预设多套固定布局，检测后切换 | UA/Client Hints、多模板、m站 | 离散切换 |
| 流式布局 | 相对单位随容器伸缩 | `%`、`fr`、`max-width` | 连续 |
| 内在式 Intrinsic | 内容与布局算法决定尺寸，少用断点 | `auto-fit`、`flex-wrap`、`clamp()` | 连续且自动 |
| 组件驱动 | 组件按所在容器调整 | 容器查询、`cqi`、`:has()` | 随容器 |
| 等比缩放 | 以设计稿宽度为基准整体缩放 | rem+flexible、vw、rpx | 连续等比 |

- 中文“自适应”已被泛化：多数时候只是“适配各种屏幕”，不等于 AWD。必追问一句：**要连续流式，还是几套固定稿？**
- 国内“移动端适配”（rem/vw）本质是等比缩放：解决同类设备设计稿还原，到平板/PC会被整体放大，需限宽或结合响应式。
- 实际项目混合：响应式为主，局部用自适应手段（如按设备下发不同尺寸图片）。

## 演进一句话

2010 Marcotte 三要素（流式网格/弹性图片/媒体查询）→ 2017 Grid → 2018 Jen Simmons 内在式（流固并存、多级挤压、二维、嵌套、按需查询）→ 2021 Una Kravets 新维度（用户偏好、容器、折叠屏形态）→ 2023 容器查询+范围语法 Baseline → 2024 `light-dark()` → 2026 锚点定位 Baseline。

## 选型口诀（与 SKILL 步骤 2 联动）

- 整页骨架/导航/栏数 → 媒体查询；可复用组件内部 → 容器查询；能自动算的 → 内在布局；连续缩放 → `clamp()`；偏好/能力 → `prefers-*`/`hover`。
