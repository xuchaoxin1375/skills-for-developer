# Skill 卡（贴进 AGENTS.md / CLAUDE.md 或 brief 开头）

## 触发条件

任何 UI / 落地页 / 视觉设计生成与迭代，尤其是成品看起来“很 AI”时。

## 核心信念

1. 模型默认输出 = 最可能被接受的 token = 委员会式设计。
2. 好设计以感受为先，用出人意料的选择制造情绪；与 LLM 天性互为反题。
3. 随机与品味必须从模型外部带入；删除是人的活，模型不会主动做。

## 工作流（发散 → 定义 → 交付）

DISCOVER 先广再深
- 随机种子：`python3 scripts/generate-seed.py --count 4 --brief --product "产品名"`，解读→定方向，串本身不入库。
- 野心简报：跨行业灵感源 × 转换规则（灵感→版式/配色/交互各占哪部分）× “必须仍成立”护栏。
- 敢写“听起来行不通”的点子；失败弃稿但留 prompt 等新模型。

DEFINE 独一无二的个性
- 批评者回环：独立 agent 只看截图，对标顶级工作室，10 分制；标准与 prompt 每轮固定；停止线（如 9/10）设在外部，不写进批评者 prompt。
- 材质真实感：图像 + shader/3D；纯色循环视频抠底叠进 UI；关键帧插值做滚动转场，尾帧做下一段种子。

DELIVER 克制即高级
- 减法打磨：逐元素执行删除测试；原生控件优先；字号降一档、色彩减一层。
- 最终轮必须至少删掉一样东西；slop 命中 ≥3 条回发散重来。

## 硬规则

- 简报必须含具体灵感源 + 转换规则，禁形容词堆砌。
- 批评者只收截图，不收代码与历史；每轮先截图后评审；先跑 1–2 轮确认收敛。
- 种子、阈值、密钥绝不进设计与产物；密钥只放被忽略的 `.env.agents`。

## 红线（出现即扣分）

紫蓝渐变 / 三列等宽卡 / 左文右图+中央按钮 / 默认字体全家桶 / 玻璃拟态圆角卡 / 霓虹辉光 / 纯装饰元素 / 过度解释 / 全屏粒子星点 / 空口号。

## 品味来源

游戏 · 装置艺术 · 室内潮流 · 年代 · 材质。没有灵感库，先建一个。
