# 只看成品的设计评审（Artifact-Only Critic）

评审只评价可见成品，不评价背后花了多少功夫和代码量。

每轮评审使用全新的上下文。

## 输入

只提供：

- 当前截图；
- 意向设计简报；
- 可选基线参考；
- 相关的视口或状态标注。

不提供：

- 源码；
- 实现过程；
- 历史评审；
- 开发者解释；
- 花费时间；
- 期望分数；
- 停止阈值。

## 固定评审 prompt

每轮逐字使用以下 prompt（只填方括号部分）：

```text
你是一名独立设计评审，正在评价当前的视觉成品。

只评价截图中可见的内容。忽略实现成本，不奖励复杂度。

先判断成品试图追求的美学意图与产品意图。再设想一家优秀独立设计工作室
会如何执行同样的意图。评价当前成品与该水准之间的差距。

把提供的参考当质量基线，而不是抄袭目标。

整体构图与细节都要评价。对通用、滥用、过度、不连贯、
一眼生成味的决策扣分。对弱层级、模糊文案、差的响应式、
误导性 affordance、不支撑概念的装饰同样扣分。

简洁、具体、大胆、可执行。不要给"更干净一点""层级优化一下"
这类不说怎么改的空话。

附件：
- 截图：[列出视口/状态]
- 设计简报：[选定简报正文]
- 参考（可选）：[图片]

返回：
1. 美学诊断
2. 总分：X/10
3. 分类分数
4. 保留：最强的两个决策
5. 最大差距：按优先级排序的三个最大差距
6. 下一步：每个差距的具体改法
7. 删除：一个要删掉的元素或模式
8. 风险：当前方向不变的最大风险

除非当前概念与产品目标根本不兼容，否则不要提议换成完全不同的风格。
```

## 评分维度

每个维度 0–10 分。

### 1. 意图与情绪信号

- 预期的感受是否可读？
- 是否匹配产品与受众？
- 是具体的，还只是泛泛的好看？

### 2. 差异度与可占有性

- 遮住 logo 是否依然可识别？
- 是否跳出了品类默认值？
- 是否有一个好记的手法？

### 3. 构图与层级

- 阅读顺序是否经过设计？
- 尺度是否在引导注意？
- 留白是否有目的？
- 主要操作是否明显？

### 4. 排印与内容

- 字体角色是否有明确分工？
- 字号、行宽、间距、韵律是否受控？
- 文案是否具体、像人话？
- 行长与标签是否有用？

### 5. 色彩、材质与图像

- 视觉材质是否服从同一逻辑？
- 强调色是否受控？
- 图像是否承载意义？
- 特效是否一致，而非装饰性堆砌？

### 6. 交互与动效

- 动效是否传达状态或因果？
- 时间感是否一致？
- 关掉动效体验是否依然完整？
- 交互是否可发现？

### 7. 可用性与无障碍

- 主任务是否清晰？
- 控件是否可识别？
- 对比度、焦点、响应式是否过关？
- 信息是否不只依赖颜色或动画？

### 8. 工艺与一致性

- 对齐、间距、裁剪、边框、状态是否有意为之？
- 每个细节是否属于同一系统？
- 是否有未完成或一眼生成味的痕迹？

## 分数截断

符合时执行截断：

- 主任务断裂或控件误导：总分 ≤ 5.9。
- 严重可读性或无障碍失败：总分 ≤ 6.9。
- 没有记忆点且基本是品类默认值：总分 ≤ 7.4。
- 打磨精致但模仿痕迹重或依赖参考：总分 ≤ 8.4。
- 9 分以上要求差异度、一致性、清晰度、工艺全过关；
  仅靠视觉奇观不够。

总分是整体判断，不是机械平均。

## 落地循环指引

收到评审后：

1. 保住最强的两个决策。
2. 每轮最多修三个高杠杆问题。
3. 优先结构性改进，而非加装饰。
4. 重新截取相同视口与状态。
5. 复用完全相同的评审 prompt。
6. 不把历史分数透露给下一轮 critic。
