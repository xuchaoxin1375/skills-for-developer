# 真实素材工作流（图像/视频/密钥）

> 移植自 opus5.5 `media.md` 工程要点。原则：主视觉不得只靠渐变色块几何图形充场。

## 1. 哪里需要素材

英雄主视觉→产品渲染/场景摄影/概念插画；分区插图→风格统一插画组；背景质感→真实材质图克制叠加；动态焦点→抠像循环视频；页面过渡→关键帧插值随滚动擦洗。

图像提示构成：主体+材质+光线+构图（含留白给标题）+绑定方向令牌色彩+禁止项（无文字/logo/人物）+画幅与槽位一致。成组素材固定风格词、以首张为参考编辑，不逐张独立生成。

## 2. 视频两技法

* 循环+抠像：纯色背景生成→色度键/视频蒙版抠除→叠加界面任意处。玻璃折射先渲染在页面背景色上再抠；深色页静态发光物可用 `mix-blend-mode: screen` 以黑代抠。
* 关键帧过渡：两静帧间插值；上一段末帧做下一段首帧；随滚动擦洗。选物理与一致性强的模型，可经 fal.ai 类聚合平台选型。

## 3. 工程与降级

首屏给 poster 帧，`preload="metadata"`，视口外暂停；循环 `muted playsinline loop`，禁自动有声；尊重减少动效偏好显示静态帧；透明视频 Chrome/Firefox 用 WebM VP9 alpha、Safari 用 HEVC alpha，不支持回退图像序列/canvas 色度键；滚动擦洗推荐图像序列画到 canvas，直接设 `currentTime` 需极短关键帧间隔；单个循环建议 ≤2MB。

无密钥降级：有意图 SVG（须服务母题）/授权图库（统一调色）/着色器+真实纹理/排版即视觉。

## 4. 密钥与合规

单独建限额密钥；存入被忽略的 `.env.agents`，并在 `AGENTS.md` 留言仅开发用；禁入源码/提交/产物/前端包；在浏览器逐帧验证；登记素材清单（来源/模型/提示/许可/用途/尺寸）；避开真实人物商标版权角色。
