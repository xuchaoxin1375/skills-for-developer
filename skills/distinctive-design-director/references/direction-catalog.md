# 大胆方向目录与种子解读规则

> 移植自 opus5.5 `escape-the-mean` 的 `direction-catalog.md`，做法不变：种子给灵感，判断做修正，种子绝不外显。

## 1. 种子解读规则（与 `scripts/generate-seed.py --json` 一致）

字母表顺序 `A–Z(0–25)/a–z(26–51)/0–9(52–61)`：

| 维度 | 子模式 | 取值 |
|---|---|---|
| 主色相 | 全部字符编码之和 mod 360 | 0–359° |
| 配色关系 | 数字字符个数 mod 5 | 单色/互补/类似色/三分色/分裂互补（偏移 0/180/32/120/150） |
| 明度基调 | 大写个数 ≥ 小写个数 | 是→暗调，否则亮调 |
| 版式原型 | 首字符位序 mod 7 | 编辑大标题/不对称网格/中心海报/目录索引/便当网格/终端打印/横向色带 |
| 字体气质 | 末字符位序 mod 5 | 衬线展示/怪诞无衬线/等宽/窄体/圆体 |
| 圆角 | 元音数 mod 4 | 直角0/微圆4px/圆润12px/胶囊 |
| 密度 | 首个数字位置(1计) | ≤8紧凑；9–20均衡；>20或无数字疏朗 |
| 母题 | 第9–16位 FNV-1a mod 8 | 网格线/点阵/巨型数字/斜纹/正圆/票据齿孔/等高线/套准十字 |
| 文案语气 | 相邻字符类别切换数 mod 4 | 冷静克制/俏皮/宣言式/技术精确 |
| 强调剂量 | 数字之和 mod 3 | 点缀/适中/大胆色块 |
| 特殊模式 | 长≥3回文子串？否则数字和是否质数 | 镜像布局/竖排书脊/无 |

判断修正：

* 版式=终端打印 → 正文统一等宽。
* 终端打印+胶囊圆角 → 改直角。

配色生成（保证正文对比度 ≥4.5:1）：

| 角色 | 亮调 | 暗调 |
|---|---|---|
| 背景 | `oklch(0.975 0.012 H)` | `oklch(0.17 0.02 H)` |
| 次级面 | `oklch(0.935 0.022 H)` | `oklch(0.24 0.03 H)` |
| 正文 | `oklch(0.24 0.03 H)` | `oklch(0.95 0.015 H)` |
| 次要文字 | `oklch(0.46 0.03 H)` | `oklch(0.74 0.03 H)` |
| 主强调 | `oklch(0.52 0.15 H')` | `oklch(0.78 0.15 H')` |

`H'`由配色关系偏移得出。用脚本 `--json` 输出为准，手算只做抽查。

## 3. 碰撞法 A×B

抽两个不相关方向组合，写出“A结构+B材质”或“A数据形式+B色彩”两种映射，再用四类品味批注锐化。例：控制面板×标本馆=金属面板上的标本标签卡；时刻表×黑胶=A/B面即上下行。
