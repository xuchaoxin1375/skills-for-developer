# 创意算子

用这些算子逃离可预测的品类默认值。

随机性负责产生候选，判断力负责挑选候选。

不要在事实性任务或只有一个正确答案的任务上使用创意算子。
发散只适用于存在多个合理解的创意任务。

## 1. 外部种子

生成种子（从 skill 根目录运行）：

```bash
python3 scripts/generate-seed.py --count 4
```

每个方向：

1. 把字符串切成 5–8 段。
2. 先把每段指派给设计维度，再做解读：
   - 构图；
   - 排印；
   - 色彩；
   - 材质；
   - 图像；
   - 动效；
   - 疏密。
3. 从模式中推导约束：
   - 重复暗示韵律或模块化；
   - 剧变暗示对比；
   - 稀疏暗示留白；
   - 聚簇暗示分区、序列或焦点集中。
4. 让种子至少改变三个设计维度。
5. 用判断力丢掉不成立的结果。

种子是脚手架，不是用户可见的母题，更不是设计理由。

每个独立方向使用新种子。

## 2. 跨域碰撞

组合：

- 一条关于产品的真话；
- 一个视觉或物理领域；
- 一个不相关的组织领域；
- 一种交互行为。

公式：

> 产品真话 + 领域 A + 领域 B + 行为

示例：

> 金融历史被呈现为地质 strata，以博物馆编目的精度组织，
> 通过横向发掘逐步揭示。

只提取结构性原理，不要贴表面装饰。

弱碰撞：

> 把后台做成飞船风。

更强的碰撞：

> 把系统健康度当导航仪器处理：稳定信息固定在地平线上，
> 异常扭曲周围的场。

## 3. 约束反转

先列出品类默认值，再反转其中一到两条。

可反转示例：

- 密集后台 → 克制的编辑序列；
- 居中 hero → 偏轴构图；
- 常驻导航 → 情境导航；
- 卡片网格 → 连续场；
- 产品截图 → 用状态变化演示产品行为；
- 多强调色 → 一支受控的信号色；
- 装饰动画 → 只在状态切换处动。

不要同时反转所有惯例。要保留可识别的 affordance。

## 4. productive tension（ productive 张力）

给期望品质配一条边界：

- 奢华，但不堆砌；
- 活泼，但不幼稚；
- 技术感，但不吓人；
- 富有表现力，但不混乱；
- 极简，但不空；
- 怀旧，但不复古 cosplay；
- 电影感，但不拖沓；
- 信息密，但不杂乱。

好的方向同时化解张力两端，而不是二选一。

## 5. 反参考

定义设计绝不能变成什么。

用两到三个具体的反参考：

- 不是通用企业后台；
- 不是霓虹赛博机房；
- 不是软绵米色生活方式品牌；
- 不是一堆悬浮玻璃卡；
- 不是遮住产品任务的作品集概念稿。

反参考防止有潜力的方向塌回熟悉模板。

## 6. 材质转译

选一种物理材质或工艺，转译它的行为，而不只是贴纹理。

考虑：

- 折叠；
- 叠层；
- 磨损；
- 折射；
- 印刷；
- 压纹；
- 编织；
- 切割；
- 浇铸；
- 索引；
- 照明；
- 侵蚀。

追问：

- 材质如何揭示层级？
- 它随状态如何变化？
- 它暗示了何种重量、速度、精度或信任？
- 能否在不伤性能与可读性的前提下落地？

## 7. 叙事与状态隐喻

把产品状态表达为视觉系统中有意义的变化。

状态转化的例子：

- 组装与拆解；
- 聚焦与失焦；
- 压缩与扩张；
- 堆积与侵蚀；
- 对齐与漂移；
- 信号与噪声；
- 揭示层次；
- 从不确定到尘埃落定。

优先选择能解释产品行为的隐喻。

## 8. 尺度切换与裁剪

改变预期的观看距离：

- 极端微距细节；
- 建筑尺度；
- 碎片化裁剪；
- 微缩系统；
- 内容顶到边缘；
- 故意延续到屏外。

尺度切换可以在不加装饰的情况下制造性格。

## 9. 破例预算

故意打破一条大惯例，周围惯例保持稳定。

可打破的大惯例：

- 非常规阅读顺序；
- 极端不对称；
- 非常规导航位置；
- 超大排印；
- 受控的色彩不协和；
- 超大留白。

打破规则必须产生意义、层级或情绪效果。

不要为了显得有创意而打破惯例。

## 方向拒绝过滤器

出现以下情况直接拒绝该方向：

- 只是风格形容词；
- 只换了配色；
- 整个身份只靠渐变、辉光或 3D 物体撑着；
- 换给大多数竞品也能用；
- 与某参考贴得太近；
- 与产品行为或内容无关；
- 遮住了主要操作；
- 落地不可达或不可访问；
- 塞了多个互不相关的"hero"想法。
