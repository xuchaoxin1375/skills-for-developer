# 评审卫生 + 交付门

> 移植自 opus5.5 `define.md/deliver.md` 可量化部分。与 `critic-rubric.md` 配合使用。

## 1. 评审卫生（步骤5追加）

* 模型分工：大模型做评审（品味），能胜任的中型模型做实现；评审 token 占比小，不要让大模型重做设计。
* 标准优先排名式：`4张专业作品+1张我方截图随机排序，按精致品味排名`；次选“想象顶级工作室如何执行该美学再对标”。禁主观标准（好看吗/像AI吗）。
* 截图固定视口（至少宽+窄），等字体加载、动画停到约定帧再截；中性文件名如 `shot-a.png`，禁 `v5-final` 类泄漏上下文名；每轮 3 独立评审取中位数降方差；分数下降回退最高分版本。
* 结构化返回便于执行：`{"aesthetic":"","studio_vision":"","gaps":[{"area":"","issue":"","fix":"","severity":""}],"score":0}`。

## 2. 打磨量化基线

字体≤7档、正文≥16px、行高≥1.6；间距只用 4/8/12/16/24/32/48；圆角≤4档、阴影≤3级、不套娃；1主色+中性+语义，正文对比≥4.5:1；动效过渡≤320ms、只动 transform/opacity、跟随减少动效。

## 3. 状态/表单/危险操作

* 四态：加载≤100ms直接切、>2s给进度+计时+取消；空态说原因+下一步；错误说发生+恢复并保留成果；成功明确确认、可撤销给撤销。
* 表单：可见标签、两级校验（失焦+提交汇总）、首错聚焦、保留已填、允许粘贴、不以禁用按钮代校验、>7项分组分步。
* 危险操作远离首屏、二次确认、默认焦点取消、可撤销优先于确认。

## 4. 质量门 G1–G7（交付前全过）

G1独特性（与基线在结构/色彩/字体≥两项本质区别）/ G2评审中位≥9 / G3减法无未处理 / G4四态可恢复 / G5可访问（键盘/焦点/目标≥24触屏44/减少动效）/ G6三宽 390/768/1440 无页面横滚 / G7素材许可体积密钥。证据记入 `assets/design-record.md`。

## 5. 轻量预检 9 项（qwen 版，G 门之前先过）

发散：c1 灵感来自模型之外（种子/跨行业源）/ c2 简报写清转换规则 / c3 至少一个“听起来行不通”的方向。
定义：c4 批评者只看截图 / c5 标准具体可复现且每轮 prompt 不变 / c6 有真实材质（图像/3D/视频）。
交付：c7 逐元素删除测试 / c8 无辉光多余渐变重复标签、原生优先 / c9 slop 十条一条不中。

判定：9/9 可交付；≥5 边缘试探回对应阶段补齐；<5 回发散重掷种子。
