# 发现辅助：野心简报 + 灵感阶梯 + 失败库

> 移植自 opus5.5 `discover.md` 可复用部分。解决“方向很多但很平均、用户说不清品味”问题。

## 1. 野心简报公式

```text
[产品与页面] + [跨领域灵感源] + [映射方式] + [功能约束：它仍须作为 X 工作]
```

跨领域优先游戏/室内/装置/印刷/工业/交通标识/科学制图，不要堆形容词。例：

* 像素艺术主题，每个分区像游戏一帧截图，但仍是落地页。
* 等距活体3D城市，功能即街区/建筑。
* 激进不对称+不协和配色+不适负空间，但依然好看。

## 2. 灵感阶梯（广→锐→压缩）

1. 广而浅：`列出尽可能多的点子，每句一句话，只求广不求深。`
2. 品味批注（四句式，选定1个方向后必填）：
   * 我想象…（感官目标：触感/声音/节奏/场景）
   * 我原以为…但显…，避免…（划边界）
   * 取而代之…（替代路径）
   * …会很无聊，需要更多…（指缺口）
3. 压缩成 POC 提示：`写一段简洁提示，让实现代理据此建初始概念页。`

禁止把 AI 点子原样喂回 AI；必须经批注锐化，否则人人可得同样结果。

## 3. 默认基线（仅对照）

开工前跑一次朴素提示（如“为效率应用做落地页”）留截图，用于步骤6换品类测试与 G1 独特性对照，不作为方向。

## 4. 失败提示库

| 提示摘要 | 模型与日期 | 失败表现 | 重测计划 |
|---|---|---|---|
| | | | 下一代模型发布后重测 |

“听起来很糟、觉得绝对行不通”往往方向正确；真不行就扔掉换方向，但要记录。
