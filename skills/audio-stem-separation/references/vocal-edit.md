# 人声精剪：空白段、伴唱衬腔与时间轴

分离后的人声轨不只有主唱。先分清内容，再决定剪什么；静音裁剪只处理空白，不处理仍然有声的伴唱/衬腔段。

## 术语

| 说法 | 含义 | 典型处理 |
| --- | --- | --- |
| 主唱 / lead vocal | 承担歌词主线的人声 | 保留 |
| 伴唱 / 背景人声 / backing vocals | 衬托主唱的其他人声层，常以和声、呼应或衬词出现 | 按目标决定 |
| 人声衬词/衬腔 / vocalise / vocable | 用“啊、哦、呜”等无词发音填充空隙、铺氛围 | 主唱缺席时通常剪掉 |
| 和声 / harmony | 同时发声的音高关系（三度、五度等） | 不等于伴唱；先确认 |

中文口语里的“和声”常被用来指伴唱或衬腔。用户说“和声不好”时，先确认指的是“伴唱/衬腔层”还是“和声音程/叠唱”，不要按字面直接剪。

## 主唱缺席的衬腔段：默认剪掉

在纯人声精剪里，主唱不唱、只剩伴唱或衬腔的段落通常显得空、散，不是保留目标；默认作为候选剪掉。用户明确要保留氛围层时再保留。

- 先看这一段有没有歌词主线（主唱）。
- 主唱缺席、只剩长音、无词发音或应答式短句，标为“衬腔候选”。
- 主唱在场时不要整段剪；需要去伴唱时走分层处理，不靠静音阈值。

## 识别：宽声场不等于伴唱

| 观察 | 主唱段 | 只剩伴唱/衬腔 |
| --- | --- | --- |
| 每秒 L/R 相关度 | 通常 > 0.8 | 常在 0–0.5 |
| mid 与 side 能量 | mid 明显大于 side | mid 与 side 接近 |
| 频谱 | 高频与辅音较完整 | 可能发闷、带通，或只有长音/气声 |
| 位置 | 歌词主线连续 | 常在前奏、间奏、主唱换气处 |

低相关只说明宽声场/去相关，可能是伴唱、衬腔、双轨主唱或立体声效果；要结合段落位置、频谱和试听确认。不要把测量结果写成“已试听”。

```bash
python scripts/scan_vocal_layers.py vocals.flac
python scripts/scan_vocal_layers.py vocals.flac --min-duration 2 --threshold-corr 0.4
```

输出按时间排列的低相关段，带平均相关度、side/mid 与 mid 电平。它只给候选；边界要前后多看 0.5–1 秒，避免切掉主唱尾音或下一句起音。

## 编辑方式

| 情况 | 做法 | 代价 |
| --- | --- | --- |
| 主唱缺席，整段是伴唱/衬腔 | 整段剪掉，前后接主唱段 | 时间轴改变；接缝要试听 |
| 主唱在场，只想压伴唱 | 用主唱/伴唱分离模型，或中置提取 | 需额外模型/试听；中置提取只能部分压低宽声场伴唱 |
| 不确定是否主唱 | 先出候选段表让用户确认，不先编码 | 多一轮沟通，避免误剪 |

主唱/伴唱分离模型按当前可用工具核对，不在本文件写死模型名；先用 10–20 秒片段对照，再决定是否全曲处理。

## 先出候选段表

主观听感（“这段听着不好”）不要直接出成品。先给候选段表，确认后再编码：

| 源时间 | 当前成品时间 | 时长 | 判断 | 建议 |
| --- | --- | --- | --- | --- |
| 2:06.5–2:21.5 | 1:24.3–1:39.4 | 15.0s | 宽声场伴唱/衬腔，主唱缺席 | 剪掉 |

同时给源时间和当前成品时间；用户报时间点时，先确认基于哪个文件。成品文件名带版本，避免覆盖上一版。

## 交付：cut map

成品交付附源时间↔成品时间对应，不只报成品时长：

| 源区间 | 成品区间 | 动作 | 原因 |
| --- | --- | --- | --- |
| 0:00–0:41.8 | — | 剪掉 | 前奏，无主唱 |
| 2:06.5–2:21.5 | — | 剪掉 | 伴唱/衬腔，主唱缺席 |
| 2:21.5–3:28.1 | 1:24.9–2:31.4 | 保留 | 主唱段 |

时间点用 `m:ss.s`，源与成品分列；剪掉的行成品区间留空，避免把两个时间轴混在一列。

## 拼接与验收

- 每个剪点做 10–30ms 淡变，剪点落在静音或低电平处，不切主唱起音。
- 从最高质量源剪一次再编码；不要 MP3→MP3 反复转码。
- 验收：时长等于保留段总长（误差 ≤0.1s）；峰值无削波；剪点局部 sample delta 无异常尖峰；至少抽查开头、每个剪点、结尾。
- 未试听时只报告测量结果（相关度、时长、峰值、静音段），不写“听感已验证”。
