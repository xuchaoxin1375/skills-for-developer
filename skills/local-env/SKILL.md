# Local Env（国内出网与下载偏好）

> 定位：国内用户典型的推荐流程和环境配置偏好，附本机实测实例。
> 仅供参考，不保证与实际用户环境完全一致；遇到不一致或需要调整，以实际情况为准，并回写本文件。

## 推荐流程（回退顺序）

1. **镜像优先**：pip/uv 先走国内镜像（本机：USTC）。最快且不依赖代理。
2. **代理次之**：镜像缺包、滞后或不可用时，走本地代理出官方源
   （本机：mihomo 在 `http://localhost:10808`，`HTTP_PROXY`/`HTTPS_PROXY` 全局已设）。
3. **裸连兜底**：最后尝试直连。直连成功说明问题在镜像/代理，直连也失败则是网络本身问题；
   裸连主要起诊断作用，生产环境不长期依赖它。

每步都要实测（端口通、能取包）再往下走，并记下哪一步通了；
单次任务优先用环境变量覆盖（如 `PIP_INDEX_URL`、`UV_DEFAULT_INDEX`），不动全局配置。

## 本机事实（2026-10-09 实测）

- 代理 TCP 通，经代理取 `https://pypi.org/simple/` 返回 200。
- pip 已配 USTC（`%APPDATA%\pip\pip.ini`）。
- uv 尚无用户级镜像配置，靠代理直连官方源；`uv run` 加 `--python 3.13`
  （本机 Python 3.13；子仓 `.python-version` 的 3.12 只是本地 pin，不是硬性要求）。
- 联网搜索：已授权，时效敏感问题直接用。
