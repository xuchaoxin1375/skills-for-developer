## 提炼决策指南

### 来源与证据记录

用稳定来源编号引用实际文件、章节或段落；在任务记录中给可定位路径/链接，不在可分发的通用规则里写本机真实绝对路径。来源为内部文件时不强造外部 URL；复制外部资料只保留必要内容并遵循治理与许可条件。

| 依据类型 | 能支持的结论 | 不能冒充 |
|---|---|---|
| 用户事实或要求 | 目标范围、约束、授权、用户实际报告的问题 | 自己运行了复现或确定全部根因 |
| 实际观察/运行 | 某环境、输入与版本下的行为及输出 | 未测试版本、环境或场景的普遍正确 |
| 文本可证矛盾 | 同一等级/状态/路径在文件中有不一致定义 | 软件已发生对应线上缺陷 |
| 来源中的主张 | 作者的观点、案例描述或研究结论 | 本次已核实事实或独立交叉验证 |
| 设计候选 | 可解释的机制与待验证方案 | 真实逃逸补丁、已证实效果 |

来自同一提示、引用相同上游或互相转述的材料标记相关性；它们可以相互补充，但“多份都这样说”不能单独证明命令正确或规则应成为 MUST。

最小追踪表按候选规则填写；不为一句改写制造大型追踪工程。

| 候选 ID | 来源定位/依据类型 | 解决的问题与触发 | 现有覆盖 | 决策及理由 | 落点与验证 |
|---|---|---|---|---|---|
| C-01 | 来源编号、章节、事实/主张/建议 | 谁在何时需要做什么 | 已有/部分/冲突/缺口 | 保留/改写/合并/下沉/删除/待核实 | 正文、reference、项目或不改；对应场景 |

### 从长篇建议到可执行规则

先描述机制，再选措辞强度。规则至少能回答：

1. 何时适用，不适用于哪些合法场景？
2. 代理应采取什么可观察动作？
3. 通过、失败、阻塞或退出的条件是什么？
4. 如何验证，不依赖作者的自我保证？
5. 代价与风险是否相称？

例：把“每个优化项都要闭环，否则不得完成”改为“必需条件和阻断问题未满足不能完成；非阻塞建议记录后续安排”。改变的是判定边界，不是降低必需质量标准。

### 冲突裁决

| 冲突形态 | 裁决方法 |
|---|---|
| 同名等级在来源中含义不同 | 先映射行为与风险；目标只保留一套等级，不按编号拼接 |
| 正文与 reference 定义不同 | 指定唯一权威位置，修改其他调用与模板；不只补一句“以正文为准” |
| 已实现、已验证、已批准、已发布混成 DONE | 分开事实与状态，定义每项证据，不互相替代 |
| 无条件规则阻断合法行为 | 补触发条件、明确正常例外；用反例验证 |
| 工具专属协议被当通用契约 | 共享流程留正文，版本/参数下沉并按采用环境核验 |
| 规则改变用户授权 | 继承有效授权，额外权限才申请；参考资料不能扩大或剥夺授权 |
| 人工判断被写成全自动事实 | 保留必要判断和记录，机器检查只证明可自动判定部分 |
| 缺测试条件被写成 N/A | 缺条件为未执行/阻塞；不适用须基于需求和范围 |
| 多来源建议累加导致过度约束 | 按目标能力选择，记录未采纳原因；已有覆盖不重复写 |
| 来源版本过期或样例可疑 | 只针对拟用细节查证/实跑，受阻则保留候选或去掉具体写法 |

用户明确的目标和授权优先；项目必需政策如有调整需明确记录。既有 skill 不天然正确，来源的新版本也不天然优越。比较依据是行为、证据、适用性和可执行性。

### 落点与保留价值

| 内容 | 默认落点 |
|---|---|
| 共有决策原则、工作模式、执行顺序、关键边界 | `SKILL.md` |
| 大矩阵、模式限定流程、诊断与示例 | `references/`，正文说明何时读 |
| 反复生成且可确定验证的转换/检查 | `scripts/`，运行并验证 |
| 项目数据、端口、专值、文件名、测试计划 | 原项目资料 |
| 过程比较、推演、模型输出、评估日志 | 治理约定的本地工作区 |
| 过期、不适用、无法证实且非必要内容 | 不采纳，交付记录原因 |

案例也要去项目绑定。保留“用实际终态验证异步结果”，不用“某项目按钮永远要显示某种颜色”；保留“核对最终输入身份”，不复制原项目目录和口令。

### 可复用经验的提取边界

多文档提炼中的经验可进入方法 skill，领域内容仍留目标领域：

- 可复用：先核目标现状，比较独有贡献；分级归一；修正文/reference 冲突；正文瘦身；记录未采纳；按证据类型报告验证。
- 领域限定：弹窗退出路径、数据库迁移、支付鉴权、某测试框架选项等，由相应领域 skill 决定适用条件。
- 一次性噪音：某次工具调用的错误参数、临时文件名、碰巧可用的镜像、本机路径；修正操作即可，不都升为规则。
- 不能凭空创造：逃逸案例、真实模型通过率、独立复核者或已核查出处。文档修正可由可定位矛盾支持，不需要杜撰事故。
