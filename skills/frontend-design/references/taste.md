# 灵感转译与审美判断（设计感）

> 何时读：Step 2 画线框之前、Step 3 定 token 之前。管创意决策，不管开发流程；不替代可用性底线（`a11y.md`、`anti-patterns.md` 的 MUST 依然优先）。

**目标：建立适合产品、鲜明且自洽的视觉主张，而不是给通用模板换皮。**

1. **先定感受，再定样式**：明确希望用户感受到什么、不要感受到什么。用具体意象代替"高级、现代、简洁"这类模糊要求。
2. **借鉴原理，不复制表象**：从建筑、出版物、游戏等领域提取构图、材质、节奏与交互隐喻，转译成界面规则。"杂志感"要落实为标题尺度、分栏关系与阅读节奏，而非只换字体。
3. **探索真正不同的方向**：拉开差异的才算方向——信息组织、空间构图或交互方式三者至少其一不同；仅换配色不算新方向。
4. **围绕一个主张做深**：选定方向后只建**一处**核心记忆点，让排版、图像与动效共同强化它；同一页不许有两个记忆点打架，也不把多个好点子平均堆进一页。
5. **以视觉结果检验判断**：用实际截图对照高质量参考，让独立评审指出最关键的差距；先修构图与层级，再雕细节。参考只校准品质，不照搬。
6. **用减法完成设计**：删除不服务内容、操作或视觉主张的元素。渐变、卡片、装饰**并非禁用项**，但不能是未经思考的默认答案——每个装饰都要能说出它服务哪一个主张。

**设计前明确链**（写进线框顶部或 `DESIGN.md`，一句话版本即可）：

`情绪目标 → 灵感转译 → 候选方向 → 核心主张 → 记忆点 → 不做什么`

**两档执行**（本 skill 默认服务小工具，不过度设计）：

- 小工具/后台页（默认）：主张一句话 + 记忆点一处 + 减法过一遍，不走三方向。
- 落地页/改版/视觉主张缺失：走全套——三个候选方向 + 截图对标 + 减法。

**底线**：在品牌约束内探索；表达可以冒险，**可读性与可用性不能让步**。主张必须落进 token（字体/色彩/圆角/阴影/图标），不落 token 的主张等于空话；与品牌 token 冲突时以品牌约束为准。
