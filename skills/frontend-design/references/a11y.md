# 无障碍基线（默认WCAG 2.2 AA，不构成法律意见）

## WCAG 2.2新增九条（2023-10-05 W3C推荐标准，4.1.1已移除）

| 编号 | 级别 | 要求 |
|---|---|---|
| 2.4.11 焦点不被遮挡（最低） | AA | 获焦元素至少部分可见，不得被粘性头/横幅/弹窗完全盖住 |
| 2.4.12 焦点不被遮挡（增强） | AAA | 完全可见（推荐） |
| 2.4.13 焦点外观 | AAA | 焦点环面积不小于2px周长圈，且与未聚焦态对比3:1；按AA执行，成本极低 |
| 2.5.7 拖拽操作 | AA | 每次拖拽都要有单指针替代（上移/下移按钮、可点滑块、键盘） |
| 2.5.8 目标尺寸（最低） | AA | ≥24×24 CSS像素，或24px圆互不交叠；句中链接/浏览器控件等例外 |
| 3.2.6 一致的帮助 | A | 帮助入口在每页保持相同相对顺序 |
| 3.3.7 冗余输入 | A | 同一流程的信息自动回填或可选，不让用户输两遍 |
| 3.3.8 可访问认证（最低） | AA | 登录不考记忆/解谜；允许密码管理器与粘贴，提供替代方式 |
| 3.3.9 可访问认证（增强） | AAA | 更严格（推荐） |

桌面密集界面24px保底，触屏界面44px（Apple 44pt / Material 48dp同量级）。

## AI最易违反的旧条款

文字4.5:1，大文字3:1（大文字=18pt约24px，或14pt粗体约18.5px）。非文字组件与焦点环3:1。不得只靠颜色传意（1.4.1）。文本间距可调时内容不丢失（1.4.12，容器用`min-height`不用`height`）。视觉结构要有语义对应（1.3.1）。全部功能键盘可达（2.1.1）。焦点可见，用`:focus-visible`（2.4.7）。纯图标按钮必须有`aria-label`（4.1.2）。图片必须有`alt`，装饰图`alt=""`（1.1.1）。320 CSS像素宽下重排、无横向滚动（1.4.10，竖滚320/横滚256）。禁止`user-scalable=no`。

## APG与焦点管理

自定义对话框/菜单/标签页/组合框/树按WAI-ARIA APG键盘模式实现。能用原生就不用ARIA（无ARIA胜过错ARIA）。对话框：焦点移入内部（优先落“取消”防误触）、Tab陷阱、Esc关闭、**关闭后焦点回到原触发按钮**。分组控件用`:focus-within`。

## 中文额外要求

`lang="zh-CN"`。长英文/URL用`overflow-wrap: anywhere`换行，段落`word-break: normal`。中文没有斜体（`em`映射为加粗或变色）。禁用`text-align: justify`处理中西混排。`text-autospace`/`text-spacing-trim`只作渐进增强（仅Chrome 123+支持，Firefox/Safari不支持）。政府/金融/教育项目另查GB/T 37668-2019。
