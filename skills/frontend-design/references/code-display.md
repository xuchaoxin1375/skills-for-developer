## 页面内的代码/配置片段：高亮、行号与复制

> 何时读：页面需要展示源码、配置、命令或 JSON 片段，或要评审现成代码块（高亮错、行号错位、复制带行号、长行撑破页面、深色模式看不清）。只写 Markdown 文档里的围栏代码块转 `markdown-style`；需要**编辑**代码时按编辑器选型，不是本节的只读展示。

### 先定形态

按运行环境与交互需求选形态，不为只读展示引入编辑器。

| 需求 | 做法 | 不选的理由 |
| --- | --- | --- |
| 只读展示，静态页/无构建 | 本地引入 Prism，按语言增量加载；必要时用 `Prism.highlight()` 自行分行 | Shiki 需打包语法与 WASM，无构建项目成本过高 |
| 有构建/SSR，片段稳定 | 构建期用 Shiki 生成高亮 HTML 或内联 token 样式 | 运行时高亮把语法与主题成本转给每个访问者 |
| 需要编辑、折叠、搜索、大文件 | CodeMirror 6（读屏与键盘支持完整）；Monaco 只在需要 IDE 能力时 | 只读展示用编辑器是过度设计，体积与无障碍成本更高 |
| 语言少、体积敏感 | Prism 仅装用到的语言；不用全量 highlight.js | highlight.js 自动识别易误判，包体随语言数增长 |

**MUST：用成熟库，不手写正则高亮。** 手写规则在嵌套标签、模板字符串、注释与转义上很快出错，且难以维护。

### 依赖与安全

- **本地 vendor，不在运行时拉 CDN。** 断网、内网与 CSP `script-src 'self'` 下都要能用；记录版本、来源、许可证和升级入口，保留 `LICENSE`。
- 选 `data-manual` 一类手动模式，避免库在页面加载时扫描并重写全部 `<code>`。
- 高亮输出必须转义源码；不要把用户片段直接 `innerHTML`。用库的 `highlight()` 或自行 `textContent` 构造行。
- 片段可能来自外部时，按不可信数据处理；预览与高亮是两件事，安全预览另有沙箱要求。

### 行号：逻辑行，不是视觉行

先决定是否允许换行，再选行号结构；行号必须绑定逻辑行。

| 方案 | 适用 | 关键点 |
| --- | --- | --- |
| 不换行 + 左侧 sticky 行号槽 | 默认推荐；代码为主、可横向滚动 | 每个逻辑行恰好一个视觉行，行号天然对齐；`position: sticky; left: 0` 需在滚动容器内实测 |
| 每逻辑行一个 grid 行（行号列 + 代码列） | 需要自动换行 | 换行仍归属同一行号；单元高度随内容增长，行号贴该行顶部 |
| 独立行号列 + `pre-wrap` 代码 | **禁止** | 代码换行后行号与内容错位；这是最常见的“看起来能用、长行就废” |

- 行号从 1 开始，空行也占号；末尾换行产生最后一行空行，按与代码一致的口径计数。
- 行号是装饰：`aria-hidden="true"`、`user-select: none`；**复制只复制源码字符串**，绝不读 `innerText`（会把行号一起带走）。
- `tab-size` 显式设为 2 或 4；代码内缩进用 `white-space: pre`/`pre-wrap`，不要依赖 HTML 空白折叠。
- 统计与展示口径统一：行数 = 换行数 + 1；在工具栏显示“N 行”和语言，未知语言不猜标签。

### 长行与滚动

- 默认横向滚动优先于强制换行；代码缩进和层级靠横向空间表达。
- 滚动容器必须可聚焦：`tabindex="0"` + `role="region"` + 可读名称，键盘方向键可滚；只靠鼠标或 Shift+滚轮不算可用。
- 提供“自动换行”开关时，开启后不得产生页面级横向滚动，也不得让行号错位（用上面的 grid 行方案）。
- 页面本身永远不出现横向滚动；横向滚动只发生在代码容器内。
- 触屏上保留完整代码，不靠缩小字号解决宽度；代码字号不低于 12px。

### 配色与主题

- **不直接套库的官方主题。** 把 token 类型映射到项目语义色，Light/Dark 分别定义；色值进令牌，组件只用语义层。
- 对比度按代码**实际底色**测，正文与每个 token 色 ≥ 4.5:1；深色模式单独测，不能由浅色数值推断。
- 色相数量克制（一般 ≤6 类：标签、属性、字符串、数字、关键字、注释），注释可弱化但仍需可读；不要给标点也上高饱和色。
- 行号槽用下沉面、代码区用抬升面，两者边界用 1px 线即可，不加大面积底色。

### 类名冲突：第三方 token 必须作用域化

Prism 等库输出的 token 类名是通用词（`tag`、`string`、`number`、`comment`、`selector`），极易与项目组件类撞名。

- **MUST：** 高亮样式限定在代码容器内，如 `.source-view .token.tag`；不要写全局 `.token.tag`，更不要为了好看给 `.tag` 之类的通用类加全局样式。
- 接入后检查已有同名类：`.tag` 若同时是徽章，Prism 的标签 token 会继承徽章的高度、内边距、`inline-flex` 与 `nowrap`，表现为“高亮字形正常但长行不换行”。
- 需要时给 `.token` 补 `white-space: inherit`，防止未来的全局规则再次污染代码行。

### 性能与降级

- 同步高亮会阻塞主线程；字符数、行数、语言复杂度都影响耗时。设一个项目阈值，超过后**关闭高亮但保留行号与复制**，并在界面上说明“片段较大，已关闭语法高亮”。
- 切换视图后再高亮：先让面板与“正在生成…”状态绘制出来，再用 `setTimeout(0)`/下一帧执行，避免点击后整页无反馈。
- 不为隐藏内容预先高亮；关闭弹窗/切换视图时释放大段 DOM 与源码字符串。
- 阈值按实测定，不照抄别的项目数字；记录测得的字符数、行数与耗时。

### 交互与反馈

- 工具栏顺序：语言/行数 → 换行开关 → 复制；主操作只有一个“复制”。
- 复制成功在按钮上就地反馈（图标/文案 1–2 秒）并保留 toast；不要只弹 toast。
- 文本可选中、可复制部分内容；行号不可选；复制按钮复制完整源码而不是可见区域。
- 代码区展开/收起、切换视图不改变焦点位置；关闭浮层后焦点回到触发按钮。
- 代码块内不放大段说明文字；解释放在代码外，避免复制时混入。

### 验收清单

- [ ] 复制内容与源码一致：不含行号、提示或省略号；换行按平台剪贴板约定。
- [ ] 行数 = 换行数 + 1，空行与末尾换行口径一致。
- [ ] 长行下横向滚动只发生在代码容器；开启换行后无页面级横向滚动，行号仍逐行对齐。
- [ ] 横向滚动容器可用键盘聚焦并滚动；行号不进读屏。
- [ ] Light/Dark 下每个 token 色对代码底 ≥ 4.5:1；未直接套用官方主题。
- [ ] 高亮样式全部作用域化，未命中项目已有的 `.tag`/`.string` 等通用类。
- [ ] 超过阈值时降级为无高亮并明示；切换视图无长时间白屏。
- [ ] 320/390px 下代码区可用，工具栏不溢出、按钮触控目标 ≥44px。
- [ ] 示例片段真实可运行，文件/语言标注正确。
