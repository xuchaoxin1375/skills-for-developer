# 渐进式披露：首屏、折叠与高级

> 何时读：Step 1 分档、Step 2 线框时。核心思想：**用户一次只做一件事，就一次只给他看相关的东西。**

## 三层

| 层 | 放什么 | 位置 |
| --- | --- | --- |
| L1 首屏 | 核心任务 + 主操作（≤3 个）+ 当前状态 | 一眼可见，无需滚动即达 |
| L2 次要 | 筛选、高级搜索、批量操作、历史记录 | "更多"、折叠面板、标签页 |
| L3 高级 | API Key、端口、主题、实验开关 | 独立设置页，带搜索框 |

## 硬规则

- 首屏主操作 ≤3 个；第 4 个起必须进"更多"菜单。
- 表单超过 7 项：分组（带小标题）或分步（步骤条+上一步/下一步）。
- 危险操作（删除、覆盖、重置）永远不在 L1，且必须二次确认。
- 新用户首次进入：空状态页只讲一件事——"点这里开始"，配一个主按钮，不许堆功能介绍。
- 设置项超过 15 个：必须分组 + 页内搜索，不许无限长的单页。

## 选项列表的展示与收纳

选项数量决定呈现方式，**高度不许随数据量涨**：

| 情形 | 做法 |
| --- | --- |
| 选项少且数量有上界（如状态 5 种、排序 3 种） | 可直接平铺（radio/胶囊多选），一眼全见 |
| 选项多或数量随数据涨（如后端动态下发的选项） | 必须收进下拉框（`select`），高度固定；选项自带数量（如`全部（n）`） |
| 阈值摇摆时 | 取稳健端：一律下拉。不做"少就平铺、多了才收"——数据一变布局跳动，且阈值本身难定义 |

- 下拉框宽度锁死容器（`width:100% + max-width:100% + text-overflow:ellipsis`），长值闭合态裁剪、展开原生浮层，不撑破布局；窗口缩放表现一致。
- 数据刷新后重建选项：保留用户已选，失效选项自动回退到"全部"；事件绑定一次（静态元素），不随重建丢失。
- 平铺的单选组改下拉时，同步删死样式与残留 ID，终验 grep 确认。

## 筛选多选语义与收纳

单选表达不了的组合（如"A 或 C"）就是多选的理由，Excel 是成熟答案：

- **按内容判定，不按位置**：可管理/可操作的判据是内容特征（如压缩包、工程标记），不是所在目录名；目录只做排序与分组依据。目录名单一刀切，必误伤住在"错地方"的真对象。
- **字段内 OR、字段间 AND**：同一字段勾多个是"或"，跨字段是"且"。生效条件另起 chips 行展示，每颗可删（等同列头漏斗的反向操作）；排序单生效、方向可翻。
- **状态值先画包含关系**：如下单前先确认 B⊂A 之类，发现空档就补值；OR 自洽可验（互补的两档相加等于全集）。
- **计数分两期**：一期全量计数（正确但不随其他字段级联），二期再做随动；先交付再优化，写进决策。
- **收纳三件套**：分组可折叠，长度不许随选项数无限涨；有选值的组自动展开 + 头部 `已选/共 N` 常显（空选不留白）；手动翻转优先，落盘记忆。

## 列表页 hero（筛选控制台，SHOULD，鼓励）

筛选分组较多（经验值 ≥4 组）、平铺后首屏见不到内容时，鼓励把分散的筛选带收成顶部 hero，而不是加侧栏列数。分组少、单屏放得下时不用。

- **常驻行（L1）**：标题 + 一行对象摘要 + 搜索框 + 主操作（≤3 个，含筛选触发按钮）。首屏之下直接是内容，筛选面板默认收起。
- **筛选面板（L2）**：全部分组收进按需展开的面板；展开态用响应式网格，列数随宽度递减、窄屏单列；触发按钮带生效条件计数徽标（无生效时不显示）；Esc 关闭；视图切换时自动收起并隐藏不适用的分组。
- **静态不 sticky**：hero 与面板随页面滚走，sticky 只留页眉（限高见 responsive.md）。面板展开是临时状态，不计入首屏高度。
- **标题写法**：一句话说明对象与任务 + 一行规模/状态摘要；装饰只许一处记忆点，不得抢任务焦点。
- **空间回收**：省下的侧栏/通栏空间还给内容区；面板内长选项仍守"选项列表的展示与收纳"一节。
- **宽屏常驻（经验值 ≥1024）**：面板可常驻为侧栏（单列 + sticky，标题与内容顶对齐）；窄屏收回按需展开。面板永远单列，不用多列网格——多列时各列标题边距必须完全一致，否则整列错位（见 layout.md 对齐一节）。

## 常用手法对照

| 手法 | 适用 | 禁用 |
| --- | --- | --- |
| 折叠面板 | 筛选条件、高级选项 | 核心任务流程（点开才知道下一步=断流） |
| 标签页 | 同级内容切换（预览/代码/日志） | 跨步骤流程（步骤条才是流程） |
| 抽屉/弹窗 | 确认、快速查看详情 | 整页表单（弹窗里填 10 项=灾难） |
| 分步向导 | ≥3 步的配置流程 | 2 步能完的事（多一次点击） |
| 行内展开 | 列表项的更多信息 | 大段富文本（跳详情页） |

## 检验方法

盖住 L2/L3 只看首屏，问：新用户知道点哪里开始吗？老用户完成最高频任务要点几下？超过 3 下就把对应的操作往上提一层。
