# 渐进式披露：首屏、折叠与高级

> 何时读：Step 1 分档、Step 2 线框时。核心思想：**用户一次只做一件事，就一次只给他看相关的东西。**

## 三层

| 层 | 放什么 | 位置 |
| --- | --- | --- |
| L1 首屏 | 核心任务 + 主操作（≤3 个）+ 当前状态 | 一眼可见，无需滚动即达 |
| L2 次要 | 筛选、高级搜索、批量操作、历史记录 | "更多"、折叠面板、标签页 |
| L3 高级 | API Key、端口、主题、实验开关 | 独立设置页，带搜索框 |

## 硬规则

- 首屏主操作 ≤3 个；第 4 个起必须进"更多"菜单。
- 表单超过 7 项：分组（带小标题）或分步（步骤条+上一步/下一步）。
- 危险操作（删除、覆盖、重置）永远不在 L1，且必须二次确认。
- 新用户首次进入：空状态页只讲一件事——"点这里开始"，配一个主按钮，不许堆功能介绍。
- 设置项超过 15 个：必须分组 + 页内搜索，不许无限长的单页。

## 常用手法对照

| 手法 | 适用 | 禁用 |
| --- | --- | --- |
| 折叠面板 | 筛选条件、高级选项 | 核心任务流程（点开才知道下一步=断流） |
| 标签页 | 同级内容切换（预览/代码/日志） | 跨步骤流程（步骤条才是流程） |
| 抽屉/弹窗 | 确认、快速查看详情 | 整页表单（弹窗里填 10 项=灾难） |
| 分步向导 | ≥3 步的配置流程 | 2 步能完的事（多一次点击） |
| 行内展开 | 列表项的更多信息 | 大段富文本（跳详情页） |

## 检验方法

盖住 L2/L3 只看首屏，问：新用户知道点哪里开始吗？老用户完成最高频任务要点几下？超过 3 下就把对应的操作往上提一层。
