# 验收清单

按序验收：任务→恢复→键盘窄屏→视觉→装饰。自动化只能帮忙，最终必须走一遍真实任务。

- 任务：首屏一眼看懂用途与下一步。每屏一个主操作、一个视觉焦点。
- 主张（SHOULD，见 `taste.md`）：能说出一句话主张与一处核心记忆点，主张已落进 token；装饰（渐变/卡片/毛玻璃）有主张支撑，否则删除。落地页/改版另需三个候选方向与截图对标记录。
- 改版保留举证（MUST，仅改版）：保留的旧有部分逐项回答三问（独特/非凡了吗、为何不更好、对照过灵感指南吗），见 SKILL.md 重设计模式；无论证保留 = 阻断。
- 视觉：标题/正文/次要/操作层级清，同类组件一致，间距有节奏，无无意图装饰；标题图标与标题同行；无整体大色块铺底（首屏与深色块克制）；背景装饰字距容器边≥24/16、不贴边半裁；多页风格一致（第三方/vendor 页外）。
- 键盘：主任务全键盘走完，顺序合理，焦点可见且不被遮挡，无陷阱，Esc关层，焦点返回。
- 无障碍：对比度（文字4.5:1、大文字与非文字3:1），控件有名有标签，`axe`零违例。
- 响应式：320px下主任务照常用，无多余横向滚动，200%缩放可用，深色模式与`prefers-reduced-motion`生效。
- 导航：多页路由下每页都有回首页的路（页眉/侧边栏/面包屑），两次点击可回首页；次级页出口明确（返回/关闭/Esc/遮罩）。
- 状态：加载/空/成功/失败同一套视觉语言；失败可重试；刷新保留旧数据。
- 内容：中英混排、长名称、长错误、长URL不撑破布局；截断有全文查看；日期数字走`Intl.*`。
- 诚实：无假按钮、无伪装可用的状态门按钮（取决于某状态而不可用时：隐藏，或真禁用 + 原因，见 `interaction.md`）、无虚假进度、无无说明禁用。

## 验证命令

- `scripts/scan.py`扫低级违例（颜色字面量、`div onClick`、裸`outline:none`、`alert(`、`user-scalable=no`）。
- 运行时回归门禁（防修过又犯）：把"之前修过的毛病"写成断言脚本（如三宽下无横向溢出、面板控件不超宽、按钮全带图标、吸顶零缝隙、无页面报错），改完样式即跑，不过即失败。规则只管行为，不管实现。
- 合同先于 bug：怕犯的毛病不等用户报，先写成行为断言（按断点、按文案点名可见性），门禁从"回归网"升级为"合同网"。
- 断言强度 ladder（由弱到强）：状态位 → 矩形非零 → 穿透点名（被点元素中心打 `elementFromPoint`，命中自己才算数）→ 内容穿透（读内嵌页正文、回执文本，不只读标题/计数/toast）。状态断言最弱，关键交互必须走到穿透级。
- 截图双通道：截图只看整体会撒谎（小图观感会脑补）。关键断言配放大裁图（控件±100px）+ 探针数字；截图是辅助，数字是结论。
- 载荷对齐：动态拼出的控件，其载荷属性与读取处逐项对齐；同一载荷被多个入口消费时，拼装收进单一来源函数，不许各入口手写——缺一个属性就是一个 404 级故障，且静默（标题计数全对，只有内容错）。
- 验内容不验壳：断言读最终内容（如内嵌页正文、回执文本），不只读标题/计数/toast。壳对内容错最难发现，抽查必须穿透到内容层。
- 体感压过数字：帧率数据和人的感觉打架时，以用户拍板为准，允许按场景留两套实现（如连续位移体感顺但数据差，就保留它）；但反直觉结论必须如实记录（含采样时机与 transient 说明），不许只报好看的数字。
- 项目lint：eslint `jsx-a11y`/vue无障碍插件通过；stylelint令牌规则通过。
- `axe-core`（Playwright/react）零违例；Lighthouse无障碍≥95；LCP≤2.5s、INP≤200ms、CLS≤0.1（p75）。
- 人工：完整Tab走查、读屏（NVDA/VoiceOver）、200%缩放、深色模式。

## 状态模型自洽门（选择、批量动作、可数状态）

无用、逻辑不自洽、经不起推敲、用户会觉得奇怪、可能诱发误操作的设计，一律视为模型错，不靠文案和标注粉饰：

- 选择必须对得上可见：筛选换条件时，被筛掉的同类选择即取消；跨类/跨视图保留需一条一句话能讲清的规则，讲不清就不保留。
- 键名即合同：动作键名是什么，空选/无目标时就只提示不动手；禁止与键名矛盾的回退（如空选建成全部可见）。
- 危险动作默认不可达：作用于看不见目标的动作，正常流程里必须走不到（构造消除）；锁定与提示只防边角，不当主路径。
- 数要对得上：界面上相关的数（已选/可见/队列），用户心算必须能对上；对不上就是模型错，不是文案错——改模型，不加标注。
- "实现如此"≠"设计如此"：把现状称为设计，需一条用户能复述的理由；复述不出来就是实现泄漏，重做模型。

## 纠错标准（报"无法复现"与修跨引擎问题时）

- 复现不了≠代码没错：字节一致 + 己方全过，只能排除己方。报无法复现时同步给出已覆盖的状态矩阵、未覆盖的变量（引擎版本/标签页新旧/URL），以及用户侧一键自证法（页面内版本标记）。
- 按最低支持构造：凡动层叠、`display:contents` 覆盖、表单控件 UA 语义，默认按最低支持写（全作者规则：class 开关、JS 提层），能靠构造消灭变量就不靠覆盖所有引擎去测。
- 误判复盘不过夜：状态对判通过、截图好像有东西这类误判，和修 bug 同一次记下来（原因 + 新断言），不攒。
