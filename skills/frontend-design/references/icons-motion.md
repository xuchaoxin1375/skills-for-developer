# 图标、列表与动效规范

> 何时读：Step 4（与 `motion.md` 同步读）。原则：**图标是成熟语言，不是装饰；列表是默认载体；动效只回答"发生了什么/还要等多久"。**

## 一、图标（成熟优先）

1. **全站只用一套成熟图标库**：Lucide / Tabler / Material Symbols 三选一，混用即返工。
   本地离线工具允许用该库笔触语言的**内联 SVG 子集**（24 格、2px 描边、圆角端点），避免整套字体/npm 包的网络依赖与体积。
2. **图标必配文字标签**，不让用户猜；状态表达必须是**颜色 + 图标 + 文字**三重（色盲可读）。
3. **同一概念只用一个图标**：刷新、删除、添加、下载、取消、历史、设置全站统一；危险操作（删除/正式执行）配警示图标。
4. 状态徽标映射（示例）：成功=对勾、失败=三角警示、取消=叉、进行中=脉冲圆点+转圈。
5. **标题图标排版（SHOULD）**：标题前放一个图标是常见做法，能提高 UI 表现力；但图标尽量不要单独占一行，应与标题同行（`display: inline-flex; align-items: center; gap`），字号与标题协调（一般为标题字号的 0.9–1 倍）。

## 二、列表（默认载体）

1. 数据展示默认提供**表格 / 列表卡片**两种视图（分段开关切换），窄屏主走卡片。
2. 列表行支持：勾选（跨页保留）+ 双击/主按钮填入下一步 + 行内编辑/删除；批量操作按钮显示已选数量，`0` 时禁用。
3. 每个列表必须有**空状态**（图标 + 一句话 + 下一步按钮）、**错误状态**（图标 + 人话 + 重试）、**加载状态**（见下）。

## 三、加载反馈

分级、忙态时机与取消边界统一见 `motion.md`“等待与忙态”。spinner、骨架和进度指示配文字；减弱模式下用静态反馈保留信息。

## 四、允许的动效清单

- 列表、弹窗/抽屉与等待指示的预算见 `motion.md`，不在此维护另一套时长。
- 默认淡入/淡出，必要时加微位移；尺寸过渡和进度指示的实现查动画指南，不将宽度动画作为固定要求。

## 五、禁用清单

- 弹跳（bounce）、弹性（elastic）、无限循环的装饰动画。
- 无文字说明的裸 spinner；长等待没有取消/离开出口或虚假承诺可撤销；加载成功只靠颜色变化。
- emoji 当功能图标（语义不稳定、读屏差、跨平台长相不一）。
