# 对比度与页面可读性

用于文字、图标、控件、图表与其实际背景的设计及验收。默认采用 WCAG 2.2 AA；AAA 和产品强化要求单独标明。配色通过不等于整页可读，仍需检查字号、字重、行宽、间距与内容完整性。

## 三条执行规则

- **MUST：按内容用途选择阈值，明确前景与实际相邻背景；次要信息与占位提示不因弱化而豁免。**例：浅灰输入提示仍按普通文字验，搜索图标按必要图形验。
- **MUST：颜色令牌成对定义，并复核实际叠层、主题、背景变化与适用交互状态。**例：白字按钮换成浅蓝 hover 底后，重新测白字对该底色。
- **MUST：数值测量与实际阅读检查共同验收，自动工具未判定的项必须补测并记录。**例：axe 无报错的图片上白字仍需测最差背景，不能直接打勾。

## 阈值与适用边界

| 对象 | AA 最低要求 | 判定对象与边界 |
|---|---|---|
| 普通文字、文字图片 | ≥4.5:1（1.4.3） | 标题、正文、按钮文字、表头、链接、辅助说明、错误、placeholder、只读值均与文字后面的背景比较 |
| 大文字 | ≥3:1（1.4.3） | ≥18pt（24 CSS px），或 ≥14pt（约18.67 CSS px）且粗体；按实际字号/字重，不能只凭“标题”类名；不确定是否满足大字定义时按普通文字验 |
| 必要图标、控件识别/状态线索、信息图形 | ≥3:1（1.4.11） | 与理解该元素所需区分的相邻颜色比较；如搜索/关闭图标、复选框勾、开关滑块、图表必要线条 |
| 必要控件边界 | ≥3:1（1.4.11） | 边框若承担识别输入框/按钮的作用，验边框与相邻背景；并非所有按钮填充与页面背景都必须3:1，有达标文字且识别不依赖边界的按钮可无需边界 |
| 作者定义的焦点指示 | 可见（2.4.7），必要视觉线索对相邻色≥3:1（1.4.11），不被完全遮挡（2.4.11） | 2 CSS px 周长等效面积、同一像素聚焦前后≥3:1 属2.4.13 **AAA**；可作产品增强基线，不能称AA必需 |
| 真禁用控件、纯装饰、logo/品牌名 | 按对应条款例外判断 | 真禁用不等于装饰；只读、低优先级、加载中提示与禁用原因不是自动豁免，原因放在独立可读说明中；logo豁免不能扩大到全部品牌色文字 |

普通文字≥7:1、大文字≥4.5:1是1.4.6 **AAA**，不能称AA通用要求；深底浅字、细字与长时间阅读可在项目中另记更高目标。禁止把4.499:1四舍五入成4.5:1通过。

同信息已有达标文字、图标只是冗余装饰时，可说明图标为何不承担必要识别；只有`aria-label`不能豁免可见功能图标的对比要求。装饰分隔线、阴影、卡片外框不一概要求3:1；若它们承担必要识别，重新归类。

## 实际背景怎样确定

1. **文字看字后的底，图标看有效笔画周围的底。**按钮文字对按钮填充，浮层文字对浮层面板，badge文字对badge底，不能统一拿页面最外层背景计算。
2. `background-color: transparent`时查祖先及其后面的绘制层；处理`rgba()`、文字透明度、祖先`opacity`、遮罩和图片后再算。组透明度需按浏览器实际合成，不能只读元素声明的两个色值。
3. 渐变、照片、纹理、视频与毛玻璃看内容覆盖区域内的**最低对比**，不能取整图平均或只验一个端点。响应式裁剪、滚动、轮播、换图可能改变字后的背景，也要覆盖。
4. 动态背景难以保证时，给内容加稳定的实色底板或经过验证的遮罩；模糊、阴影和描边不能自动证明合格，计入时须测实际形成的背景/字边。图片加载失败、模糊不支持时的回退也要可读。
5. 同一状态标记如果紧邻多个必须区分的颜色，分别检查相邻色；可以用达标边缘/分隔或额外形状解决，不能仅宣称主色够深。

例如透明工具栏滚到照片亮部时，原来合格的白字可能失败；改为实色工具栏，或证明遮罩在所有可出现背景上都满足阈值。

## 令牌与状态配对

颜色清单记录`前景 token → 背景 token → 用途 → 主题/状态 → 阈值`。主色填充、`on-primary`、链接色、弱底及其文字色分别定义；不能因为品牌色或深色模式提亮，就沿用白字。

| 场景 | 检查配对 |
|---|---|
| 正文、次要说明、placeholder、表格值 | 各文字色对实际page/surface/input底；hover行、条纹行、选中行逐项复核 |
| 主/次/危险按钮 | 文字与功能图标对default/hover/active/loading底；有必要边界时另测边界 |
| 标签与成功/警告/错误提示 | 文字对soft底≥4.5:1，必要图标对soft底≥3:1；不能把图标阈值套给旁边的小字 |
| 开关、复选框、导航选中态 | 必要勾/滑块/标记对相邻色≥3:1；文字/图标/形状补充颜色传意 |
| 焦点、文本选择、浮层 | 焦点环对相邻底，选中文字对选择底，tooltip/menu/dialog文字对各自面板底 |

只覆盖产品实际支持的主题与适用状态，无需机械枚举不可能状态。`currentColor`、CSS层叠、浏览器自动填充、主题继承与hover工具类可能改变最终色；以实际渲染检查。`forced-colors`用系统颜色/可见outline等保留识别，不默认`forced-color-adjust:none`；如支持`prefers-contrast`，复核其覆盖样式。

## 数值之外的阅读质量

- 正文默认14–16 CSS px、中文行高1.6–1.7；12px用于短辅助内容，不承担主要任务说明。这是产品排版起点，**不是WCAG统一最小字号**。细笔画、小图标与深底浅字即使刚过阈值仍可能难辨，先改善字重、字号或笔画，再复测。
- 中文行宽约28–40字、英文45–75字符；长内容收窄阅读栏，不靠缩字号或降低颜色对比制造层级。标题、正文、说明用字号、字重、间距区分，次要信息也可读。
- 链接、错误、选中与图表系列不只靠颜色；正文链接常显下划线，错误带文字，图表可配标签/线型/形状。前景对背景合格不代表链接与正文容易区分。
- 200%文本放大、320 CSS px等效回流与文本间距覆盖下不得裁切、重叠或丢信息。1.4.12要求承受行高1.5、段后距2、字距0.12、词距0.16倍字号的覆盖（按语言/书写系统适用项），并非必须将这些设为默认值。
- 真禁用可弱化，但其原因、恢复方式与关键数据保持可读；只读值按内容验。placeholder既要达标，也不能替代可见label。

## 验收与证据

先在令牌层验证已知色对，再在浏览器中进入变更涉及的主题/状态，运行axe等自动检查并查看关键区域截图；复杂背景、图标、canvas/SVG与未能计算项补人工测量。工具的`incomplete`/需人工复核不算通过，axe零违例也不是全部对比度合格或整页WCAG合规证明。

标准比率使用WCAG相对亮度`(L亮+0.05)/(L暗+0.05)`；普通不透明sRGB可用WebAIM Contrast Checker或已核对公式的库。透明/P3/oklch/滤镜等先确定实际合成与颜色空间，不能直接以HSL明度、OKLCH的L或APCA分数代替WCAG 2.x比率。文字取浏览器实际前景/背景色，勿取抗锯齿边缘像素当原文字色；截图用于发现细字难辨及复杂背景最差区，不能凭观感断言数值合格。

| 元素/区域 | 主题/状态 | 前景与实际背景 | 最低比率 / 阈值 | 方法与证据 | 结论 |
|---|---|---|---|---|---|
| 主按钮 | light/hover | 文字色 / hover填充 | 实测值 / 4.5 | 计算器或浏览器测量 + 区域截图 | 通过/失败/未执行 |
| 图片上标题 | mobile/裁剪后 | 字色 / 字后最差背景 | 实测值 / 对应字级阈值 | 局部采样及遮罩合成依据 | 通过/失败/未执行 |

验收覆盖所有变更涉及的语义色对及高风险背景，不以“抽查三处正文”代表全部通过。例外项记对象、条款与理由；未测项记缺口，不写成不适用。单个色对失败可定位为QA `A-01`，仅颜色传意用`A-11`，焦点问题用`A-08`，阅读布局问题按对应布局编号。

## 标准依据

依据核对日期：2026-10-10。以下为W3C条款解读，规范原文见[WCAG 2.2](https://www.w3.org/TR/WCAG22/)；上文另行标注的排版起点与强化目标属于产品建议。

- [1.4.3 Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通/大文字、禁用与装饰例外、阈值不取整、抗锯齿判定。
- [1.4.6 Contrast (Enhanced)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-enhanced.html)：AAA的7:1与4.5:1。
- [1.4.11 Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)：必要控件线索/图形对相邻色3:1及边界适用性。
- [2.4.13 Focus Appearance](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html)：AAA的面积与聚焦前后对比。
- [1.4.12 Text Spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)：用户覆盖间距时保留内容与功能。
