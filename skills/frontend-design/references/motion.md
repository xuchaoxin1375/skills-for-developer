# 动效：过渡、加载与克制

> 何时读：Step 4。原则：**动效只回答两个问题——"刚才发生了什么"和"还要等多久"。**答不上来就别加。

## 过渡时长

| 场景 | 时长 |
| --- | --- |
| 轻提示（toast） | 120ms 快档 |
| 悬停、开关、折叠 | 150–200ms `ease-out` |
| 页面切换、抽屉、弹窗 | 200–320ms `ease-out` |
| 上限 | 任何装饰性动画单次 ≤320ms，不循环 |

进入用淡入+微位移（8–12px），退出更快（≤150ms）。禁止弹跳（bounce）、弹性（elastic）进正式工具界面。

## 属性预算

- 只动 `transform`/`opacity`；位移走 `translate`，不碰宽高、内外边距、`top`/`left`。
- 尺寸变化首选 FLIP：量旧矩形 → 瞬时切新尺寸 → 用 Web Animations 把整框从旧矩形 `transform` 到新矩形（200ms，同缓动）→ 播完回到 `transform:none`，不断言残留。动画期只有合成器在动；切换瞬间的一次同步回流不可避免，别把它算到动画头上。
- WAAPI 不受 CSS 的 `prefers-reduced-motion` 兜底：必须在 JS 里显式判断，命中直接瞬时切换。
- 宽高过渡默认禁止：实测动画帧本身不贵，贵的永远是回流；FLIP 绕开动画期回流后，宽高过渡已无存在的理由。内容淡化只掩盖不顺滑，留作兜底。
- 重内容切换先冻结再演——但只配"藏内容"策略（淡出/遮罩）：框里挂着富文本/大图/live 嵌入页时，动画前把内嵌内容尺寸钉死（播完释放），让切换瞬间那次同步回流只剩空盒子；贵的永远是动画开始前那一帧，不是动画本身。揭示（clip/反 scale）策略下冻结反而制造落位跳变：内容冻着旧排版演完、最后跳到新排版；正确做法是 Last 步直接按终态排版（一次同步回流，常为个位数 ms），飞行与落位同一套排版。
- 藏不住就盖住：中间态实在顺不下来，加约 120ms 遮罩盖住重排，眼睛只看缩放。冻结（性能）+ FLIP（运动）+ 遮罩（视觉）各管一层，不要指望一种手法包办。遮罩必须独立于运动元素（否则面板自身淡出会连累遮罩 double-dip），时长与飞行对齐、曲线可另给慢起。
- 退出双轨：关闭 = 面板向触发源 FLIP 缩小 + 淡出（ease-in，约 0.7× 进入时长）与遮罩并行淡出；播完再落语义状态（隐藏/清空/焦点回到触发源）。触发源丢失、减弱模式走瞬时关闭。

## 载入与滚动

- 图片/内嵌页载入淡入：初始 `opacity:0`，`load` **和** `error` 后都挂类淡入——只挂 `load` 的话，加载失败就永久透明。
- 日志/消息流自动滚动：只在粘底（距底 <40px）时跟随到最新；用户上翻查看时不抢；新任务开始时沉底一次。
- 悬停反馈：位移 ≤2px + 阴影升一级，200ms；不改变布局、不抢焦点，触屏上无害即可。

## 加载策略（按等待时长）

| 等待 | 做法 |
| --- | --- |
| <300ms | 什么都不做（闪一下比转圈体验好） |
| 300ms–2s | 行内 spinner 或按钮 loading 态，按钮禁用防重复提交 |
| >2s | 骨架屏（skeleton）占位 + 进度说明 + **可取消**按钮 |

规则：按钮一旦进入 loading 必须禁用；>2s 的任务必须可取消；失败必须进错误态（人话+重试），不许无限转圈。

## 骨架屏 vs 转圈

- 能预知布局（列表、卡片、详情）→ 骨架屏，按真实布局画灰块。
- 预知不了（提交、保存、计算）→ 按钮/行内转圈 + 文字说明在干什么（"正在转换第 3/10 张…" beat 裸 spinner）。
- 飞行中骨架不是加载态骨架：线条对比度从 slate-200 起、镜像真实结构（标题/按钮胶囊/hero/卡片块），否则就是白闪；与内容的交叠在密集文本页上会形成鬼影——骨架实顶前半、后半快速交接（约 80ms），不要长交叉淡化。

## 可访问性

- 跟随系统 `prefers-reduced-motion`：开启动效全部降为瞬间切换（`@media (prefers-reduced-motion: reduce) { * { animation: none; transition: none } }` 级别）。
- 加载与成功不能只靠颜色：spinner 配文字，成功配图标+文字。
