# 动效：过渡、加载与克制

> 何时读：Step 4。原则：**动效只回答两个问题——"刚才发生了什么"和"还要等多久"。**答不上来就别加。

## 过渡时长

| 场景 | 时长 |
| --- | --- |
| 悬停、开关、折叠 | 150–200ms `ease-out` |
| 页面切换、抽屉、弹窗 | 200–320ms `ease-out` |
| 上限 | 任何装饰性动画单次 ≤320ms，不循环 |

进入用淡入+微位移（8–12px），退出更快（≤150ms）。禁止弹跳（bounce）、弹性（elastic）进正式工具界面。

## 加载策略（按等待时长）

| 等待 | 做法 |
| --- | --- |
| <300ms | 什么都不做（闪一下比转圈体验好） |
| 300ms–2s | 行内 spinner 或按钮 loading 态，按钮禁用防重复提交 |
| >2s | 骨架屏（skeleton）占位 + 进度说明 + **可取消**按钮 |

规则：按钮一旦进入 loading 必须禁用；>2s 的任务必须可取消；失败必须进错误态（人话+重试），不许无限转圈。

## 骨架屏 vs 转圈

- 能预知布局（列表、卡片、详情）→ 骨架屏，按真实布局画灰块。
- 预知不了（提交、保存、计算）→ 按钮/行内转圈 + 文字说明在干什么（"正在转换第 3/10 张…" beat 裸 spinner）。

## 可访问性

- 跟随系统 `prefers-reduced-motion`：开启动效全部降为瞬间切换（`@media (prefers-reduced-motion: reduce) { * { animation: none; transition: none } }` 级别）。
- 加载与成功不能只靠颜色：spinner 配文字，成功配图标+文字。
