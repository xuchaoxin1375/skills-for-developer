## 界面验收清单（交付前逐项打勾）

> 用法：Step 6 对照，未全过不得交付。

### 布局

- [ ] 间距只用 4/8/12/16/24/32/48，无魔法数字
- [ ] 同屏卡片/标题/按钮左对齐到同一垂直线
- [ ] 一屏只有一个视觉焦点
- [ ] 布局模式是四种之一（仪表盘/表单/列表详情/设置），无自创第五种

### 渐进式披露

- [ ] 首屏主操作 ≤3 个，其余进"更多"
- [ ] 表单 >7 项已分组或分步
- [ ] 弹窗标题说清后果，主按钮动词化；隐藏操作（双击）有可见等价按钮
- [ ] 二级页面（历史/审计/明细）结构化行，非裸文本
- [ ] 危险操作不在首屏且有二次确认
- [ ] 空状态只有一件事+一个主按钮

### 响应式（范围见 adaptive-responsive-guide/references/acceptance.md）

- [ ] 线框已说明窄屏/窄容器重排、操作收纳、滚动归属；项目阈值有内容实测依据
- [ ] 页面级无非必要横向滚动，确需二维阅读的内容可局部滚动，边界见响应式专项 `page-patterns.md`
- [ ] 导航可达（手机抽屉有关闭+点遮罩可关）
- [ ] 表格有降级（横滑冻结首列 / 卡片列表 / 列显隐）
- [ ] 触控与键盘目标按 `references/a11y.md`，产品基线与合规要求已区分
- [ ] 普通弹窗/底部面板/全屏与页面/局部滚动按任务选型，缩放和键盘下内容、关闭与操作可达

### 动效与三态

- [ ] 每个异步操作有空/错/加载三态（空有图标+指引，错有图标+人话+重试）
- [ ] 过渡与等待符合 `references/motion.md`，项目例外有理由，骨架与内容结构连续
- [ ] 退出中间帧保持内容与布局，正常速度连续；采样方法见 `web-animation-guide/references/performance-a11y.md`
- [ ] 请求开始即忙态、防重入，等待指示延迟出现，成功/失败后恢复，取消边界真实
- [ ] 长等待有阶段说明、已用时间和取消/离开出口，支持缩小范围时给入口（边界见 `references/motion.md`）
- [ ] 按钮文案是动词+对象+后果，无"刷新/提交/送操作页"类黑话
- [ ] 状态门按钮已二选一（隐藏 / 真禁用+原因可见），无伪装可用；表单校验错误不禁用提交（点了定位首错）
- [ ] 正常模式有双向退出反馈；减弱/不支持/取消动画时，终态与加载信息仍正确
- [ ] 快速开关和 Esc 可收尾，关闭内容不可聚焦，焦点合理返回，无重复提交
- [ ] 列表有表格/卡片双视图（或明确的降级方案），进入反馈不拖延内容可用

### 视觉与规范

- [ ] 主张一句话可说清（情绪目标+记忆点），已落进 token，不落 token 的主张不算数
- [ ] 减法过一遍：删不服务内容/操作/主张的元素；渐变/卡片/毛玻璃有主张支撑（见 `taste.md`），同一页记忆点装饰只一处
- [ ] 字体/字号/行高按 token（中文正文行高 ≥1.6）
- [ ] 正文对比度 ≥4.5:1（抽查 3 处）
- [ ] 背景装饰字有安全边：距容器边 ≥24（手机 ≥16），溢出裁掉+边缘淡出，不贴边、不半裁半露
- [ ] 错误/成功有图标+文字，不只靠颜色
- [ ] 全站一套成熟图标（Lucide/Tabler/Material 三选一），图标必配文字标签
- [ ] 同一概念同一图标；禁用 emoji 当功能图标
- [ ] token 已进 CSS 变量/主题文件，无散落硬编码

### 改版保留举证（仅改版，未全过不得交付）

- [ ] 默认推倒重做，非在旧稿上打补丁（用户只点特定部分除外）
- [ ] 每处保留(包括布局和样式),都要检查问答：独特在哪里? 新颖在哪里? 为何不更好、对照过灵感指南吗（见 SKILL.md 重设计模式）
- [ ] 交付物含"保留清单"（保留了什么 + 答案）

### 自我批判（交付前必做）

流程：换三种视角各列出可能的问题 → 逐一解决 → 解决不掉的写入已知问题。

- [ ] 新用户视角：盖住说明文档，只看界面能完成核心任务吗？卡点列出来并解决
- [ ] 窄屏视角（390px）：逐屏找挤压/溢出/重叠，见下节专项
- [ ] 键盘视角：全程只用 Tab/回车走完主流程，焦点可见且顺序合理
- [ ] 每个问题有结论：修了打勾，修不掉进 README/发布说明的"已知问题"

### 溢出与挤压专项

- [ ] 长文本（标题/文件名/URL）有省略策略（单行省略+title，多行 ≤2 行）
- [ ] 长串（URL/token/无空格英文）可断行，不撑破容器
- [ ] flex/grid 子项设了 min-width:0，无内容顶出
- [ ] 图片有固定比例 + object-fit，加载不跳动
- [ ] 页面级无非必要横向滚动，不以全局 `hidden/clip` 掩盖真实溢出

### 自动化与截图审核（条件允许）

- [ ] `node scripts/screenshot.mjs <地址>` 产出基础宽度截图并由 Agent 查看，容器/阈值/极窄等适用专项另验；记录实际宽度与未执行项
- [ ] 动效另跑正常与减弱模式的行为检查；静态截图脚本默认减弱模式，不证明进出场有效
- [ ] axe/Lighthouse 跑一遍，对比度与可访问性错误清零或已列入已知问题
- [ ] 按项目目标与变更风险复核平台字体/滚动条差异，结论与未覆盖环境已记录
