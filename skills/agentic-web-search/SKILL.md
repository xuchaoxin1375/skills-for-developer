## 联网搜索与证据核验

目标是用足以支持主张的证据回答，不是运行固定轮数或读满参考篇数。默认先走下面的短路径；仅在出现对应条件时读取参考章节。

## 轻量执行入口

1. **确定范围与限制**：复用当前日期、已注入偏好和本轮可见记录。简单事实或“搜一下”默认轻量查询；只有“只搜一次／最多一次”等明确数量才构成次数硬限制。硬限制内失败也计次，不自动重试、换渠道或扩量；搜索次数不自动限制正文读取，除非用户另有限定。
2. **选择获准渠道**：按 `user-profile` 顺位选择，核对当前工具定义、实际认证方式与费用边界。需要的本地命令可用性、认证状态及网络线索尽量合并检查；不回显密钥、不另发收费探针。已加载规则和本轮已确认的同环境信息直接复用，版本或状态改变才复查；只有参数不明确时才查帮助。
3. **取得有目标的证据**：需要发现来源时先做一次搜索，用具体实体、版本和必要的年份，不用“最新/latest”代替查询规划。已知官方URL足以核验时可直接读取，不为形式先搜索。简单任务用一句话说明渠道和核验目标即可，不展开预算表、双语矩阵或完整研究计划。
4. **补足决定性证据**：根据结果读取能支持主张的官方原文或关键报道。网页选路归 [network-access](../network-access/SKILL.md)，提取归 [htmlmini](../htmlmini/SKILL.md#使用边界)；已有正文或快照直接复用。搜索服务成功不证明本地抓取路线可用。
5. **回答或有界补查**：证据充分即停，标注日期、链接和未核验部分。证据不足时，可在既有渠道、范围、费用与时间授权内定向补查，或收窄结论并说明缺口；不因“搜一下”强行停在一次，也不自动展开多轮调研。多跳、争议或需要扩量时才读[详细协议](references/search-protocol.md)。

## 费用与请求底线

- **认证不等于计费结论**：已安装、已有密钥或工具支持免密访问，都不能证明本次免费。发出请求前按实际认证和授权判断；费用不明且无相应授权时先澄清。若返回的认证方式与预期不同，暂停追加请求，静态核对，不推断失败免费或已经扣费。
- **前置校验**：使用当前 schema 或已核实的命令参数，不通过真实收费请求猜入口或修参数。失败、重试和回退计入实际尝试次数；费用与次数限制不因用户要求“继续”或质疑而自动解除。
- **渠道回退**：不把相同查询扇出到所有渠道，不静默切供应商托管搜索；入口归属不明或疑有越权时按 [harness-web-check](../harness-web-check/SKILL.md)静态核对。第三方工具 skill 只管执行，不修改其正文承载本仓库规则。
- **请求节奏**：限制未知时逐条、留间隔；429 遵守 `Retry-After` 与共享冷却，不换工具或出口绕过。重试受次数与总耗时限制，不叠加工具已执行的重试；批量调度时读取 [tooling.md](references/tooling.md)。

## 证据与停止条件

- **官方明确事实**：发布、版本、价格等由当前且明确支持该主张的一手公告或文档确认即可，不机械凑第二来源。官方营销自测只能证明厂商的声明，不能据此断言普遍性能领先。
- **争议与第三方消息**：高影响、存在冲突或仅有第三方独家消息的关键结论，尽量用不同原始出处交叉验证；无法验证时明确“据某来源报道／尚未确认”，不写成确定事实。
- **独立性看原始出处**：同一公告的转载、数据库镜像只算同一出处；同一抓取工具可以读取独立来源，换工具读取同一公告不会增加独立性。摘要加工、内容失真或通道可靠性存疑时，才换读取路径验证保真度。
- **否定判断要收窄**：查不到不等于不存在。判断当前版本或发布状态应查覆盖发布历史的官方入口；覆盖不足时写“本轮未找到官宣”，不要写成“截至现在绝未发布”。
- **日期与原文对齐**：区分发布、更新、事件和抓取日期；搜索结果与记忆冲突时以可靠且有日期的证据为准。用户指定 URL 时实际读取该页，取不到就声明，不能用邻近页面冒充原文。
- **完成判定**：关键主张有对应证据、范围已覆盖、没有会改变结论的未决线索即可收尾；预算或期限到达则说明缺口，不为凑轮数继续。轻任务保留主张、URL、日期与核验状态即可，无需新建账本文件。

## 成本与预算（分档）

轻任务采用上述入口，不默认展开档位表。调研、复杂核验或扩量时，按[预算与计费细则](references/search-protocol.md#成本与预算分档)选择档位、记录调用与总期限；参考额度不是最低调用量，也不构成收费授权。

## 自检与验证

- [ ] 是否保留明确次数、渠道与费用限制，未把口语“搜一下”误当硬限制？
- [ ] 是否复用已加载规则与同环境记录，必要本地检查已合并，未通读无关参考？
- [ ] 主张是否有对应证据，传闻、官方确认和未找到是否区分，独立性是否按出处判断？
- [ ] 是否只为实际缺口补查，日期、链接、限制与未核验范围是否清楚？

维护时运行仓库结构、链接及分发校验，并按[轻任务回归场景](references/evidence-and-evaluation.md#轻任务回归)桌面走查；仅有文档校验不能声称代理行为或端到端性能已改善。
