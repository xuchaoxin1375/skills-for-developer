# 交互与状态说明

## 1. 综合案例

用户为 `example.com` 管理 DNS 解析。任务路径是：找到记录、确认类型与目标、编辑或添加、校验、保存并获得反馈。所有数据是本地模拟，不会改变真实 DNS。

默认提供 6 条记录，覆盖 A、CNAME、MX、TXT。可以新增 AAAA。IPv4 和 IPv6 示例使用文档保留网段。

## 2. 导航状态机

| 状态 | 进入条件 | 布局行为 | 退出条件 |
| --- | --- | --- | --- |
| 固定展开 | 用户点击固定按钮 | 宽屏为主内容预留 224px | 用户主动收起 |
| 收起 | 用户点击收起按钮 | 工作台留 64px，站点留 56px | 悬停、键盘聚焦或点击固定 |
| 悬停预览 | 精细指针停留 120ms | 覆盖内容，不改变主内容起点 | 离开 240ms 且没有焦点保持 |
| 焦点展开 | 键盘聚焦导航项 | 覆盖展开，标签可见 | 焦点离开导航 |
| 移动端抽屉 | 用户点击菜单按钮 | 原生 dialog 覆盖层 | 选中页面、关闭或 Escape |

展开延时可在“侧边栏导航”页面调整为 120 / 250 / 400ms。关闭悬停自动展开不影响点击固定和键盘聚焦。

### 关键约束

- 固定按钮本身不触发焦点展开，避免用户点击“收起”却因为按钮仍聚焦而无法收起。
- 快速进入与离开先取消旧计时器；组件卸载时清理所有计时器。
- 触摸设备不依赖 pointer hover。
- 站点画布小于 961px 时，即使固定也采用覆盖方式，避免压缩数据区域。
- 工作台小于等于 1000px 时，改为移动导航入口。
- 站点画布小于等于 640px 时，图标栏替换为顶部抽屉入口。

## 3. 预览宽度

预览使用 CSS 容器查询改变真实内容布局，不使用 CSS scale。

- 桌面预设：填满当前可用画布。
- 平板预设：目标 768px，不超过当前画布。
- 手机预设：目标 390px，不超过当前画布。
- 滑条：从 300px 到可用画布宽度；画布不足 300px 时使用当前实际空间。
- 数值：显示限制在可用画布内的目标外框宽度，动画结束后即为实际宽度；内容宽度会扣除边框。
- 自动演示：在上下界往返，手动拖动、切换预设，或开始操作画布内控件时自动停止。
- 减少动态效果：改为间隔 1.8 秒的离散宽度切换。
- 页面在后台时不更新自动演示尺寸；卸载时清理计时器。
- 独立预览：打开 `?preview=1`，用于直接按 1440 / 768 / 390 / 300px 测量视口。

手机预设只能验证布局，不会改变真实设备的指针类型、触屏行为、屏幕阅读器或像素密度。触屏验收必须使用实际设备或浏览器设备仿真。

## 4. DNS 列表

### 搜索与筛选

搜索匹配主机名、完整示例域名、类型、内容与备注，不区分大小写。`useDeferredValue` 降低输入更新与结果更新的耦合。

筛选支持名称、类型、内容、代理状态，操作符为“等于”或“包含”。最多 4 个条件，条件之间为 AND。空条件不应用；点击“应用筛选”或按 Enter 后生效。关闭浮层不应用未提交的条件。

点击名称或类型列头在升序、降序间切换，并通过 `aria-sort` 公开排序状态。

无结果时解释当前状态，提供“清除搜索与筛选”。筛选、关键词或每页数量变化时返回第 1 页并清空选择，避免对不可见旧选择执行删除。

### 选择与分页

全选仅针对当前页，部分选中通过原生 `indeterminate` 表达。支持每页 10 / 25 / 50 条，上限 200 条本地记录。删除后页码会限制在有效范围内。

选中后，底部才出现删除所选。未选中时导出全部记录，已选中时导出所选记录。

### 窄屏重排

小于等于 640px 时，每条记录在原有表格语义中重排：类型和名称在第一行，内容在第二行，代理与 TTL 在第三行。长 TXT 内容可换行。列头保持辅助技术可读。

隐藏的列头不保留可聚焦控件；排序和全选入口移入“显示设置”。变窄时若焦点原本在即将隐藏的导航或列头，会移交到可见的导航入口或搜索框。

## 5. 添加与编辑

宽屏通过右侧抽屉编辑，窄屏成为全宽表单。独立“表单与校验”页面展示同一套表单，避免维护两种校验逻辑。

### 字段结构

| 分组 | 字段 | 行为 |
| --- | --- | --- |
| 基本信息 | 类型 | A / AAAA / CNAME / MX / TXT |
| 基本信息 | 名称 | 必填，支持 @、子域与常用 DNS 主机名 |
| 基本信息 | 内容 | 按记录类型校验 IPv4、IPv6、域名或文本 |
| 基本信息 | MX 优先级 | 仅 MX 出现，0 至 65535 |
| 解析设置 | 代理状态 | 仅 A / AAAA / CNAME 支持 |
| 解析设置 | TTL | 自动、1 分钟、5 分钟、1 小时；代理时自动 |
| 解析设置 | 备注 | 可选，最多 200 字符 |

### 校验顺序

1. 首次输入不立刻责备用户；字段失焦后显示格式错误。
2. 已触发校验的字段在修改时同步更新错误，避免旧错误一直残留。
3. 提交时检查全部字段，显示摘要并聚焦第一个错误字段。
4. 格式正确后进入本地保存等待状态，约 550ms，防止重复提交。
5. 检查同类型、同名称、同内容的重复记录与数量限制。
6. 保存成功后刷新列表并提示；新增草稿清空。

等待仅用于演示异步反馈，不是网络延迟测量，也不是服务端验证。

### 恢复策略

新增草稿在当前浏览器保留。取消、关闭抽屉或离开页面后可以继续新增。编辑中的输入只在当前表单实例内保留，取消编辑即放弃该次未提交更改；文案不将编辑标为自动保存草稿。

格式错误、重复记录或模拟保存失败均不会清空当前输入。“模拟保存失败”只存在于表单实验页，用于测试错误提示和重新保存。

存储被限制、隐私会话结束、清除站点数据或点击“重置演示”后，不保证草稿仍在。生产环境需要明确草稿保留期限与隐私策略。

## 6. 删除

删除入口出现在选中后的底部操作区，或编辑抽屉的独立危险操作位。点击后打开二次确认对话框，列出实际记录并说明后果。默认焦点放在“保留记录”，而不是危险按钮。

确认删除才修改本地数据。取消或 Escape 不删除。可以通过重置演示恢复初始的 6 条记录，但不是任意操作的撤销历史。

## 7. 导入与导出

支持本项目 JSON 格式，不支持 BIND zone 文件或 Cloudflare API 原始返回格式。

```json
{
  "version": 1,
  "domain": "example.com",
  "records": [
    {
      "type": "A",
      "name": "dev",
      "content": "192.0.2.10",
      "proxied": false,
      "ttl": "auto"
    }
  ]
}
```

也允许直接提供记录数组。每条记录必须有 type、name、content，其他字段使用演示默认值。导入时生成新的本地 ID；来源 ID 不作为可信标识。

文件上限 1MB，合计记录上限 200 条。格式、字段或重复检查失败时，整个导入拒绝，不产生部分写入。导出是本地 Blob 下载，生成的对象 URL 随后释放。

## 8. 主题、快捷键与反馈

主题默认跟随系统，手动选择后保存。顶部和独立预览均提供相同入口。

- Control / Command + K：搜索页面。
- Tab / Shift + Tab：依次访问控件。
- 页签区域的左右箭头、Home、End：切换查看模式。
- Escape：关闭当前原生对话框；普通浮层关闭并返回触发器。
- Enter：提交当前筛选或表单。

普通成功反馈通过非阻塞通知与 live region 公开。表单错误直接位于表单中，不依赖临时通知。

## 9. 已知边界

这不是权威 DNS 校验器：未实现完整国际化域名归一化、CNAME 排他性、真实 zone 权限、DNS 传播、原子服务端事务或多标签页冲突合并。生产产品需要补足这些能力。
