# 08 · 交互式表格与条目规范

> 适用范围：承载「查看 → 排序 / 筛选 → 勾选 → 批量操作 → 编辑单条」的数据表格（列表页）。目标是 **列再多也不丢关键操作、列宽由用户掌控、批量与编辑都不丢数据**。

对应实现：`src/dashboard/pages/DnsRecords.tsx`（页面）、`src/ui/columns.tsx`（列宽与滚动提示）、`src/dashboard/RecordEditor.tsx`（行内 / 弹窗编辑器）、`src/index.css` 中 `.dt*`、`.col-resizer`、`.bulkbar`。

## 1. 能力总览

| 能力 | 规则摘要 | 设计稿位置 |
| --- | --- | --- |
| 列宽可调 | 表头右缘分隔条：拖动 / 键盘 / 双击恢复；有最小宽度；持久化 | 任意列表头右缘 |
| 排序 | 表头放排序按钮；升序 → 降序 → 无 三态；`aria-sort` | Name / Type / Content / Proxy / TTL / Comment / Modified |
| 勾选与全选 | 首列复选框；表头复选框 = 本页全选（半选态）；Shift 连选；可「选择全部匹配项」 | 首列 |
| 批量操作 | 悬浮粘性批量条；可撤销；对不适用项给出说明 | 页面底部 |
| 行内操作 | **最后一列常驻**（粘性固定）：Edit + Delete | 末列 Actions |
| 编辑形式 | 展开编辑区（默认）或弹窗，由用户在显示选项中选择 | Display options → Edit style |
| 列显隐 / 密度 | 次要列可隐藏；紧凑 / 舒适密度 | Display options |
| 分页 | 每页 5/10/25/50；跨页选择；返回列表时翻到高亮行所在页 | 表格下方 |
| 窄容器 | 容器 < 700px 切换为卡片列表（同一数据，触控友好） | 拖窄宽度 |

## 2. 表格结构

```text
┌ .tbl（overflow-x:auto，可聚焦 region）─────────────────────────────────────┐
│ [☐ sticky-left] [!] Name ⇅│ Type ⇅│ Content ⇅│ Proxy ⇅│ … │ 填充列 │ [Actions sticky-right] │
│ [☐]            [!] …                                             │ [Edit][🗑]            │
│ ┌ edit-row（colSpan 全部，内容 sticky-left，宽度 = 容器可视宽度）─────────────┐ │
│ │ 行内编辑器：Type / Name / TTL / Content / Proxy / Comment · Save / Cancel │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
        分页 / 计数                                       [悬浮批量条 sticky bottom]
```

- 使用真实的 `<table>`；`table-layout: fixed` + `<colgroup>` 控制列宽；
- `border-collapse: separate; border-spacing: 0`：粘性列的边框才不会随内容滚走；
- 表格 `width:100%`，`min-width` = 可见列宽之和 + 固定列宽；容器更宽时由一列**填充列**（`<col />` 无宽度）吸收剩余空间，因此用户设置的列宽永远是精确值。

## 3. 列宽调节

### 3.1 必须

| 条目 | 原因 |
| --- | --- |
| 每个数据列都有最小宽度（如 64 / 120px），拖动不能小于它 | 防止列被拖没，内容不可辨 |
| 键盘可调：分隔条可聚焦（`role="separator"`、`aria-valuenow/min/max`），`←/→` ±8px，`Shift` ±32px，`Home/End`，`Enter` 恢复默认 | 全键盘可达 |
| 提供恢复入口：双击分隔条 / `Enter` / 显示选项里的「Reset column widths」 | 用户可以随时回到默认 |
| 宽度被持久化（`localStorage`） | 偏好不应每次刷新丢失；存储失败时静默降级 |
| 拖动不应触发排序（分隔条的点击要 `stopPropagation`） | 避免误操作 |

### 3.2 应该

- 分隔条常驻一条淡色竖线作为**可发现性提示**；悬停 / 聚焦 / 拖动时加粗并使用主色；
- 命中区 12px（粗指针 20px），位于表头单元格右缘**内侧**，避免被相邻列覆盖；
- 拖动过程**只改写 DOM**（`<col>` 与 `<table>` 的 style），松手时一次性提交到 React state——拖动期间零重渲染；
- 表头文字过长时使用省略号，不换行、不撑破列。

### 3.3 避免

- 用 `width: 100%` 的表格 + 无填充列：容器变宽时所有列被按比例拉伸，用户设置的宽度失真；
- 拖动中每个 `pointermove` 都 `setState`：行数多时会掉帧；
- 把分隔条画在单元格之外（右侧列会盖住它，拿不到事件）。

## 4. 排序

- 表头放一个**按钮**（不是整格可点），文字 + 方向图标；三态循环：升序 → 降序 → 无；
- 当前排序列的 `<th>` 设置 `aria-sort`；图标在激活时使用强调色；
- 数值列（TTL）、时间列（Modified）按数值排序，其余按字符串（`localeCompare`）；
- 排序发生在筛选之后、分页之前；排序后保持当前页码（筛选 / 搜索变化才回到第 1 页）。

## 5. 勾选、全选与批量操作

### 5.1 勾选规则

| 控件 | 行为 |
| --- | --- |
| 行复选框 | 单击切换；`Shift + 点击` 选择连续区间（以上次点击的行为起点） |
| 表头复选框 | 作用于**本页**所有行；部分选中时显示半选（`indeterminate`） |
| 「Select all N matching records」 | 本页全选后，若还有更多页，在批量条中出现，选中所有匹配筛选的行 |
| 选中高亮 | 整行主色浅底；`aria-selected` |

- 选择集合与分页解耦：翻页不丢选择；筛选后批量操作只作用于「被选中且当前可见（匹配）」的行；
- 复选框命中区 ≥ 32px（`.hit`），列宽 44px。

### 5.2 批量条

- **悬浮 + `position: sticky; bottom: 16px`**，贴在视口底部；**不得**插在表格上方——否则勾选第一行后整张表下移，`Shift` 连选会点错行；
- 内容：已选数量（`aria-live`）· 可选的「选择全部」· 动作按钮 · 清除选择；
- 动作按顺序为：不危险的修改 → 导出 → 危险操作（Delete，危险色）；
- **可撤销优先于二次确认**：删除除了确认对话框外，还提供 8 秒的「Undo」通知；批量修改（代理状态）直接执行并给出「Undo」；
- 对不适用的项给出说明，而不是静默忽略：「2 records set to Proxied · 3 skipped (not proxyable)」。

## 6. 行内操作：最后一列常驻

### 6.1 必须

| 条目 | 原因 |
| --- | --- |
| 编辑 / 删除放在**最后一列**，用 `position: sticky; right: 0` 固定 | 列很多时用户需要横向滚动，但随时都要能点到 Edit |
| 首列（勾选）同样粘性固定 | 横向滚动时仍可对行勾选 |
| 粘性单元格必须有不透明背景（`background: inherit`，行本身有实色背景） | 否则下面滚过的内容会透出 |
| 悬停 / 选中 / 展开时，粘性单元格背景与整行一致 | 视觉上是一整行 |
| 横向可滚动时，粘性列边缘出现阴影提示（`data-more-left/right`） | 告诉用户「还有内容」 |

### 6.2 应该

- 末列只放 1 个文字按钮（Edit）+ 1 个图标按钮（Delete），宽 144px；Edit 带文字，因为它是主要行内动作；
- 末列有可见的列头「Actions」，读屏可读；
- 滚动提示通过 `scroll` + `ResizeObserver` + `rAF` 合并更新，**直接写 DOM 属性**，滚动时不触发 React 渲染。

## 7. 编辑形式：展开编辑区 vs 弹窗

两种形式共用同一个 `RecordEditor`，校验规则一致；由用户在「Display options → Edit style」选择，偏好被记住。

| 维度 | 展开编辑区（行内） | 弹窗 |
| --- | --- | --- |
| 上下文 | 保留在表格里，可对照周围行 | 暂时离开表格，专注编辑 |
| 并行编辑 | 可同时展开多行（各自独立保存 / 取消） | 一次一个 |
| 适合 | 字段少（≤ 7）、频繁微调 | 字段多、需要更多说明或更严肃的确认 |
| 无障碍 | Edit 按钮 `aria-expanded` + `aria-controls`；打开后焦点进入第一个字段 | 原生 `<dialog>`：焦点陷阱、Esc、背景 inert；`aria-haspopup="dialog"` |
| 关闭后 | 焦点回到该行的 Edit 按钮 | 同左 |

### 7.1 展开编辑区的实现要点

- 编辑行是紧跟数据行的 `<tr>`，单个 `<td colSpan=全部列>`；
- 因为表格可能比容器宽，编辑区内部使用 `position: sticky; left: 0; width: var(--sw)`，`--sw` 为滚动容器可视宽度（由 `useScrollAffordance` 维护）——横向滚动时编辑区始终停在可视范围内；
- 编辑区内字段使用 `grid-template-columns: repeat(auto-fit, minmax(min(260px,100%), 1fr))`，从 300px 到 1100px 都自适应；
- 窄容器（卡片模式）下，编辑区展开在卡片内部。

### 7.2 编辑器的行为规范

- 校验同整页表单（失焦即时校验 → 提交整体校验 → 首个错误聚焦 → 保留输入）；紧凑场景不显示顶部汇总，只保留行内错误；
- 服务端冲突（如 CNAME 与其他记录同名）映射回对应字段；
- 保存中显示进度并防止重复提交；成功后收起编辑区、通知、高亮该行；
- 提供「Open full form」链接，进入整页表单做复杂编辑。

### 7.3 未保存保护

- 编辑器通过回调向页面上报 `dirty`；页面维护一个脏集合；
- 有脏数据时：Cancel / 再次点击 Edit / 关闭弹窗 → 弹出「Discard unsaved changes?」（默认焦点在「Keep editing」）；
- 站内导航（侧边栏、面包屑、链接）同样被拦截；刷新 / 关闭标签页使用 `beforeunload`；
- 记录被删除时，编辑器卸载并清除其脏标记，**不得**留下「幽灵脏数据」把导航永远拦住。

## 8. 响应式

| 容器宽度 | 表现 |
| --- | --- |
| ≥ 700px | 表格；内容超宽时在 `.tbl` 内横向滚动，首末列粘性固定 |
| < 700px | 卡片列表：名称 / 类型 / 内容 / 代理 / TTL + 底部 Edit / Delete；勾选与展开编辑仍可用 |

- 切换由 `ResizeObserver` 驱动，只在**跨越阈值**时更新 state（宽度扫描 / 拖动窗口时零额外渲染）；
- 表格与卡片**只渲染一种**，避免同一条记录同时存在两个编辑器；
- 工具栏、分页区使用 `flex-wrap`，在 300px 下自动换行。

## 9. 分页

- 底部左侧显示「Showing 1–10 of 14」（筛选时附带「filtered from N」，`aria-live`）；右侧「Rows per page」+ 上一页 / 下一页；
- 搜索 / 筛选 / 每页数量变化 → 回到第 1 页；
- 从表单页保存返回并带 `?highlight=<id>`：自动翻到该行所在页，滚动到视口中央并闪烁高亮；
- 上一页 / 下一页在边界处禁用是可以接受的（这不是表单提交，用户不会因此困惑）。

## 10. 无障碍

- 表格有 `<caption>`（读屏可读，说明如何调整列宽）；`<th scope="col">`；排序列 `aria-sort`；
- 横向滚动容器：`tabindex="0"` + `role="region"` + 名称，键盘用户可用方向键滚动；
- 每个行内按钮都带对象名称：`aria-label="Edit A record www.myexample.com"`（可见文字 Edit 包含在名称开头，满足「标签包含在名称中」）；
- 分隔条：`role="separator"`、`aria-orientation="vertical"`、`aria-valuenow/min/max`、可聚焦；
- 勾选、批量条数量、分页计数使用 `aria-live="polite"`；
- 状态不只靠颜色（待处理记录使用警告图标 + 文字替代）。

## 11. 性能

| 点 | 做法 |
| --- | --- |
| 搜索输入 | `useDeferredValue` 延后过滤 |
| 列宽拖动 | 只改 DOM，松手才 `setState` |
| 横向滚动提示 | `scroll`（passive）+ `rAF` 合并，写 `dataset`，不进 React |
| 断点切换 | `ResizeObserver` + 仅布尔值变化才 `setState` |
| 行渲染 | 分页限制每次渲染的行数；`key` 使用稳定的记录 id（编辑器状态在排序 / 翻页时不被误复用） |
| 选择集合 | `Set`；连选在事件处理函数里计算，**不在 setState 更新函数里改 ref**（StrictMode 会二次调用更新函数） |

## 12. 避免（AVOID）

| 反模式 | 问题 |
| --- | --- |
| 把 Edit 放在可横向滚走的中间列 | 列一多就要先滚到最右才能编辑 |
| 粘性列没有背景 | 内容从下面透出，文字重叠 |
| 勾选后在表格上方插入批量条 | 表格整体下移，连选错位 |
| 整行点击即编辑 | 与勾选、选中文本冲突 |
| 拖动列宽时同步重渲染整张表 | 掉帧 |
| 列宽不设最小值 | 列被拖没 |
| 弹窗里再弹一个确认窗且焦点丢失 | 键盘用户迷路（本方案用原生 dialog 栈，关闭后焦点还原） |
| 排序 / 翻页后丢失正在编辑的内容 | 编辑器以记录 id 为 key，且有未保存保护 |

## 13. 检查清单（验收）

- [ ] 拖动任意数据列右缘可改变宽度；不能小于最小宽度；刷新后保持；双击恢复
- [ ] Tab 聚焦分隔条后，`←/→`、`Shift+←/→`、`Home/End`、`Enter` 可用
- [ ] 显示更多列让表格变宽后，横向滚动时最右侧 Edit / Delete 始终可见，首列勾选始终可见
- [ ] 粘性列边缘有滚动阴影；悬停 / 选中时粘性单元格背景与整行一致
- [ ] 表头排序三态；`aria-sort` 正确
- [ ] 表头复选框本页全选 / 半选；Shift 连选；「Select all N matching」可用
- [ ] 勾选后底部出现悬浮批量条，表格行没有位移
- [ ] 批量修改与删除均可撤销；不适用项有说明
- [ ] Edit：行内展开与弹窗两种形式均可用，切换后偏好被记住
- [ ] 编辑器：空 Name 提交 → 首错聚焦；CNAME 冲突 → 映射到 Name
- [ ] 有未保存编辑时，Cancel / 导航 / 刷新都有保护；删除正在编辑的记录后不会再拦截导航
- [ ] 容器 < 700px 为卡片列表且功能不缺失；300px 下无横向溢出（表格容器内滚动除外）

## 14. 在设计稿中验证

1. 打开「设计稿」→ 场景「DNS 记录」；
2. 拖动 Content 列右缘；再用 Tab 聚焦分隔条，按 `←/→`；
3. 打开 Display options，勾选 Modified、Comment，再把预览宽度拖到 900px：观察横向滚动与粘性的 Edit 列；
4. 点击 Edit：先清空 Name 保存；再改为 `www`、类型 CNAME 保存；
5. Display options → Edit style 切换为「Open in dialog」，重复一次；
6. 勾选一行，按住 Shift 点另一行；点击底部 Proxied / Delete，再用通知中的 Undo；
7. 并排对比模式：对照「传统方案」中无排序、无列宽调节、无批量的表格。
