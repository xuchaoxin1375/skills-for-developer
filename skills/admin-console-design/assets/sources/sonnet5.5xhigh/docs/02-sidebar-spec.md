# 02 · 侧边栏规范

> 适用范围：宽屏桌面端的应用级主导航。目标是 **常驻时稳定、折叠时省空间、悬停时自动展开、移开后自动收起**，并保证键盘与触屏用户同样可用。

对应实现：`src/dashboard/Sidebar.tsx`（状态机与组件）、`src/index.css` 中 `.sb*` 样式。

## 1. 结构与尺寸

```text
.sb-slot   ← 文档流中的占位槽：宽 56 或 240（sticky，100dvh），决定内容区可用宽度
 └─ nav.sb ← 绝对定位的真实侧边栏：宽 56 → 240（过渡），可覆盖内容
     ├─ .sb-head    Logo（高度与顶栏一致：56px，底部分隔线对齐顶栏）
     ├─ .sb-scroll  导航列表（纵向滚动，折叠态隐藏滚动条）
     └─ .sb-foot    设置 / 折叠切换按钮
```

| 项 | 取值 |
| --- | --- |
| 展开宽度 | 240px |
| 图标栏宽度 | 56px（8 + 40 + 8，图标恰好居中） |
| 导航项高度 | ≥ 40px；子项 ≥ 36px |
| 图标 | 18px，统一图标库（Lucide），描边风格 |
| 分隔 | 1px 边框色，上下 8px 间距 |

**必须**把「占位槽」与「视觉宽度」解耦：槽宽只由用户的固定偏好决定；视觉宽度由「固定偏好 ∪ 临时悬停展开」决定。

### 1.1 图标栏（折叠态）的视觉规范

| 规则 | 要求 | 实现 |
| --- | --- | --- |
| 图标严格居中 | 图标中心在 56px 带的正中（x = 28） | 侧边栏容器 padding 8 + 导航项 padding 8 + 图标 24 → 中心 = 28；**右侧分隔线用 `::after` 伪元素绘制，不占用盒模型宽度**，否则内容区只有 55px，图标会偏 0.5px |
| 文字不显示、不外露 | 折叠态不得出现任何文字片段、徽标、快捷键提示、箭头 | 标签宽度被压缩到 0（`flex:1; min-width:0; overflow:hidden`）+ `opacity: 0`；徽标 / 箭头 / 键帽使用 `.sb-fade`（透明且 `pointer-events:none`）；外层 `overflow: hidden` 兜底 |
| 读屏仍可读 | 文字只是视觉隐藏，名称仍在 DOM 中 | 不使用 `display:none` / `visibility:hidden` 隐藏标签 |
| 无滚动条 | 滚动条不得挤压 40px 的内容宽度 | 折叠态 `scrollbar-width: none` |
| 悬停背景 | 悬停 / 当前项背景是 40px 宽的圆角块，位于带内居中 | 与图标同一容器，无额外 margin |

### 1.2 手动控制（不只靠自动判断）

自动适配（按视口宽度切换布局档位）只是**默认值**，用户必须始终能手动控制：

| 布局档位 | 手动控制入口 | 效果 |
| --- | --- | --- |
| wide（≥ 1024） | 侧边栏底部「Collapse / Expand sidebar」按钮（图标 + 文字，折叠态仅图标）；`[` 快捷键；命令面板 | 固定展开 ⇄ 折叠，持久化 |
| medium（768 – 1023） | 同一个底部按钮 | 临时展开 ⇄ 收起（覆盖式） |
| narrow（< 768） | 顶栏汉堡按钮；抽屉内关闭按钮 | 打开 ⇄ 关闭抽屉 |

按钮的图标随状态变化（`PanelLeftClose` ⇄ `PanelLeftOpen`），可访问名称随状态变化（Collapse sidebar / Expand sidebar）；展示壳舞台的浮层也提供「侧边栏展开 / 折叠为图标栏」手动分段按钮，用于演示。

## 2. 状态模型

| 状态量 | 类型 | 含义 | 持久化 |
| --- | --- | --- | --- |
| `pinned` | `expanded` / `collapsed` | 用户选择的常驻状态 | 是（`localStorage`） |
| `hover` | boolean | 指针悬停意图成立 | 否 |
| `kbFocus` | boolean | 键盘焦点（`:focus-visible`）进入侧边栏 | 否 |
| `forced` | boolean | 触屏 / 中等宽度下的显式临时展开 | 否 |
| `suppressed` | boolean | 刚点击「收起」后，抑制再次悬停展开 | 否 |
| `drawer` | boolean | 窄屏抽屉是否打开 | 否 |

派生量（`layout` 为 `wide` / `medium` / `narrow`）：

```text
rail     = layout == medium  ||  (layout == wide && pinned == collapsed)
peek     = rail && ((!suppressed && (hover || kbFocus)) || forced)
expanded = wide   ? (pinned == expanded || peek)
         : medium ? peek
         : false
slotWidth= wide ? (pinned == expanded ? 240 : 56) : medium ? 56 : 0
overlay  = expanded && slotWidth < 240        // 需要阴影以区分层级
```

## 3. 响应式行为矩阵

| 布局档位 | 视口宽度 | 常驻形态 | 展开方式 | 切换按钮 |
| --- | --- | --- | --- | --- |
| wide | ≥ 1024px | 展开 240 或图标栏 56（用户选择，被记住） | 折叠态：悬停 / 键盘聚焦 → 覆盖式展开 | 固定 / 取消固定 |
| medium | 768 – 1023px | 图标栏 56 | 悬停 / 聚焦 / 按钮 → 覆盖式展开；点击外部或 Esc 关闭 | 临时展开 |
| narrow | < 768px | 无（隐藏） | 顶栏汉堡按钮 → 模态抽屉 | 打开 / 关闭抽屉 |

## 4. 悬停展开与自动收起

### 4.1 时序

```text
指针进入 ──120ms──▶ hover=true  ──▶ 宽度 56→240（220ms）
指针离开 ──250ms──▶ hover=false ──▶ 宽度 240→56（220ms）
```

- **进入延迟 120ms**：过滤鼠标划过屏幕边缘的误触，避免「一碰就弹」。
- **离开延迟 250ms**：容忍鼠标短暂滑出、抖动或穿过边界；在延迟内重新进入则取消收起。
- 进入 / 离开事件使用 `pointerenter` / `pointerleave`，并**忽略 `pointerType === "touch"`**（触屏没有悬停）。

### 4.2 覆盖而非推挤

折叠态悬停展开时，侧边栏覆盖在内容上方，`z-index` 高于顶栏，并加上 `shadow-2` 区分层级；**内容区宽度不变**，不会发生重排。

### 4.3 抑制规则（防「点了收起又弹出来」）

用户点击「Collapse sidebar」时指针仍停在侧边栏上。若不处理，指针仍处于 hover 状态，侧边栏会立刻再次展开。规则：

1. 点击收起：`hover=false`、`kbFocus=false`，并在指针仍位于侧边栏内时设置 `suppressed=true`；
2. 指针**离开一次**侧边栏后，`suppressed` 复位；
3. 若收起由键盘或快捷键触发（指针不在侧边栏内），**不得**设置 `suppressed`，否则之后将无法再悬停展开。

### 4.4 键盘等价

- Tab 进入侧边栏且焦点可见（`:focus-visible`）时视同悬停，侧边栏展开；焦点移出后收起。
- 鼠标点击产生的焦点（非 `:focus-visible`）**不应**触发展开，避免点击后卡在展开态。

### 4.5 触屏与中等宽度

- 触屏没有悬停：点击图标栏上的分组图标会临时展开（`forced`），点击外部、按 Esc 或导航后关闭。
- 中等宽度的切换按钮切换 `forced`。

## 5. 动画规范

| 属性 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| 侧边栏宽度 | 220ms | `cubic-bezier(.2,.8,.2,1)` | 先快后缓；仅动画 `width` 与 `box-shadow` |
| 占位槽宽度（固定切换） | 220ms | 同上 | 与侧边栏同步，内容区平滑让位 |
| 标签 / 徽标 / 箭头 | 160ms 透明度 + 220ms 位移 | ease / 同上 | 展开时延迟 50ms 出现，折叠时立即淡出，避免文字被截断闪烁 |
| 分组子菜单 | 220ms | 同上 | 使用 `grid-template-rows: 0fr → 1fr`，无需测量高度 |
| 阴影 | 220ms | 同上 | 覆盖态才出现 |

要点：

- 侧边栏内部宽度**随外层流式变化**（`width: 100%`），文字用 `overflow: hidden; white-space: nowrap` 裁切；**不要**给内容写死 240px，否则折叠态的悬停背景会超出可视区。
- 子菜单折叠使用 `visibility: hidden`（带延迟过渡）把收起的链接移出 Tab 顺序。
- **必须**尊重 `prefers-reduced-motion: reduce`：将动画缩短到近似 0。
- 只对 `width / opacity / transform / grid-template-rows / box-shadow` 做动画，**避免** `height: auto` 或 `left/top`。

## 6. 导航项规则

| 类型 | 元素 | 规则 |
| --- | --- | --- |
| 链接项 | `<a>`（路由 Link） | 当前页 `aria-current="page"`，背景加深 + 字重 600 |
| 分组项 | `<button aria-expanded aria-controls>` | 展开时显示子列表；折叠态点击先展开侧边栏 |
| 子项 | 缩进 + 左侧竖线 | 当前子项高亮；分组仅在折叠态下因子项激活而高亮图标 |
| 命令项 | `<button>` | 如「Quick search」，不是路由 |
| 徽标 | `badge` | 如 New，折叠态淡出 |

分组默认只展开包含当前页的一组；路由变化时自动展开包含当前页的分组。

## 7. 键盘与无障碍

| 操作 | 行为 |
| --- | --- |
| `[` | 切换侧边栏固定状态（在输入控件中不触发；窄屏无效） |
| `Ctrl/⌘ + K` | 打开快速搜索 / 命令面板 |
| `Tab` | 依次聚焦导航项；折叠态聚焦时自动展开 |
| `Esc` | 关闭临时展开 / 抽屉 |
| `Enter / Space` | 激活链接或分组 |

必须满足：

- 容器使用 `<nav aria-label="Primary">`；切换按钮的可访问名称随状态变化（Collapse sidebar / Expand sidebar）并提供 `aria-keyshortcuts`——**不要同时**使用会变化的名称与 `aria-expanded`，否则读屏会重复播报；分组按钮使用 `aria-expanded` + `aria-controls`；
- 图标按钮必须有可访问名称；折叠态的文字只是视觉隐藏，仍在 DOM 中，读屏可读；
- 窄屏抽屉使用原生 `<dialog>` + `showModal()`：自带焦点陷阱、Esc、背景 inert，关闭后焦点回到汉堡按钮；
- 提供「跳到主内容」跳过链接（聚焦时可见）；
- 路由切换后把焦点移到主内容区，并滚动到顶部。

## 8. 实现要点与常见坑

1. **槽宽与视觉宽度解耦**：否则悬停展开会推动内容。
2. **hover 只在 rail 状态记录**：固定展开时忽略，避免之后折叠瞬间误弹。
3. **toggle 后清理计时器与状态**：进入 / 离开计时器必须在卸载与切换时清除。
4. **`:focus-visible` 判断**：使用 `e.target.matches(":focus-visible")`。
5. **指针类型**：`pointerType === "touch"` 直接返回。
6. **滚动**：导航列表单独滚动并 `overscroll-behavior: contain`，避免滚动穿透到页面。
7. **折叠态隐藏滚动条**，否则 40px 内容宽度会被滚动条挤压。
8. **模态层与悬停**：打开命令面板时指针离开侧边栏属正常，侧边栏随之收起。
9. **持久化失败**（隐私模式）时静默降级为内存状态。
