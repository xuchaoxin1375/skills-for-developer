# 04 · 响应式与无障碍

> 目标：在 **300px 到 1920px** 的任意宽度下，页面级无横向滚动、元素不挤压、不溢出；满足无障碍底线。

## 1. 验证宽度

| 宽度 | 代表设备 | 布局档位 | 必须验证的内容 |
| --- | --- | --- | --- |
| 300 / 320 | 极窄窗口、折叠屏外屏、400% 缩放 | narrow | 320px 可回流；无横向滚动；按钮不重叠 |
| 390 | 主流手机 | narrow | 抽屉、卡片列表、单列表单、44px 控件 |
| 768 | 平板竖屏 | medium | 图标栏 + 临时展开；表格列收敛 |
| 1024 | 小笔记本 | wide（临界） | 固定展开 / 折叠切换；内容区宽度变化 |
| 1440 | 桌面 | wide | 完整表格；帮助侧栏出现 |
| 1920 | 宽屏 | wide | 内容 `max-width: 1440` 居中，不无限拉伸 |

设计稿提供宽度滑条、预设与「宽度扫描」。**至少**在 390 / 768 / 1440 三个宽度验证，并用 300 做极端测试。

## 2. 断点策略：外壳用媒体查询，内容用容器查询

| 层 | 使用 | 原因 | 取值 |
| --- | --- | --- | --- |
| 外壳（侧边栏、顶栏） | 媒体查询 / `matchMedia` | 取决于设备与窗口 | 1024 / 768（及 640、480 的细节） |
| 内容组件（表格、表单、设置页） | **容器查询** | 侧边栏展开 / 折叠会改变内容区宽度，视口断点无法覆盖 | 见下表 |

| 组件 | 容器宽度 | 行为 |
| --- | --- | --- |
| DNS 记录表 | ≥ 700px | 表格；列宽可调，总宽超出时在表格容器内横向滚动，首列勾选 / 末列操作粘性固定（见 08） |
| | < 700px | 整体切换为卡片列表（由 `ResizeObserver` 判断，仅渲染一种形态） |
| 表单页 | ≥ 1040px | 出现右侧帮助侧栏 |
| 设置页 | ≥ 720px | 行内左说明右控件；否则堆叠 |

**应该**：宽表格优先保证**关键操作常驻**（勾选、编辑用粘性列固定），其余列在容器内横向滚动并允许用户调列宽 / 隐藏次要列；容器过窄时改用卡片，而不是整体等比缩小。

## 3. 防溢出清单

| 问题 | 对策 |
| --- | --- |
| Flex / Grid 子项撑破容器 | 给可收缩子项加 `min-width: 0`（Tailwind：`min-w-0`） |
| 长域名 / 长文本 | `overflow-wrap: anywhere`（单元格）、`break-words`（标题） |
| 表格过宽 | 表格放入自己的 `overflow-x: auto` 容器，容器可聚焦并有标签；页面本身不滚动；操作列粘性固定在右侧 |
| 按钮并排放不下 | `flex-wrap`；窄屏下次要文字改为 `sr-only`，只保留图标（保持可访问名称） |
| 浮层超出视口 | 打开时测量并夹取到视口内；< 640px 变为底部面板 |
| 固定宽度 | 避免 `width: 480px`；使用 `min(480px, calc(100vw - 16px))` |
| 图片 / 媒体 | `max-width: 100%` |
| 兜底 | 应用根节点 `overflow-x: clip`（不破坏 sticky），但**不得**用它掩盖真实溢出 |

## 4. 极窄窗口（≤ 320px）处理

1. 顶栏：隐藏次要入口（< 640 隐藏 Ask AI；< 480 隐藏 Support 与套餐徽标），域名使用省略号；
2. 页头：标题与操作区 `flex-wrap`，操作区自动换到下一行；
3. 工具栏：搜索框独占一行，按钮自动换行；
4. 表单：字段 100% 宽；操作栏按钮 `flex: 1 1 120px`；
5. 对话框：`width: min(480px, 100vw − 16px)`，内部内边距不变；
6. 抽屉：`min(288px, 100vw − 48px)`，保证右侧留出遮罩可点区域；
7. 文案：不依赖单行显示；英文长单词可断行。

## 5. 触控目标

| 场景 | 最小尺寸 |
| --- | --- |
| 桌面指针设备 | 24 × 24px（WCAG 2.2 AA），默认控件 36px |
| 触屏或窄屏（< 640px） | 44 × 44px（`--control-h: 44px`，由媒体查询 `pointer: coarse` 与宽度共同触发） |
| 行内小图标按钮 | 至少 24px，必要时通过 `.hit` 扩大命中区 |

相邻目标之间保持 ≥ 4px 间距，避免误触。

## 6. 无障碍底线

### 6.1 键盘

- 所有功能**全键盘可达**；不使用 `div onClick` 冒充按钮（列表框选项是 ARIA 模式的一部分，且有键盘等价）；
- Tab 顺序与视觉顺序一致；
- 模态层：焦点陷阱 + Esc 关闭 + 关闭后焦点还原；非模态浮层：Esc 关闭 + 焦点还给触发按钮；
- 仅悬停才出现的内容**不得**是唯一入口（提示在聚焦时同样出现，Esc 可关闭）。

### 6.2 焦点

- 全局 `:focus-visible { outline: 2px solid var(--focus); outline-offset: 2px; }`；
- **不得** `outline: none` 而无替代；焦点环对比度 ≥ 3:1；
- 粘性栏不能遮挡聚焦元素：设置 `scroll-padding-top / bottom`。

### 6.3 对比度

| 内容 | 要求 | 设计稿取值（浅色） |
| --- | --- | --- |
| 正文 / 标签 | ≥ 4.5:1 | `#1b1b1b` on `#ffffff` ≈ 17:1 |
| 次要文字 | ≥ 4.5:1 | `#5b5b5b` on `#ffffff` ≈ 6.9:1 |
| 输入框边框、图标等非文字 UI | ≥ 3:1 | `#8c8c8c` on `#ffffff` ≈ 3.4:1 |
| 主按钮文字 | ≥ 4.5:1 | `#ffffff` on `#0051c3` ≈ 7.1:1 |

深色主题使用独立的令牌（见 05），而不是简单反色。

### 6.4 文字与行高

- 正文行高 ≥ 1.6（中英文）；标题 ≥ 1.3；
- 字号不低于 12px；输入框在窄屏为 16px；
- **不得**禁用缩放；支持 200% – 400% 缩放时回流到单列。

### 6.5 语义与地标

| 区域 | 元素 |
| --- | --- |
| 跳转 | 首个可聚焦元素为「Skip to main content」 |
| 导航 | `<nav aria-label>`；面包屑 `<nav aria-label="Breadcrumb">` + `<ol>` |
| 主内容 | `<main id="main" tabindex="-1">`，路由切换后聚焦 |
| 页头 | 每页一个 `<h1>`；分区 `<h2>`；对话框标题 `<h2>` |
| 表格 | 真实 `<table>`、`<th>`；排序列使用 `aria-sort`；容器 `role="region"` 且可聚焦 |
| 表单 | `<label for>`、`<fieldset>/<legend>`、`aria-describedby`、`aria-invalid` |
| 动态提示 | 常驻 `aria-live="polite"` 区域（Toast）；行内错误 `role="alert"` |
| 进度 | `role="progressbar"` + 文字说明 |

### 6.6 动效与主题

- 尊重 `prefers-reduced-motion`；
- 支持 `prefers-color-scheme`；主题提供「跟随系统（默认）/ 浅色 / 深色」，并在首屏前应用，避免闪烁；
- 状态不只靠颜色：警告 / 错误同时有图标与文字。

## 7. 性能与稳定性

| 项 | 做法 |
| --- | --- |
| 搜索输入 | `useDeferredValue` 延后过滤，输入保持流畅 |
| 事件监听 | 仅在需要时绑定（浮层打开时绑定外部点击 / Esc），卸载时清理 |
| 计时器 | 悬停进入 / 离开计时器在卸载时清除 |
| 宽度监听 | 使用 `ResizeObserver` / `matchMedia`，避免 `scroll` 中读取布局；窗口 `resize` 用 `requestAnimationFrame` 节流 |
| 目录高亮 | `IntersectionObserver` 代替滚动监听 |
| 动画属性 | 仅 `width / opacity / transform / grid-template-rows` |
| 宽度扫描 | 在 `requestAnimationFrame` 中推进，状态只在整数像素变化时更新 |

## 8. 测试方法

1. **手工**：设计稿宽度扫描 + 三个固定宽度；键盘走一遍；打开系统「减少动态效果」；
2. **缩放**：浏览器缩放到 200% / 400%，确认 320px 等效宽度回流；
3. **自动化**（可选）：使用 axe-core / Lighthouse 检查对比度、名称、地标；使用 Playwright 在 300 / 390 / 768 / 1440 截图并断言 `document.documentElement.scrollWidth <= innerWidth`；
4. **屏幕阅读器抽查**：NVDA / VoiceOver 走通「添加记录」流程，确认错误汇总与首错聚焦被播报。

## 9. 检查清单

- [ ] 300 / 390 / 768 / 1440 四个宽度下 `scrollWidth ≤ innerWidth`
- [ ] 无元素重叠、文字截断（除有意的省略号）
- [ ] 所有交互元素 ≥ 24px，触屏 / 窄屏 ≥ 44px
- [ ] 全键盘可完成主要流程，焦点环始终可见
- [ ] 正文对比度 ≥ 4.5:1，非文字 ≥ 3:1（两种主题）
- [ ] 200% 缩放不丢失功能
- [ ] 开启「减少动态效果」后无明显动画
