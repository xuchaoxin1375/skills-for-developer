# 05 · 设计令牌

> 原则：**先写令牌，再写样式**。组件只引用令牌，不出现魔法数字。令牌定义在 `src/index.css`，通过 CSS 变量提供给 Tailwind（`@theme inline`）与自定义组件类。

## 1. 约束总览

| 维度 | 上限 | 取值 |
| --- | --- | --- |
| 字号 | ≤ 7 档 | 12 / 13（等宽）/ 14 / 16 / 20 / 24 / 32 |
| 圆角 | ≤ 4 档 | 4 / 8 / 12 / full |
| 阴影 | ≤ 3 级 | shadow-1 / shadow-2 / shadow-3 |
| 间距 | 固定刻度 | 4 / 8 / 12 / 16 / 24 / 32 / 48 |
| 图标库 | 1 套 | Lucide |
| 行高 | 正文 ≥ 1.6 | 标题 ≥ 1.3 |

## 2. 颜色

采用「语义令牌」命名，不在组件中直接写色值。

| 令牌 | 用途 | 浅色 | 深色 |
| --- | --- | --- | --- |
| `--bg` | 页面背景 | `#ffffff` | `#141414` |
| `--bg-subtle` | 表头、弱背景 | `#f6f6f6` | `#1c1c1c` |
| `--bg-hover` | 悬停背景 | `#f0f0f0` | `#262626` |
| `--bg-active` | 选中 / 当前项 | `#e8e8e8` | `#2e2e2e` |
| `--surface` | 卡片、浮层 | `#ffffff` | `#1a1a1a` |
| `--canvas` | 展示壳舞台背景 | `#e6e8eb` | `#0d0d0d` |
| `--border` | 装饰性分隔线 | `#e2e2e2` | `#303030` |
| `--border-strong` | 次要按钮边框 | `#bdbdbd` | `#4d4d4d` |
| `--border-input` | 输入框边框（≥ 3:1） | `#8c8c8c` | `#7d7d7d` |
| `--text` | 正文 | `#1b1b1b` | `#ededed` |
| `--text-muted` | 次要文字 | `#5b5b5b` | `#a6a6a6` |
| `--primary` | 主按钮背景 | `#0051c3` | `#2f6fe0` |
| `--primary-hover` | 主按钮悬停 | `#003f9a` | `#2559bd` |
| `--primary-soft` | 选中、信息背景 | `#e8f0fc` | `#1b2a45` |
| `--link` | 链接 / 强调文字 | `#0051c3` | `#7fb0ff` |
| `--danger` / `--danger-solid` | 错误文字 / 危险按钮 | `#b3261e` / `#c62b21` | `#ff8f85` / `#d4352b` |
| `--warn-bg / -border / -fg` | 警示横幅 | `#fff6e0` / `#f0d08a` / `#7a4300` | `#35280d` / `#6b5016` / `#ffd58a` |
| `--ok` | 成功 | `#1a7f37` | `#4cc26b` |
| `--brand` | 品牌橙（Logo、代理图标） | `#f6821f` | `#f6821f` |
| `--focus` | 焦点环 | `#0051c3` | `#7fb0ff` |
| `--scrim` | 遮罩 | `rgb(15 15 15 / .45)` | `rgb(0 0 0 / .6)` |

要点：

- 主按钮背景与链接文字色分开（深色主题下按钮需要更深的蓝以保证白字对比度，而链接需要更浅的蓝）；
- 语义色（警示 / 错误 / 成功）必须配合图标或文字，不得单独表达含义。

## 3. 字体与字号

| 令牌 | 字号 | 行高 | 用途 |
| --- | --- | --- | --- |
| `text-xs` | 12px | 1.6 | 说明、徽标、快捷键、表单提示 |
| mono | 13px | 1.6 | 代码、DNS 内容、预览 |
| `text-sm` | 14px | 1.6 | **默认正文**、表格、按钮 |
| `text-base` | 16px | 1.6 | 小节标题、窄屏输入框、文档正文 |
| `text-xl` | 20px | 1.4 | 页面标题（窄屏）、对话框标题、文档三级标题 |
| `text-2xl` | 24px | 1.33 | 页面标题（≥ 640px）、指标数值 |
| `text-3xl` | 32px | 1.25 | 文档一级标题 |

字体栈：`Inter, system-ui, -apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`；等宽：`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`。

字重：正文 400；标签、按钮、表头 500 – 600；标题 600 – 700。

## 4. 间距

| 刻度 | 像素 | Tailwind | 典型用途 |
| --- | --- | --- | --- |
| 1 | 4px | `1` | 图标与文字的最小间隙、标签与提示 |
| 2 | 8px | `2` | 紧凑元素间距、浮层内小间隙 |
| 3 | 12px | `3` | 控件内边距、字段内元素间距 |
| 4 | 16px | `4` | 字段间距、卡片紧凑内边距、窄屏页面边距 |
| 6 | 24px | `6` | 分组间距、卡片内边距、页面上边距 |
| 8 | 32px | `8` | 页面左右边距（≥ 768px） |
| 12 | 48px | `12` | 页面底部、大分区间距 |

## 5. 尺寸

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| `--control-h` | 36px（窄屏 / 粗指针 44px） | 按钮、输入框、选择框最小高度 |
| `--topbar-h` | 56px | 顶栏与侧边栏头部高度（对齐） |
| `--sb-rail` | 56px | 侧边栏图标栏宽度 |
| `--sb-w` | 240px | 侧边栏展开宽度 |
| 页面最大宽度 | 1440px | 居中 |
| 表单卡片最大宽度 | 720px | 单列表单（向导 768px） |
| 设置页最大宽度 | 896px | 行布局的设置页 |

## 6. 圆角与阴影

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--r-sm` | 4px | 键帽、行内标签、小按钮内部元素 |
| `--r-md` | 8px | 按钮、输入框、列表项、横幅 |
| `--r-lg` | 12px | 卡片、浮层、对话框 |
| full | 999px | 徽标、开关、药丸 |

| 阴影 | 值 | 用途 |
| --- | --- | --- |
| `--shadow-1` | `0 1px 2px rgb(0 0 0 / .08)` | 分段控件选中项 |
| `--shadow-2` | `0 6px 24px rgb(0 0 0 / .14)` | 浮层、菜单、侧边栏悬停展开、Toast |
| `--shadow-3` | `0 20px 60px rgb(0 0 0 / .28)` | 模态对话框 |

**避免**卡片套卡片：同一视觉层级只用一层容器；分区使用分隔线与间距。

## 7. 层级（z-index）

| 层 | z-index | 说明 |
| --- | --- | --- |
| 粘性操作栏 | 15 | 表单底部 |
| 顶栏 | 20 | 页面内最高的常驻层 |
| 浮层（Popover） | 30 | 筛选、显示选项、账户菜单 |
| 侧边栏槽 | 40 | 高于顶栏，使悬停展开覆盖顶栏左侧 |
| 提示（Tooltip） | 70 | 固定定位 |
| Toast | 80 | 通知 |
| 跳过链接 | 100 | 聚焦时最上层 |
| 模态 / 抽屉 | 顶层（`<dialog>` top layer） | 不受 z-index 影响 |

## 8. 动效

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ease` | `cubic-bezier(.2,.8,.2,1)` | 侧边栏、抽屉、分组展开 |
| 微交互 | 120ms | 悬停背景、边框 |
| 展开 / 收起 | 220ms | 宽度、网格行高 |
| 对话框进入 / 退出 | 180ms / 140ms | 位移 8px + 透明度 |
| Toast 停留 | 5s（带撤销 8s） | 可手动关闭 |
| 悬停意图 | 进入 120ms / 离开 250ms | 见 02 |

`prefers-reduced-motion: reduce` 时所有时长缩短至约 0。
