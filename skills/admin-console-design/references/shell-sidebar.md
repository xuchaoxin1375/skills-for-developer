# 外壳与侧边栏

默认采用 fable 的顶栏、搜索/返回、导航分组、底部控制与页面节奏。当前归档已分离hoverPeek/focusPeek，修复主图标横移、Esc焦点丢失与分组节点替换，并保护按住指针时的目标和点击语义；其实现仍不等同于下述完整模型。需要完整输入策略或临时展开时参考 sonnet，继续核对[已知缺口与验证范围](builds-comparison.md)。

若实现依据来自 UI 草稿，先按[草稿到模板](cf-customization-guide.md#草稿到模板)映射到本页的完整外壳单元；页脚控制、peek、Esc、快捷键与槽宽/点击稳定不因草稿未画而省略。

## Vue 3 同栈候选移植

[Vue 3 外壳候选](../assets/sources/vue3-cloudflare-shell/README.md) 是本节参数和交互的 Vue 3 落地样例：264/56、Rail hover／focus peek、手动收起抑制、Esc 回主内容、1024 以下抽屉与焦点陷阱、容器查询收纳和 reduced-motion。它只复刻布局与交互，示例配色为宿主深青／中性令牌，不是 Cloudflare 官方色板；不替代本节状态模型，也不把命令面板、账号／主题／资源切换器带入目标。

## 结构与参数

`Topbar + SidebarSlot(占位) + SidebarPanel(视觉) + main(min-width:0) + 可选footer`。

文档滚动为默认，导航内部可滚动；工作台允许固定高度，但明确滚动所有者。fable 原值为展开264/Rail56/顶栏56/max1440 居中；sonnet 展开240。沿用基底，按文本和挂载容器调整，不强制收敛。

Rail 图标居中与展开后水平位置稳定是两项检查；纵向允许受控错位，按“覆盖与点击稳定”的规则处理。把内边距、边框、图标盒全部计入坐标；临时展开不要再次横移可点击图标。顶栏保留当前资源上下文与全局入口；资源切换器仅多资源业务需要时加入。多账号/域名切换器先按输入过滤再截断渲染，并提示继续输入；不一次挂上千项。

顶栏品牌槽宽度与侧栏 slot 同步（展开/收起），品牌图标与 Rail 图标同中心，品牌文字只在展开态出现；品牌槽右边界与侧栏边框连续，不再额外加品牌/面包屑竖线。面包屑按内容左内边距起排，右侧服务状态按内容右内边距对齐；状态胶囊给稳定最小宽度，轮询文案（读取中／正常／异常）不能改变顶栏布局。顶栏面包屑只承担父级导航：根列表页可只保留品牌，当前页标题交给工作票头；详情页列父级和当前对象，不用页头 eyebrow 重复同一层级。

## 状态模型（参考 sonnet，参数用所选模板）

```text
pinned: expanded | collapsed                // 固定偏好，可持久化
hover, kbFocus, forced, suppressed: boolean // 临时状态
layout: wide | medium | narrow
rail        = medium || (wide && pinned == collapsed)
peek        = rail && ((!suppressed && (hover || kbFocus)) || forced)
visualOpen  = wide ? (pinned == expanded || peek) : medium ? peek : false
slotWidth   = wide ? (pinned == expanded ? expandedWidth : railWidth)
            : medium ? railWidth : 0
visualWidth = visualOpen ? expandedWidth : railWidth
overlay     = visualOpen && slotWidth < expandedWidth
drawer      = narrow && drawerOpen
```

**槽宽不使用 visualOpen 或 peek**。固定切换可以改变槽宽，临时展开不可以。模型不要求同名变量或强换状态库。

- 意图延迟与宽度过渡分别配置：fable 进/出110/220ms、宽度280ms；sonnet120/250ms、宽度220ms。
- 进入/离开清相反计时器；卸载、路由/布局切换和手动控制清过期事件。
- 点收起且指针仍在导航时抑制 hover，离开一次恢复；键盘收起且指针在外不能留下永久抑制。
- 键盘进入可展开；焦点仍在导航时不能因鼠标离开藏起。鼠标点击收起按钮的焦点不能反向重开。Esc 回到稳定入口，避免直接 blur 丢失焦点。
- Rail 中点击导航/任务后不要立即收起：保留 hover peek 到指针离开，再回 Rail；仅 pinned 保持展开。鼠标点击可释放 focus peek，但不能取消 hover peek；键盘激活保留焦点展开，焦点离开后再收起。
- 触屏不能依赖 hover：中等布局有临时展开按钮，外部点击/Esc/导航后关；窄屏有汉堡与抽屉关闭入口。
- 默认可用768/1024两个断点；fable 平板行为受存储偏好影响，不是已实现的强制Rail。CSS、JS、测试采用同单位/边界，检查767/768和1023/1024，无需特殊小数rem。

## 折叠/展开的动效编排（CF 实况）

2026-11-25 登录态取样（Edge 157，1440×900，light）：rail 56px（含 1px 边框实测 57）、展开 260px。容器宽与外壳 grid track 同为 **250ms / `cubic-bezier(0.77, 0, 0.175, 1)`**，标签、品牌、内边距用 **250ms / `cubic-bezier(0.4, 0, 0.2, 1)`**。

| 层 | 属性 | 折叠 ↔ 展开 |
| --- | --- | --- |
| 外壳与面板 | `grid-template-columns`、`width` | 56 ↔ 260；固定开关推开内容，peek 槽位不动、面板只覆盖 |
| 标签 | `transform` + 容器裁切 | `translateX(-4px) ↔ 0`；宽度由容器让出，透明度始终为 1 |
| 分组标题 | `grid-template-rows` | `0fr ↔ 1fr`，外层 `overflow: hidden`；分隔线用颜色/透明度过渡 |
| 品牌 | `scale` | `0.833 ↔ 1`，`origin-left`；文字随槽宽裁切 |
| 内边距 | `padding` / `margin` | 11 ↔ 14/16px，与上面同时长 |

- 宽度过渡只让一个布局属性承担（外壳 track 或面板 `width`），其余元素跟随同一时长。不要 aside width、main margin、顶栏品牌槽各写一套；无法合并时至少共用 duration/easing，并实测三者在同一帧到位。CF 在外壳 grid 上常驻 `will-change: grid-template-columns`；自建时按 `web-animation-guide` 的临时提示规则处理，不照抄常驻。
- 大位移不要用 `ease-out`：`cubic-bezier(0, 0, 0.2, 1)` 在 25% 时间已走约 58% 位移，观感是“先弹一下再爬”。上面的 S 曲线在 25%/50%/75% 时间约走 5%/60%/96%，起步慢、落点软，适合 200px 以上的侧栏/面板。
- 标签不要用 `opacity` 抢先出现：透明度会在面板还没让出空间时完成，文字先亮再被裁。用裁切 + 4px 位移，并让标签盒随容器收缩；要做过渡就不要 `display:none`，会瞬切。
- 分组标题不要条件挂载：会让下方导航在动画第一帧整段跳动。保留节点：要么用 `grid-template-rows: 0fr↔1fr` 收缩行高（允许受控纵向错位），要么保留固定标题槽只切换标题与分隔线；两种都把行高与宽度放在同一时间轴，分隔线单独过渡。
- 减弱动效时面板与 track 都要关。CF 只给 panel 关了 `transition-none`、外层 grid 仍保留 250ms（90ms 冻结时面板已 260、grid 才 87），属于实现缺口，不要照抄；统一令牌或 `motion-reduce:transition-none` 覆盖两层。
- 验收：先在 Rendering 面板确认 `prefers-reduced-motion` 与应用全局覆盖，别在瞬切上评判；用 DevTools Animations 以 10% 慢放看标签/分组/品牌是否同帧，再用 WAAPI 在 25%/50%/75% 时间点 `pause()` 并设 `currentTime` 冻结画面，检查标签无残影、分组行连续、主区与面板同帧到位；最后跑 reduce、正常速度、快速反复切换与中途反向。流程见 [动画排查](../../web-animation-guide/references/inspecting-motion.md)。

## 标签、分组与可访问名称

- Rail 主入口保留 Tab 和名称，可用 aria-label 或视觉隐藏标签；视觉隐藏标签时同时提供 title/tooltip，让鼠标用户也能发现入口。opacity:0 通常仍在可访问树；visibility:hidden/display:none 会隐藏名称来源，需补独立名称。不能声称“在DOM中就仍可读”。
- 参考稿裁剪掉非本业务导航后，若只剩少数入口，重估 Rail 默认态/密度：默认展开、补充真实入口或与用户确认，不用死链填充；入口少时保持紧凑顶部排列，空白留在导航与底部控制之间，不用拉大组间距或空分组填充高度。
- 第一段主导航可以不设分组标题：直接从顶部开始，用顶部留白或分隔线建立节奏，不要为了和后续分组对齐而补空标题槽。没有标题时，图标本身承担识别，展开态再按需显示后续分组标题。
- **只有两个及以上分组、且收起态确实隐藏了分组标题时，才用分隔线替代标题槽**；单一分组不画分隔线，也不保留空标题槽或分组标题，直接紧凑排列入口。需要分隔时，隐藏分组标题，优先保留固定高度的标题槽，在槽内画 1px 分隔线；线宽约为 Rail 宽的 40%–50%，左右留白大于行内边距，上下留白相等。展开/peek 在同一槽位显示标题时图标不位移；若保留槽位会留下无意义空白或压缩首段密度，可改为展开态让标题占位并允许受控的纵向错位（见“覆盖与点击稳定”），不要为对齐强行保留标题或空槽。不要再叠加分组 margin，否则会变成“标题高度 + margin”的双重留白。组间空白因此读作刻意分组，而不是布局漏空。
- 收起子项移出Tab，可用hidden/inert/visibility/tabIndex=-1；不要出现不可见焦点。隐藏方式按动画需要选，不全面禁display:none。
- 链接用aria-current=page，分组按钮用aria-expanded/controls；避免Rail是链接、peek突然变按钮而打断点击。当前fable分组统一为按钮：Rail点击首个子页、展开态切换手风琴，失去链接的新标签页能力；需要原生链接时分开导航与展开动作，或采用一致的分组展开契约。
- 默认展开当前路径组；子菜单展开会移动后续行，不能把所有offsetTop全等当普遍要求。

## 导航层级与路由

- 多个同级工具、设置页或低频能力需要长期并存、可直达时，优先用侧栏分组承载，每个子项对应独立路由；不要把它们塞进单页的页内 tab、锚点或长滚动分区。页内 tab 只用于同一对象的并列视图、短流程步骤，或切换频繁且不要求深链的场景。
- 需要直达、刷新、分享、当前项高亮和前进/后退时，用路径路由（`/section/page`）；hash 路由（`#/section/page`）只作为无法配置 SPA 回退时的降级。服务端需把未知路径回退到 SPA 入口；旧 hash 链接做一次迁移或重定向。
- 参考稿的 hash 路由是演示实现，不当作目标默认；目标项目沿用自身框架，但有 SPA 回退时优先路径路由。独立路由页只挂载当前页，切页会卸载未提交输入，需要保留的业务输入另做草稿或离开保护。

## 覆盖与点击稳定

分别检查 **页面稳定**（main left/width不变）和 **目标稳定**（mousedown与mouseup仍是同一按钮/链接）。只验第一层不能声称全部零位移。

- 固定图标列、单行导航标签、只扩文本区；长说明可折行，但不要在一次指针动作中改变点击位置或重挂载目标。fable在按住主键时延后peek，松开后先完成click再恢复展开；同时验证动作结果（如实际路由），不能只记录click事件。
- **零位移是默认偏好，不是绝对验收项**：横向位置必须稳定；纵向允许受控错位，但只在展开/收起触发后发生，按下指针期间不移动目标，展开完成后不再持续位移。允许错位时，必须验证悬停展开后点击仍命中预期项；不能把“图标完全对齐”当作保留无意义标题槽或压缩信息密度的理由。悬停 peek 也会让分组标题改变行高时，目标在按下之前就移走；要求点击效率时，让标题槽在 rail 也保持展开高度（固定槽，接受 rail 变疏），只在动画结束后验证命中不够。
- 面板脱离Grid/Flex流，槽仍占原轨；需要时指定main轨道。grid-column:2仅适用于对应两列结构。
- 定位可相对稳定祖先，必要时读取rect；不是所有peek都必须fixed、捕获rect或滚动即关闭。
- 用computed style检查显隐优先级，避免堆选择器。层级看实际stacking context和侧栏起点；原生模态dialog在top layer。

## 抽屉、命令面板与验证

抽屉采用已有可靠组件或原生dialog.showModal，处理名称、首焦、Esc、遮罩策略、滚动锁和回焦；原生能力不替代未保存保护。

命令面板为可选效率入口。采用时支持Ctrl/⌘+K、↑↓、Enter、Esc、可见活动项和可访问名称；输入中快捷键不误触。combobox/listbox语义须有匹配键盘行为。

验证记布局、存储偏好和输入方式。覆盖折叠→进入→离开、快速划过、手动收起后仍悬停、键盘进入/Esc、触屏显式展开、窄屏抽屉，范围只限本次采用的能力。路径路由另验直达/刷新、当前项高亮与旧 hash 迁移；无 SPA 回退时说明 hash 限制。Rail 另看组间节奏：单分组确认没有分隔线或空标题槽；多分组时组内行距、组间空白、分隔线上下留白使用同一套参数；隐藏标题时不得留下“标题高度 + margin”且无可见分隔的空白。顶栏核对品牌槽与侧栏 slot 同宽、品牌图标与 Rail 图标同中心、面包屑和右侧状态与内容左右边距对齐。允许纵向错位时，补验展开后点击仍命中预期项。点击导航后检查：折叠态保持 hover peek 至指针离开再回 Rail，pinned 不收起；焦点展开与鼠标点击的释放路径分别验证。
