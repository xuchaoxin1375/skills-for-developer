# 表头型数据列表与编辑

默认是**声明的混合基线**：页面层级和编辑反馈用 fable，表头型数据呈现的视觉几何用 Cloudflare 实况，列宽交互用 sonnet，窄屏等价控件与表格增强用 gpt/本地。它不是把 fable 整页逐项改成 Cloudflare；若项目明确选择 fable 整页（含表格），按 fable 表格原值实现并在交付中说明。业务不需要的推荐、配额、导入、列宽或批量可裁剪。Cloudflare 是基准不是封顶：列宽键盘/持久化、勾选列粘左、列顺序和窄屏等价入口按本文增强，不为保真删掉。

本文适用于**带表头的数据呈现**：原生 `<table>`、`div` 组合的 ARIA table、带字段标签的卡片/列表。它不要求使用 `<table>` 元素；元素选型按“DOM 与语义选型”处理。

## 规格先行

先写清一行代表什么、稳定 ID 与版本、主任务、列优先级与固定列、选择范围（本页／全部匹配／当前操作集）、查询变化是否清选择、排序是否回第 1 页、草稿归属、操作风险与恢复、排序/分页能力、切卡阈值，再写 CSS。规格没有这些决定时，外观再像也不是完整迁移；不要把 DNS 字段和值硬套到新业务。

## 页面与工具栏

`PageHeader → 按需状态/推荐 → 搜索与操作 → 生效筛选chips → 列表/编辑 → 结果计数与分页 → 选中操作`。

- 一个主创建入口，次要动作描边或低强调，不把每个动作都画成蓝色按钮；工具栏只服务列表，不堆无关统计与宣传块。
- 宽屏搜索目标宽约500px，空间不足先收缩；默认新增在右端，窄屏搜索独占一行、动作折行/收纳，不为保持最右让主操作越界。筛选下拉按最长选项保留可读宽度；窄屏先收纳计数/同步状态等次要文本，再压缩控件。中文输入法 composition 期间不提交远程查询/筛选，等 compositionend 再触发。
- 小型本地列表可直接过滤；重算昂贵/服务端搜索再防抖，150ms是fable参数。useDeferredValue不等于网络请求防抖。
- 多条件Filters默认草稿/应用分离，关闭不偷偷应用；简单单条件可即时过滤。chips/计数/清除反映实际生效条件。
- Display可记列显隐、顺序、密度、列宽、编辑偏好；损坏存储回退安全默认，功能列不隐藏到无法操作。
- 零数据给新增，零匹配给清除，无范围/无资源给切换入口；加载、请求失败和空数据分别表示。

## 视觉与交互基线

默认取 [Cloudflare 实况基线](cf-live-baseline.md) 的表格几何：40px 表头与行、14px 正文、14/500 表头（浅色白底，深色用对应 surface）、1px 发丝线、10px 列宽热区、36px 工具栏控件、紧凑 Display 菜单。fable 参考约 40px 表头／41px 默认行高／33px 紧凑行高，sonnet 约 44／45／29px；这些是各模板的视觉语言。项目明确选择 fable/sonnet 整页时，表格沿用其自身值并在交付中说明；默认混合基线只在表头型数据呈现上采用 CF 几何。

- **排序**：标签加 14px 独立图标，三态升序／降序／取消，`aria-sort` 放列头（`th` 或 `role="columnheader"`）；命中区不小于 24px，可整格点击，不照抄实况的 14px 小按钮。
- **列宽**：把手视觉取 10px 热区加 2×20px 线；键盘步长、边界、指针捕获和持久化取 sonnet，不取实况。
- **Display options**：173px 宽、33px 行、12px Reset 的紧凑几何；可加密度、重置列宽，用分组与分隔线区分。列顺序放在加宽的顺序子视图（见下），不把主面板扩成大面板。
- **工具栏**：控件 36px 高；搜索目标宽约 500px，空间不足时先收缩搜索，再按“搜索与筛选 → Display → Import/Export/主操作”折行；手机上主操作保留文字，次要动作图标化。
- **批量**：默认用底部浮动条并预留空间，勾选后不推动表头与行；内联选择条只在预留固定槽位、行位置不变时使用。
- **增强**：勾选列粘左、列宽键盘与持久化、列顺序、窄屏排序／列显隐入口都可以保留或新增；操作列粘右是 Cloudflare 已有做法，继续保留。Cloudflare 没有前述增强，不作删减依据。

## DOM 与语义选型

表头型数据呈现不限定元素：原生 `<table>`、`div` 组合的 ARIA table、带字段标签的卡片/列表都可以承载同一套视觉与交互。选元素看布局和交互需求，不看“看起来像表格”。

- **原生 `<table>` 是默认**：普通数据列表、需要 `caption`/`th scope`/行列表头、粘性列和常规横滚时，优先用它，语义和浏览器行为最省成本。
- **`div` 组合的 ARIA table** 只在有具体理由时使用：表头与表体独立滚动并同步、虚拟化、复杂分组/固定列、设计系统已有该结构。此时必须完整提供 `role="table"`/`rowgroup`/`row`/`columnheader`/`cell`、`aria-colindex`/`aria-rowindex`、`aria-sort` 和可访问名称，并自己保证表头/表体横移同步、列宽对齐、粘性列、选择、键盘与窄屏回流。只画 div 不补语义不算完成。
- **`role="grid"` 不用于普通列表**：只有实现完整方向键、roving tabindex、编辑/选择协议时才用；否则保持普通 Tab 导航。
- **卡片/列表**：有表头字段但无表格关系时，用语义化标签组或 `dl`，不要伪造 table 角色，也不要把字段标签只放在 placeholder 里。

Cloudflare 的 DNS 表就是 `div` 组合的 `role="table"`（表头与表体分开滚动再同步），可作为 ARIA table 的观察样例，但不是要求所有列表都改成 div。

## 表结构与选择

- 默认原生table/caption/th scope=col；若采用 div ARIA table，按上一节补齐角色、索引、排序与滚动同步。排序按钮在表头，aria-sort放列头上。除实现完整方向键/roving tabindex 的网格协议外，不要加 `role="grid"`。排序控件命中区不小于24px；标签可点或图标独立都可，视觉与命中区分别验收。排序状态数按用途定，不默认照抄三态：用户主要在同一列升/降之间来回、原始顺序只是落脚点时用两态——新列从升序开始，同列点一下换方向，另给显式重置入口（工具栏按钮或排序下拉里的“默认顺序”），不要求用户为复位点第三下；只有“未排序”本身是用户要回的常用状态、界面也能明确表达它时才用三态。
- 数值按数值，服务端分页不只排序当前页冒充全量；本地模式排序覆盖已加载全部记录，切换模式或请求中保留旧行。数字/金额/时间按原始值，枚举按业务顺序；相同值用稳定 ID 作次排序键；空值置前/置后要约定且双向一致；隐藏当前排序列时同步清除或明示“按 X 排序”，不能留下不可见依据。
- 先确认数据规模、后端排序/分页能力与首屏成本，再选加载模型：小数据集一次取回后本地搜索/筛选/排序/分页；大数据集用服务端分页与排序。可按首屏总量分档（少量直接全量、中等一次补全、超过阈值转服务端），阈值按业务定，不把小表硬套逐次请求。参考稿的本地 mock 只作交互参考，既不能直接当生产全量方案，也不能因既有分页就拒绝小表本地化。
- 可调列在原生 table 用table-layout:fixed+colgroup、min/default/max、固定功能列和填充列；div ARIA table 用每列 CSS 变量或 grid 轨道，列宽状态仍按列 id 管理。普通表不必引入整套。
- 固定功能列（勾选/图标/操作）不要继承通用单元格的 `text-overflow: ellipsis`；内容区窄于控件命中区时，裁剪边缘会露出省略号小点。列宽按 padding 加控件宽反算；触屏选择列约 64px 或保证 44×44 命中区，不能把 44px 列宽当 44px 命中区。行操作常驻，不以 hover 作为唯一入口。
- 行高由内容、控件和 padding 决定，不写死 height 裁掉文字或错误；36px 控件时舒适档约 56–61px、紧凑档约 45px，40px 只用于纯文本密集档。
- 省略号只用于次要值；完整值要能通过聚焦、展开或复制取得，`title` 只能补充。整行不要 `onClick` 直接进编辑，保持文本可选；移动卡用显式展开/编辑入口，不把整卡做成按钮。空值用有解释的占位，避免 0/关闭/未知看起来相同；金额与数值右对齐并用 `tabular-nums`，日期统一时区。
- 宽表自有overflow-x:auto，必要时可聚焦且有名称；勾选列默认粘左、末列操作粘右，二者用不透明行背景，hover/selected同步，仍有遮挡内容才显示阴影。Cloudflare 实况勾选列不粘左；这里保留粘左作为增强。
- 粘性列背景不透明并跟随 hover/selected，选中态优先于 hover；多列固定偏移按前序固定列累计。焦点环不被粘性层裁切；横滚自动滚到控件时为粘性列留 `scroll-padding-inline`；RTL 下先标准化 `scrollLeft`，再用逻辑方向判断边缘阴影。需要粘性表头时明确滚动所有者：`overflow-x:auto` 会创建滚动容器，不要让页面和表内各有一套可交互表头/表体。
- 行末操作菜单在首行、末行和滚动后打开时不得引发行高、列宽、页面滚动条或菜单位置抖动。默认用非模态浮层：不要锁 body 滚动或做滚动条补偿，打开/关闭前后 `clientWidth`、`scrollY`、表格和顶栏位置不变。浮层先完成定位再播放入场；入场只用 opacity 或独立 translate/scale，不用会覆盖定位 transform 的动画。末行向上翻转是允许的定位结果，不要求强开向下。
- 先分清三个集合：本页可选择项、全部匹配项、当前操作集合。表头复选框只对当前页可选择项含 indeterminate，全选本页不自动升级为全库。选择状态优先用原生 checkbox 的 checked/indeterminate；普通 table 行不要为了染色随便加 `aria-selected`，除非当前角色语义确实适用。
- 只对当前权限下可选择的项显示可选状态；无权限/只读行禁用选择并说明原因，全部不可选时不显示全选。
- 查询变化两选一：清空选择（默认）或保留并显示已选总数、隐藏数量和批量目标；不能只改计数。Shift 连选以当前排序后的本页可选择项为准，排序／翻页后重置锚点。
- 全匹配选择用 query fingerprint、服务端 token 或排除 ID，不把当前页 ID 当全量；确认时冻结目标快照，等待期间新增记录不加入本次操作。
- 批量只作用于明确的交集或快照，不在 await 后重新读取当前 UI 选择；反馈成功、失败、跳过数量，不只报一个总数。失败项保留选择并可只重试失败项；超时先查询操作状态再决定是否重试。
- 分页、虚拟化、表内滚动按数据与工作台需求选。配额不是分页替代品；不强制列表一屏或小表内滚。浮层内任务详情/日志轮询随可见性启停：关闭后停止，重新打开再拉取；外层运行中任务计数保留。

## 列宽调节

优先迁移 sonnet `src/ui/columns.tsx` 的宽度状态/键盘/持久化协议，再映射样式和状态。原生 table 用 colgroup；`div` ARIA table 用每列 CSS 变量或 grid 轨道，保留同一套宽度协议，不照搬 colgroup。把手视觉按 [Cloudflare 实况基线](cf-live-baseline.md)：10px 热区、2×20px 常驻发丝线；不取实况的无键盘、无持久化。

| 来源 | ←/→ | Shift | Home | End | 还原 |
|---|---|---|---|---|---|
| sonnet | 8px | 32px | 最小值 | 最大值 | Enter / 双击 |
| fable | 16px | 64px | 默认值 | 未实现 | Home / 双击 |

新模块默认选sonnet；继续采用fable可保留其键位，不混写说明。把手可聚焦，separator方向、名称和当前/min/max值完整；拖动不误排序。处理pointer capture、cancel/lost capture、卸载和文本选择恢复。

8–12px 是鼠标热区（fable 8、sonnet 12、CF 10）；8/32 和 16/64 是键盘步长，不是热区。粗指针至少 24px，触屏目标 44px 或给数值调节入口；不能把 8–12px 手柄当触控目标。拖动局部预览，松手提交+持久化，刷新检验；cancel恢复原预览。DOM直写是样例优化，不强制所有框架绕开响应式状态。

WCAG 2.5.7 还需要无需拖动的单指入口：在 Display options 中选中列后提供宽度数值框、减 8px／加 8px 和恢复。键盘等价不算单指替代，二者都要验证。

列宽按列 id 保存，列顺序变化不改变宽度；列宽、显隐、顺序、密度同属一张表的偏好对象，但各自可重置。不要把宽度存进位置索引。

## 列顺序

列顺序在三套模板和 Cloudflare 实况中都没有实现，属于本 skill 推荐新增的增强项。默认放在 Display options 的“调整顺序”子视图，不塞进 173px 的主面板，也不放在表头拖动上，避免和列宽拖拽、排序点击争抢同一手势。顺序子视图可加宽到约 300–360px，或在进入排序模式时用移动菜单替换复选框；主面板仍保持紧凑。

- 只调整数据列；勾选、状态/警告、操作列固定，不参与。
- 行内可用拖拽把手，键盘用“移动”菜单（上移/下移/置顶/置底）或 Alt+↑/↓；不要把把手、两个按钮、复选框和长标签同时塞进 173px。
- 顺序按列 id 持久化；隐藏列保留相对位置，重新显示时不自动追加到末尾；排序状态按 key 保存，不随列移动改变。
- 卡片模式下可见数据列按新顺序渲染，身份列和操作仍在卡片头部；展开区字段顺序跟随数据列。
- 移动后用 `aria-live` 播报新位置，焦点留在被移动行的按钮；提供“Reset order”，默认顺序时禁用。
- 验证要覆盖移动、隐藏/显示、改宽、排序、刷新和切卡片，确认表头/表体不串列、宽度不串列。

## 编辑与批量

需要邻行上下文用行内，复杂字段用dialog/详情页；两种共存共享编辑模型和校验，不强制每表做全部形态。

按稳定记录ID管理编辑。开进首字段；保存/取消回触发器，删除后回邻行或列表。排序/翻页/切形态保护输入，桌面表与移动卡不同时挂载同ID编辑器。横滚编辑区保持可见。批量弹窗用打开时的记录快照/ID，不在写入成功后依赖实时选择；成功写入由弹窗关闭，父级不在 await 返回前卸载，避免内容闪空或卸载后更新。

草稿放在页面级 `draftsById`，不要只存在行组件。`key={id}` 只能保持身份，不能跨卸载保存组件 `useState`；翻页、筛选、排序把行移出当前页、表格/卡片切换、行内/弹窗切换都不能清除草稿。清除只由保存确认、用户明确丢弃、对象已删除且解释后果触发；不要在 effect cleanup 里 `setDirty(false)`。

保存开始后捕获提交的 draft、baseVersion、requestId 和 revision；要么禁止继续编辑，要么允许继续输入但只提交捕获的 revision，成功回调不得关闭包含新输入的会话。版本冲突保留草稿与输入，显示服务器版本，不自动覆盖。

写入成功后只按响应中的记录或成功 ID 更新/删除对应行，失败项保持原数据；不要用整表重拉代替局部更新。响应应返回实际生效的记录或足够字段，前端不能凭请求参数猜服务端归一化结果。保存成功用少于约 3 秒的行强调加通知，不持续闪烁；错误不能只把整行涂红，要定位控件并给可行动文案。

默认用底部浮动选择条并预留空间，不遮最后一行，勾选后不推动表头与行；内联选择条只在预留固定槽位、行位置不变时使用。Shift 连选时尤其不能让行在点击之间移位。

## Undo与真实接口

sonnet `dashboard/data.tsx` 是本地机制范本：更新前存记录，删除前存{rec,index}，按ID/原索引恢复。是否可撤销看实际恢复，不以某函数是否返回快照判断。

真实业务需服务端撤销、软删除或补偿，处理版本冲突/超时；UI回填不能恢复服务端。低风险可逆动作优先Undo；不可逆/高风险确认后执行并明确后果。8s为样例窗口，必要恢复入口不能因短toast消失而失效。

## 导入导出

gpt `DnsConsole.tsx` 先解析/整体验证再一次写入，任一失败零部分写入，生成新本地ID，检查现存/本批重复。1MB/200条是演示限制。

后端原子性需事务/批端点保障；支持部分成功时给预览、逐项结果、重试策略。前端全量校验不能保证服务端原子性。导出说清全部/匹配/选中范围，不以当前页冒充全量，Blob URL用后释放。

## 窄容器

Cloudflare 实况在 752–760px 视口、约 720–728px 内容宽之间切卡片；fable 是视口 640、sonnet 是容器 700、gpt 是容器 640，都是起点。切卡阈值由表头型呈现的实际 min-width 加外层左右 padding 反推，并实测边界两侧，不照抄单一数字。

- **按信息层级而不是列数决定**：有 2–4 个主字段（身份、主值、状态）且其余可折叠时用摘要卡片；字段同等重要、需要横向比较时保留表格横滚。`>6` 只说明可能不适合卡片，不是硬规则。
- **卡片是摘要加展开**：身份、主值、状态、一条摘要；其余字段进展开区或编辑层，不把当前可见列逐项堆成“标签＋值”。
- 切卡片后排序、列显隐、全选这类只挂在表头上的能力要另给等价入口（工具栏下拉/按钮），不能静默消失。
- 窄屏仍要能完成排序、选择范围、批量、编辑、分页和完整值查看；表格转列表不等于删功能。
- 300px 下可收缩子项用 `min-width:0`，输入字号 16px，弹窗宽 `min(内容上限, 100vw - 16px)`；页面不横溢，只让表格或局部区域滚动。
- 不要同时挂载表格和卡片两套完整 DOM 再用 CSS 隐藏；切换前把查询、选择、草稿、偏好提升到共同父层，避免重复 ID、重复编辑器和读屏噪声。
- 卡片顶部保留选择与行操作；字段多时优先减少摘要字段，而不是把卡片拉成长表单。卡片用显式展开/编辑入口，保留文本选择。

ul 卡片有属性名称，重排 table 时保留表头关联；没有 table 的卡片不留孤立 thead。只挂载一种编辑形态，切断点保数据/选择/输入并移交消失控件焦点。二维比较型表可局部横滚；页面回流且关键操作可达。

## 交付前检查

- 300/390/768/1440 和切卡阈值前后 1px：页面不横向溢出，表格只在容器内滚动，卡片不丢排序/选择/编辑/分页。
- 横滚到中间和最右：粘性勾选列与操作列不透字、Edit 可点，键盘焦点不被固定列遮住。
- 列宽：拖动、键盘、数值/±8、Esc 取消、刷新保留、损坏存储回退；拖动不误触排序。
- 选择：本页、全部匹配、当前操作集三者清楚；查询变化策略明确；批量目标冻结，部分成功/失败/跳过可区分。
- 草稿：翻页、筛选、排序、切卡片、行内↔弹窗后仍在；保存中 revision 和版本冲突不丢输入。
- 内容：长中文、连续 URL、空值、0、同名不同 ID、只读、无权限、加载失败、无匹配各有明确结果。
- 键盘与读屏：排序、选择、编辑、首错、关闭回焦；浅/深色、reduced-motion、200%/400% 缩放不破坏操作。
- 证据分级：源码、构建、浏览器、截图、a11y、真实后端分别记录；未执行写“未验证”，失败不改成通过。
