# 参考稿设计与交互功能目录

本目录回答“参考稿具体设计了什么、怎样操作、哪些细节要一起复用”。对象是 skill 归档的三份 **Cloudflare-inspired 独立样例**，不是 Cloudflare 官方后台的完整功能清单。以 fable 为默认模板，sonnet、gpt 的能力分别标注，不能把三者合并成一个已经存在的成品。

## 按复用区域查阅

| 想复用或核对 | 详细目录 | 包含的设计与交互 |
|---|---|---|
| 外壳、侧栏、顶栏、全局搜索 | [外壳功能](feature-shell.md) | 区域层次、分组、Rail/peek、鼠标与键盘混用、按住点击、收起抑制、抽屉、资源菜单、命令面板 |
| DNS 列表和编辑表单 | [DNS 功能](feature-dns.md) | 搜索筛选、列显隐/密度/列宽、排序选择、桌面表/手机卡、三种编辑容器、字段联动、校验、保存删除、导入导出 |
| 通用控件、浮层、概览、设置、长表单和向导 | [控件与其他页面](feature-patterns.md) | 标签/提示/错误、按钮与反馈、浮层焦点、分区保存、危险区、步骤回退、开发预览工具 |
| 需要补强 fable 的局部能力 | [其他两稿的补充功能](feature-supplements.md) | sonnet 六状态、分页/连选/批量/Undo/离开保护；gpt 草稿/失败重试/JSON 导入预检/容器回流 |

这是查漏与取用地图；[模板单元](template-units.md)定义一起取用的依赖，[定制指南](cf-customization-guide.md#完整模板迁移)定义如何接业务。各领域 reference 定义目标应满足的规则。目录描述源码现状，二者不互相冒充。

## 证据与边界怎么读

- **已实现**：归档源码存在对应状态、事件与结果。本轮逐项说明来自静态源码核对，不代表每条都运行验证。
- **演示**：前端能操作或有反馈，但数据为本地/内存模拟，缺少实际服务端业务。标题、图表和成功 Toast 不能证明接线。
- **占位/无动作**：静态展示、占位路由或缺少处理器，需明确保留外观、补功能或有依据地裁剪。
- **复用需补**：与目标交互底线存在差距，或源码不能证明可靠性。先补缺口再交付，不以模板保真为由继承缺陷。

已有浏览器证据和覆盖范围只引用[三工程对照](builds-comparison.md#已执行抽查与已知缺口)；不要把本目录的静态分析写成新的交互测试通过。源码版本由 [manifest](../assets/sources/manifest.json) 标识；原始参数见[工程对照](builds-comparison.md#参数原值非全项目强制收敛)与[令牌](tokens.md)。

## 能力差异速查

| 能力 | fable | sonnet | gpt |
|---|---|---|---|
| 侧栏临时展开 | 独立 hover/focus；已修正图标、Esc 和按住点击路径 | pinned/hover/kbFocus/forced/suppressed/drawer 明确分离；平板强制 Rail | 另有控制台与站点导航；不能套成前两稿同一模型 |
| 列宽 | 拖拽、16/64 键盘步长、Home/双击默认值 | 拖拽预览/提交、8/32、Home 最小/End 最大/Enter 默认 | 未实现 |
| 分页 | 只有计数，没有分页 | 5/10/25/50；页选择和全部匹配 | 10/25/50；筛选等变化清选择和页码 |
| 行内编辑 | 替换原行；单个 editingId | 保留原行、插入编辑行；可同时开多行 | 共享 RecordForm；失败重试和新建草稿 |
| 未保存保护 | DNS 仅 beforeunload；无站内/取消保护 | 列表编辑有取消确认、站内 guard、beforeunload | 新建表单本地草稿；不等于完整站内保护 |
| 批量 | 选择、清除、删除 | 删除、代理状态、导出、清除；本地 Undo | 删除；导出选择或全部 |
| 导入 | 简化 zone 文本，接受可解析子集 | 简化逐行文本，有解析错误整批不写；缺全面语义预检 | JSON 全批校验、容量/重复预检，通过后统一写入本地状态 |
| 记录持久化 | `cfui.dns.records` localStorage | `useState` 内存数据；偏好/列宽另行持久化 | `edgelab.records` localStorage，读取时检查结构 |
| 删除恢复 | 本地快照前插，原顺序不保留 | 按原索引恢复删除；批量修改恢复旧字段 | 删除确认，没有业务 Undo |

细节和限制在对应目录中；不要只凭本表实现。Auto TTL 的数据表示也不同：fable 为数值 `1`，sonnet 为数值 `0`，gpt 为字符串 `auto`；应在数据适配层转换，不能直接混用。

## 用目录防止细节累计丢失

选定单元后，按对应目录核对视觉结构与整条交互路径：默认态 → 触发 → 展开/编辑态 → 错误或进行中 → 成功/取消 → 焦点与恢复。控件的排布、图标、文本层级、密度、时序、浮层位置和窄屏形态都属于模板。

例如只复用侧栏，仍需完整保留槽与覆盖层的关系、各类入口和隐藏子项的焦点规则；不需要顺带搬 DNS。只复用 DNS 表单，字段联动和错误反馈仍需保留，列表分页可以留给挂载端。实际业务不支持的功能明确接线或裁剪，不做没有结果的按钮。

先用与参考一致的数据、视口、主题、状态检查设计，再用目标业务的长文本、权限、空数据和保存失败检查行为。对照截图与实际操作各自提供证据；本目录不替代目标项目验证，也不要求每次加载所有页面。
