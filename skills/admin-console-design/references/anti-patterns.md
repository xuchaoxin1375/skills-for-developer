# Legacy反例与边界

sonnet `src/dashboard/Legacy.tsx`刻意展示缺陷，可在独立反例预览中观察。它是教学对照，不证明所有固定宽度、禁用按钮或顶部反馈都有错。

| 反例组合 | 实际问题 | 改进与合理边界 |
|---|---|---|
| 固定220px侧栏且无窄屏入口 | 内容被挤、导航不可用 | Rail/抽屉或其他可用窄屏方案；固定桌面侧栏本身合法 |
| 900px表宽传到整页 | 页面横滚、操作被滚走 | 限于表容器内滚或重排卡片；table min-width本身合法 |
| placeholder代label、置灰且无原因、笼统错误无定位 | 不知字段/错误/怎么改 | 可见标签、可行动字段错误、提交定位、保输入；保存中/无改动/无权限可禁用 |
| 只有远处Saved且无可感知结果 | 用户不知操作成功 | 就地状态、toast或结果页面；清楚的顶部live成功条也可合格 |

同样检查：只靠hover的唯一入口、透明粘性格、勾选后点击行突移、排序后丢编辑输入、局部UI恢复冒充服务端Undo、根overflow裁切掩盖缺陷。

评审按实际影响和任务判定阻断，不因没做toast、没有常驻实验室、危险区恰在首屏就自动打回。报告含可复现步骤、影响、原因和改法；未知状态明确待核实。
