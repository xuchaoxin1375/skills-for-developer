# EdgeLab 设计规划

## 定位与边界

EdgeLab 是参考 Cloudflare 控制台交互理念的独立设计实验室，不是 Cloudflare 官方产品、组件库或规范。目标用户是需要设计基础设施管理后台的设计师与前端开发者。核心任务是：通过一套可操作的 DNS 案例，理解可折叠导航、表单校验与响应式设计。

本项目不连接 Cloudflare API，不提供 DNS 服务。记录、草稿和偏好只保存到当前浏览器。示例 IP 使用文档保留地址。

## 信息架构

1. 设计总览：理解范围与推荐学习路径。
2. 侧边栏导航：体验固定、收起、悬停、键盘聚焦四种状态。
3. DNS 管理：搜索、条件筛选、排序、选择、增删改、导入导出。
4. 表单与校验：字段级校验、提交校验、草稿保留与失败重试。
5. 响应式布局：预设宽度、连续调节、自动往返演示。
6. 设计规范：规范性要求、推荐实践与禁止事项。
7. 设计令牌：语义颜色、字号、间距、圆角与动画。
8. 交付文档：文档地图、部署说明与验收边界。

## 视觉决策

- 背景采用中性白与浅灰，细线划分区域，不使用装饰性渐变。
- 橙色表达实验室品牌与导航选择，蓝色表达执行操作。
- 内容以列表、表格和单列表单为主，容器只用于承载实际交互。
- 中文优先使用系统无衬线字体，技术数据使用等宽字体。
- 先定义语义令牌，再为浅色和深色主题分别赋值。
- 非必要图片为零，避免管理任务被装饰打断。

## 交互与运动

导航宽度过渡、页面进入、弹窗进入三类运动表达状态变化。悬停延时为 120ms，离开延时为 240ms，宽度动画为 220ms。上述时间是本案例的设计选择，不是 Cloudflare 官方数值。遵循 `prefers-reduced-motion`，减少动态效果时取消装饰运动，自动宽度演示改为离散切换。

## 验收优先级

P0：数据操作正确、键盘可达、错误可恢复、300px 不产生页面级横向滚动。

P1：深浅主题、系统主题监听、草稿与偏好持久化、导航无意外抖动。

P2：过渡质感、辅助说明、文档与自动化用例。
