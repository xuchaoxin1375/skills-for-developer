# 验收与测试清单

## 1. 验收原则

构建成功只证明可以产出静态资源，不代表功能、视觉、无障碍或浏览器兼容性合格。本文件区分自动化用例、人工验收和当前交付能力。

本项目提供 Playwright 配置与用例。浏览器是否通过，以运行后的 HTML 报告为准。若交付环境只允许文件编辑与构建，不提供浏览器执行工具，则浏览器用例、截图审查和辅助技术验收应标为未执行。

## 2. 执行方式

```bash
npx tsc --noEmit
npm run build
npx playwright install chromium
npx playwright test
npx playwright show-report
```

项目内测试可直接使用 `npx playwright test`，不需要修改 package.json。测试服务器使用 4173 端口，已有同端口服务时应先确认服务正确。

## 3. 覆盖矩阵

| 维度 | 必须覆盖 |
| --- | --- |
| 视口 | 1440 / 768 / 390 / 320 / 300px |
| 主题 | 浅色、深色、跟随系统；系统改变时自动更新 |
| 输入 | 鼠标、键盘、触屏；允许粘贴 |
| 动态效果 | 正常、prefers-reduced-motion |
| 数据 | 默认、空列表、空结果、多页、超长 TXT、200 条上限 |
| 表单 | 空输入、格式错误、重复记录、模拟失败、成功、取消草稿 |
| 环境 | 正常存储、损坏存储、存储受限；正常与失败文档请求 |

Playwright 默认运行 4 种宽度；320px 由窄屏专项用例补充。生产发布还需要真实 Safari / Firefox 与移动设备检查。

## 4. 导航验收

- 工作台收起后保持 64px，站点收起后保持 56px。
- 快速经过侧栏时不闪烁。
- 悬停足够时间后展开，主内容的左边界没有变化。
- 离开后延迟收起；焦点仍在侧栏时不得收起。
- 点击固定后保持展开，点击收起后能够立即进入收起状态。
- 关闭悬停后仍能使用 Tab 和固定按钮。
- 移动端菜单有可见关闭入口、焦点约束和 Escape 退出。
- 在悬停计时期间切换页面，不出现过时的展开或状态更新错误。

## 5. DNS 与表单验收

- 搜索存在的名称得到准确结果，随机关键词显示可恢复的空状态。
- 应用筛选后结果正确，清除后恢复。关闭筛选不应用草稿条件。
- 排序表头正确更新 `aria-sort`。
- 勾选当前页全选与部分选中状态符合实际。
- 添加记录成功后列表更新，刷新后仍可见。
- 取消新增后草稿保留，成功新增后草稿清空。
- 提交空表单时聚焦名称字段，IP 错误关联到内容字段。
- 粘贴值不受阻止，错误后修正无需重填其他字段。
- 切换记录类型时，代理能力、MX 优先级与内容标签同步更新。
- 模拟失败保留输入，关闭模拟后重试成功。
- 删除先确认，取消删除不改变数据，确认后只删除选择项。
- 导出 JSON 包含正确记录；有选择时只导出所选。
- 导入畸形 JSON、重复记录或超量数据不产生部分写入。

## 6. 响应式与外观验收

- 每个尺寸下 `document.documentElement.scrollWidth <= window.innerWidth`。
- 标题、预览控件、表单、浮层和通知没有相互遮挡。
- 预览宽度改变时，实际内容重排而不是缩放。
- 300px 下搜索、添加、保存、取消和删除确认仍能完成。
- 长 TXT、错误消息和文件名可以断行，不撑破页面。
- 两个主题都检查表格、表单、选中、悬停、焦点、错误、禁用状态。
- 触屏控件达到 44px 目标或具备等效可点击区域；不能只看图标尺寸。
- 页面缩放到 200%，再检查核心任务；文本缩放到 400% 时记录回流结果。
- 实际截图需人工查看，不能仅以截图文件成功写入作为视觉通过。

## 7. 无障碍人工检查

1. 从跳转链接开始，仅用 Tab / Shift + Tab 完成添加和取消。
2. 检查标签、必填状态、辅助说明、错误消息是否按逻辑被朗读。
3. 检查各弹窗首个焦点，循环导航与关闭后焦点恢复。
4. 检查收起导航的图标名称、当前页、排序和开关状态。
5. 使用 VoiceOver 或 NVDA 检查窄屏重排表格的读取顺序。
6. 测量文本对比度，不能依据屏幕观感推断 4.5:1。
7. 开启减少动态效果，确认没有持续位移动画，自动演示可暂停。

## 9. 发布门槛

P0：不能保存、错误删除、无法退出浮层、核心任务键盘不可达、窄屏主操作不可用。任何一项都应阻止发布。

P1：主题状态丢失、焦点位置错误、重复提交、草稿意外清空、导入部分写入。修复或明确阻断影响范围后再发布。

P2：轻微动画不一致、非关键排版或辅助说明问题。可以列入后续计划，但必须记录。

本原型的个人验收勾选列表只是用户笔记，不会自动推断这些检查已通过，也不是 WCAG 合规证明。
