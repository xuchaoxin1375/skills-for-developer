# 自定义边界指南（cf-customization-guide）

> 用途：项目功能与 CF 参考稿不同时，指导"改哪里、 kept哪里"。总原则：**直觉层冻结，功能层自定义**——用户学过的导航/表格/表单/反馈行为一个不许变；变的只能是导航项、列定义、字段、接线。
> 前置：先读 `cf-intuition-map.md` 并亲手点过 `references/builds/` 产物。数值以 `SKILL.md` 收敛口径为准。

## 1 必复用清单（动之前先申请并写理由，见 §3）

- 外壳骨架：Topbar56 + Sidebar 状态机（pinned/rail/peek/drawer + 意图延迟 + 覆盖不推挤）+ 内容 max1440。含通用控件：搜索框、返回上级、导航分组、底部收起、资源切换器、命令面板。
- 表格骨架 9 层：搜索/Filters 草稿分离/Display/三态排序/粘性末列/行内↔弹窗共用表单/悬浮批量条+Undo/配额条/窄屏切卡。
- 表单契约：Field 三段式、两级校验+首错聚焦+可行动文案、保存永可点、草稿+脏保护、一卡一决策、危险区隔离+输名确认。
- 反馈契约：primary 最右、toast 时长与 Undo、空态双文案、忙态三件套、危险默认聚焦安全选项。
- 令牌与层级：语义变量名、深色独立映射、fable 完整 z 套（二选一后全项目统一）。

## 2 可改清单（直接改，不用申请，但写一行备注）

- 导航项：分组名、条目、图标（同语义 Lucide，不硬套错语义）、徽标（New/计数）。
- 表格列：列定义（字段/min-max/显隐默认）、筛选字段与操作符、排序列白名单、配额上限数字。
- 表单字段：字段增删、分组、条件联动规则、校验函数体（错误文案公式不变：哪里错+为什么+如何改+示例值）。
- 数据接线：mock 数据层换真实 API（见 §4）；持久化键前缀按项目重命名；空态文案中的业务名词。
- 文案与品牌：Logo、产品名、域名示例、帮助链接；品牌橙的出现位置（总量仍≤5%）。

## 3 改前理由模板（动 §1 内容时必填，三行）

```markdown
- 改什么：（如：去掉 Filters，只要搜索）
- 为什么：（业务原因，如：该表只有一列可筛，下拉浮层比输入还重）
- 影响哪条直觉：（对照 cf-intuition-map，如：表格心智"筛选配完点Apply"——本表无多条件，故降级为搜索框，chips/计数一并去掉，不留半套）
```

半套禁令：同一心智内的配套元素要么全留要么全降级，不许留半套（如：去掉 Undo 就必须有语义对等的二次确认+明确不可恢复声明；去掉 persistent 草稿就别做浮层筛选）。

## 4 接线替换指南（mock → 真实 API，交互契约不变）

1. 保持校验函数签名（字段→消息列表），服务端冲突映射回字段的入口保留，只是把本地 `findConflicts` 换成接口返回码翻译。
2. 保持 Undo 语义：真实删除先拿回滚凭据（id/index/快照）再执行，无凭据的删除不许称"可撤销"（判定标准见 `builds-comparison.md` §3 sonnet 条）。
3. 保持草稿键名规则与清空时机（成功清空、取消保留、删除清脏），只换存储后端。
4. 保持忙态与防重：接口延迟替换本地模拟延迟，`aria-busy` 与不可重入逻辑不动。
5. 替换完跑一遍 `SKILL.md` 步骤5 验证（390/768/1440+300、主题三态、纯键盘增改删撤销），结论写进交付已知问题。

## 5 常见越界（评审见到即打回）

- 跨稿拼凑：表格骨架用 fable、列宽用自创第三种步长——列宽只有收敛口径一种，不许自拼。
- 产物数值直抄：把某构建的 264px/110ms 原样搬进新项目——落地只用收敛口径。
- 直觉层"优化"：把批量条从底部改到顶部、把保存改成置灰、把危险区搬到首屏——这叫改直觉，不叫自定义，打回。
- 形态按挂载裁剪不算拼凑也不算越界，但必须声明（如：嵌入 iframe 时隐藏顶栏，需在方案 §2 写明）。
