# Cloudflare 后台设计分析总表（cf-design-analysis）

> 用途：三参考工程（fable5.1-high / gpt6astra-max / sonnet5.5xhigh）的功能与设计全量整理：定位、功能模块、侧边栏、表格、表单、顶栏、卡片、弹窗、令牌、响应式与无障碍，外加三家互补点。每表带"批注"列说明可取之处与语义。
> 读法：先看 §0 定参考来源（默认 fable 整体），再按需查表；动手前双击 `references/builds/` 产物亲手验证。
> 边界声明：文件行号指向各工程源码（zips 与源码目录同在 skill 素材来源，见 `SKILL.md`）；时序/尺寸数值为三工程的独立设计选择（非 Cloudflare 官方规范），落地一律用 `SKILL.md` 收敛口径。
> 与另两篇的关系：本篇是"素材全集"（有什么、好在哪）；`cf-intuition-map.md` 是"对齐清单"（还原时逐项打勾）；`cf-customization-guide.md` 是"改动边界"（什么能改）。

## 1 功能模块总表（三家并集）

| 模块 | 功能点 | 批注 |
|---|---|---|
| 站点总览 Overview | 域名+套餐徽标、待办 checklist、24h 统计、快捷入口 | 一页一事：首屏≤3 主操作仅 1 primary；checklist 打勾划线给进展感 |
| DNS 记录管理 | 搜索/多条件筛选/排序/列显隐列宽/密度/导入导出/分页或配额/批量/行内或弹窗编辑/删除撤销 | 最完整的综合案例；编辑形态可切换（行内↔弹窗复用同一表单同一校验，偏好持久化） |
| DNS 分析/邮件 | 记录类型分布条、MX/TXT 自动过滤视图 | 条形占比+文字代替图表库，无数据不硬上图表 |
| SSL/TLS 设置 | 加密模式单选卡片、TLS 版本、Always HTTPS 开关 | 一卡一决策：左说明右控件，脏时才出现底部操作条 |
| 危险区 | Pause/Remove 站点、输域名确认删除 | 垫底红描边独立区；高风险输域名才启用，且按钮保持可点、错了再校验 |
| 添加站点向导 | Domain→Plan→Review 三步，Review 逐项 Change | 线性进度+Back 不丢数据+换步焦点移到标题；窄屏收成进度条 |
| 命令面板 | `Ctrl/⌘K` 跳页/新建/切侧栏/切主题 | combobox 语义+分组+快捷键说明条，专业用户效率入口 |
| 响应式实验室 | 宽度滑条+预设+自动往返播放+独立预览 | 实验室即验收台：同一产物真跑媒体查询，可亲手验证 |
| 设计资源 | 令牌三 Tab 可复制、规范 MUST 表、文档在线读+合并下载 | 规范、原型、实现三位一体互证 |

## 2 侧边栏设计

| 设计点 | 三家共同做法 | 批注 |
|---|---|---|
| 三态/五态状态机 | pinned（占位）↔ rail（56px 图标栏）↔ peek（覆盖展开）+ 移动抽屉；意图延迟进/出；`[` 快捷键 | 占位与视觉宽度解耦是灵魂：peek 只覆盖不推挤（零 CLS），只有 pinned 才占位 |
| 防抖弹 | 点收起后 suppressed 到鼠标离开；快速进出清计时器 | 防"点收起秒弹回"的经典烦躁，可直接抄 |
| Rail 零泄漏 | 固定宽内容容器 + overflow 隐藏 + 文字透明度延迟 + 图标中心 x 不变；DOM 保留读屏可读 | 折叠态连半个字不漏；收起≠藏起可访问性 |
| 选中态 | 底色 + 左 3px 品牌竖条 + `aria-current="page"`；子项缩进+左边线 | 三重信号（色/形/语义），不单靠颜色 |
| 徽标/计数 | New/Demo 弱标签；折叠时淡出 | 弱标签不抢导航，折叠淡出防泄漏 |
| 快捷键帽 | `[` 切换、`⌘K` 搜索印在按钮旁 | 可发现性强；读屏细节：变化名称处慎用 `aria-expanded` 防重复播报 |
| 触屏/键盘等价 | `(hover:none)` 禁 peek 走 forced 按钮；仅 `:focus-visible` 才键盘展开 | 鼠标点击不展开、键盘聚焦才展开，三类用户各走各路 |
| 移动端 | <768px 汉堡→左抽屉（原生 dialog，Esc/遮罩/导航项关闭+焦点移入） | 抽屉是独立形态而非简单缩小 |
| 持久化 | pinned 进 localStorage；桌面默认展、平板默认 rail | 偏好记住+按设备给不同默认 |

代表实现：fable `src/components/shell/Sidebar.tsx + ShellContext.tsx`（状态机正本）；sonnet `src/dashboard/Sidebar.tsx`（像素居中与覆盖零位移实证最多）；gpt `src/components/Sidebar.tsx`（工作台+站点双导航）。

## 3 表格设计（以 DNS 记录表为基准）

| 设计点 | 做法 | 批注 |
|---|---|---|
| 列配置 | `table-fixed` + colgroup 精确定宽；列显隐/密度持久化；填充列吸剩余空间 | 宽度是用户资产：可调（拖拽热区+键盘+双击还原+拖完持久化）+ 可藏 + 设定不漂移 |
| 粘性列 | 首列勾选 + 末列操作双粘性；实色行底防透；滚到边才现阴影 | 阴影即 affordance：有阴影=还有内容 |
| 排序 | 表头内按钮三态 asc→desc→null + `aria-sort`；数值按数字文本按 locale | 三态可回到"不排序"，少一次死胡同 |
| 筛选 | 字段×操作符×值（AND，上限 4）+ 草稿/已应用分离 + chips 逐删 + 计数徽标 | 浮层内随便改不触发重算，Apply 才生效，心智清晰 |
| 搜索 | 防抖 + deferred 解耦输入与过滤；`?q=` 可预填分享 | 输入不卡手；URL 可分享当前视图 |
| 分页/配额 | 传统分页 或 配额条（已用 n/上限 + Showing 区间） | 数据量小用配额条更轻，语义是"额度"而非"翻页" |
| 批量操作 | 本页全选+indeterminate；Shift 连选；跨页不丢+选全部匹配；底部悬浮条不插表格上方 | 防连选错位是魔鬼细节；删除必 Undo 而非仅二次确认 |
| 行内编辑 | 末列常驻 Edit；行内展开与弹窗复用同一表单同一校验；横滚时编辑区 sticky 锁定可视宽 | 上下文与专注兼得；用户自选形态偏好持久化 |
| 空态/加载态 | 无数据 vs 无匹配双文案+恢复按钮；保存用 Spinner+`aria-busy`+防重 | 空态永远给下一步，不说空话 |
| 窄屏 | 容器 <640 表格转语义化卡片（thead 保语义视觉隐藏），只渲染一种形态 | 卡片是重排不是压缩；防双编辑器重 id |

代表实现：fable `src/pages/dns/DnsRecordsPage.tsx + components/ui/table.tsx`；sonnet `src/dashboard/pages/DnsRecords.tsx + ui/columns.tsx`（列宽与滚动阴影最全）；gpt `src/components/DnsConsole.tsx`（导入导出原子性标杆）。

## 4 表单设计

| 设计点 | 做法 | 批注 |
|---|---|---|
| 布局 | Field 三段式（label 行+控件+hint/error）；单列默认，≥7 字段分组/向导；长表单右侧 sticky 大纲+错误角标 | 大纲即地图：长表单不迷路 |
| 控件 | 原生 input/select + 统一样式；Toggle=switch；≤4 项用卡片单选；Tags 回车/逗号添加 | 原生优先：免费得无障碍与移动端键盘 |
| 两级校验 | 失焦轻查 + 提交全查 + 顶部汇总（数量+可点击跳转）+ 首错聚焦；纯函数校验；"错+改"文案（哪里错+怎么改+示例） | 错误是可恢复的状态，用户永远知道错在哪、点一下就到 |
| 联动 | 切类型清不适用字段；互斥强制并注明原因；条件字段按需出现 | 联动有解释，不用"悄悄改值"吓人 |
| 永不丢输入 | 草稿 localStorage；失败/离开保护（站内拦截+beforeunload）；成功才清 | 晚惩罚早奖励：输入保留、粘贴自动归一化 |
| 提交反馈 | 保存永可点（不用禁用代替校验），保存中 Spinner+防重保焦点；成功 toast+回列表高亮行 | 按钮禁用是伪装可用；焦点管理让读屏用户不迷路 |
| 危险确认 | dialog 危险红按钮+动词+列出实物+默认聚焦安全选项；删站点输域名 | 默认焦点永远在安全侧；输域名把"我知道删的是谁"变成动作 |

代表实现：fable `src/components/ui/primitives.tsx + pages/forms/FormPatternsPage.tsx`；sonnet `src/dashboard/pages/RecordForm.tsx + ui/controls.tsx + recordModel.ts`；gpt `src/components/RecordForm.tsx`。

## 5 顶栏/页眉设计

| 设计点 | 做法 | 批注 |
|---|---|---|
| 三段式 | 汉堡（移动）/Logo/资源切换器 … spacer … 搜索/AI/通知/主题/头像；56px sticky | 左上下文、中弹性、右工具，分工一眼清 |
| 资源切换器 | 域名+套餐徽标+星标收藏，下拉搜索切换站点；上下文常驻 | 切模块不丢"我在管哪个站"，控制台与普通后台的本质区别 |
| 面包屑+PageHeader | `h1 + meta徽标 + description + actions右置` | 标题、状态、说明、动作四件套固定槽位，页面间可预期 |
| 命令面板 | 顶栏无常驻搜索框，入口在侧栏+全局快捷键 | 搜索框不占顶栏常驻位，需要时即达，省空间给上下文 |
| 通知 | 无铃铛，统一右下 toast（error 8s+alert，其余 5s+status，可 Undo） | 通知即反馈，不设"消息中心"增加心智负担 |

## 6 卡片/弹窗/令牌/响应式/无障碍（合并表）

| 域 | 做法 | 批注 |
|---|---|---|
| 卡片 | 一卡一主题，禁卡套卡片，用分隔线；统计=标签+大数字+delta | 少卡片是规范级要求，克制即高级 |
| 弹窗 | 原生 dialog 统一封装：焦点陷阱+锁滚动（计数器支持嵌套）+首焦+Esc+点 backdrop 关+关后回焦点；移动端变底部抽屉 | 原生能力免费得无障碍；删除/重置默认聚焦安全选项 |
| 浮层 | Popover/Tooltip/Menu：视口夹紧、四向定位、Esc 回焦点、窄屏变底部面板 | 三件套行为一致，用户不用重新学习 |
| 令牌 | 语义命名，组件禁裸色值；品牌橙≤5%仅标识；操作蓝独立 | 换肤只换 `:root`；小字橙另给 ink 色保对比是美学让步的范本 |
| 深色 | 非纯黑底+逐态提亮+首屏防闪脚本+system 跟随 | 深色不是反色，每档对比度重核，状态永不单靠颜色 |
| 响应式 | 外壳媒体查询 + 内容容器查询分工；策略优先级：伸缩→折行→截断→重排→隐藏 | 内容随槽变而非随窗变，折叠侧栏瞬间不错位 |
| 无障碍 | 跳链/landmark/aria 全套、焦点陷阱恢复、44px 触控、reduced-motion 一刀切、200–400% 缩放回流 | 对标 CF Project A11Y；诚实边界：没测读屏就标没测 |
