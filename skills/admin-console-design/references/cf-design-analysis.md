# 三工程设计贡献与取舍

这是素材导读，具体行为、参数和缺口以[三工程对照](builds-comparison.md)及领域reference为准，不重复维护强制数值。归档源码/文档见[素材入口](../assets/sources/README.md)。

逐项查设计和交互时用[功能目录](feature-catalog.md)：它记录视觉安排、触发与状态转换、源码入口及实现边界。本页解释贡献与偏好，目录帮助复用时避免丢掉细节。

| 工程 | 保留的贡献 | 使用时的取舍 |
|---|---|---|
| fable | 外壳区域与视觉节奏、搜索/返回/分组/底部控制、DNS完整列表和共享编辑、命令面板、长表单/设置 | 默认整体来源；已修复主图标横移、鼠标离开藏焦点、Esc回焦与分组节点/按住点击问题；仍非完整六态模型，分组按钮与原生链接需按业务取舍 |
| sonnet | 显式pinned/hover/kbFocus/forced/suppressed/drawer模型、精确列宽、滚动提示、本地Undo、Legacy正反对照、设计舞台 | 补机制时保留基底视觉；演示dock/场景面板不搬进生产界面 |
| gpt | 文档分级与诚实验收边界、Playwright案例、完整预检导入、模拟失败恢复、真实容器回流 | 学验收与导入契约；双导航和不同断点不是其他工程必须照搬的结构 |

## 哪些机制值得复用

- **外壳**：资源上下文与导航分组让用户知道位置；槽/视觉分离使peek不推挤main。临时展开、固定偏好和抽屉各自有作用，不能混一个expanded变量。
- **列表**：搜索到编辑的扫描路径明确，长数据与行操作分离；粘性操作的实色背景和滚动提示能避免内容透出。列显隐、列宽、分页和配额解决不同问题，按需组合。
- **表单**：label/hint/error稳定分段，错误可恢复且有焦点定位；草稿/离开保护与保存反馈减少丢输入。Field布局不代替业务规则，也不意味着所有设置即时保存。
- **反馈**：普通成功不阻断，危险结果有确认或可用恢复；Undo快照是本地机制，服务端事务/恢复另行实现。不可逆动作只加假Undo更糟。
- **视觉**：统一密度、间距、图标与语义色形成完整风格。深色采用独立映射，但必须测实际色对；品牌点缀比例不是强制百分比。
- **响应式**：外壳看视口，内容看容器；真实iframe宽度用于观察，transform用于演示缩放。手机卡片或局部表横滚依任务决定。

## 不采纳为通用要求

不强制React/Vite/hash/localStorage、不固定四页型、不所有功能求并集、不强制先删空、不把通用控件增删设为审批、不把整页定高一概错误、不所有列表一屏、不把普通Toast层级数字用于推断dialog top layer。

优先整体模板复用仍然保留：拿fable的外壳/列表做视觉基底，sonnet补列宽/恢复，gpt补导入/验证；补模块有明确边界和验证，不把不同设计语言逐个按钮混搭。
