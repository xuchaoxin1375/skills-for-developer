# 三工程对照与复用决策

来源为三份独立 Cloudflare-inspired 设计工程。默认 **fable 外壳、导航与页面框架**；**表格单元采用声明的混合基线**（CF 实况几何 + sonnet 列宽交互 + gpt/本地窄屏与增强），不默认复刻 fable 表格。按需补 sonnet 本地 Undo、gpt 导入/验证。偏好来自其完整页面组织与交互覆盖，不意味着每个细节都已正确或是官方标准。

源码在[assets/sources](../assets/sources/README.md)，产物在[builds](builds/README.md)。原文档、源码、运行结果不一致时核对具体版本，原文档不会自动升级为当前规范。文件哈希与归档信息见[manifest](../assets/sources/manifest.json)。

## 同栈候选：Vue 3 外壳移植（2026-11-23）

三份 React 工程之外另有一份同栈候选：[Vue 3 外壳候选](../assets/sources/vue3-cloudflare-shell/README.md)。它用于 Vue 3 项目直接复用外壳，不是第四套主模板，也不是 Cloudflare 官方还原。

- 覆盖：顶栏、264/56 侧栏、分组、Rail hover/focus peek（槽位不变）、手动收起抑制、Esc 回主内容、1024 以下抽屉与焦点陷阱、容器查询收纳、reduced-motion。
- 不覆盖：命令面板、账号／主题／通知／资源切换器、DNS 表格与表单。
- 配色：示例使用宿主深青／中性令牌；迁移时替换为宿主令牌，不能拿本节品牌色做还原对照。
- 验证：1280／1440／768／390；1280 展开 264、Rail 56、peek 面板 264／槽位 56／主内容 left 56；768／390 抽屉可开可关；控制台 0 错误。记录见 [verification.json](../assets/sources/vue3-cloudflare-shell/verification.json)。

## Cloudflare 实况基线（2026-11-25）

对登录态 DNS records 页做了只读取样，尺寸与交互细节见 [Cloudflare 实况基线](cf-live-baseline.md)。三套模板都不是实况复刻：默认表格单元的视觉几何以实况为基准，交互按模板强项组合；页面外壳与其余区域仍按所选模板。

| 项 | Cloudflare 实况 | fable | sonnet | gpt | 采用 |
|---|---|---|---|---|---|
| 表头/默认–紧凑行高 | 40/40px，浅色白/深色 surface 表头，14px/500 | 约 40/41–33px，灰表头，font-medium | 约 44/45–29px，灰表头，600 | 未逐项测量 | 实况几何；选 fable 基底时沿用其灰表头与自身行高 |
| DOM 形态 | div 组合的 ARIA table | 原生 table | 原生 table | 原生 table | 原生默认；div 仅在独立滚动/虚拟化等有理由时使用，并补齐语义 |
| 垂直网格线 | 表体无；表头只有把手短竖线 | 表体无；表头无竖线，操作列左侧有边界线 | 表体无；表头无竖线 | 表体无；th/td 只有底边 | 表体默认无，首末列也不例外；表头只保留可调列右缘短竖线；末列操作列的左线单独取消 |
| 列宽 | 10px 热区，2×20px 线；无键盘、无持久化 | 键盘步长 16/64，Home 回默认；整高线 | 键盘步长 8/32，Home 最小/End 最大/Enter 默认；持久化 | 未实现 | 实况把手视觉 + sonnet 键位/边界/持久化 + Display 数值/±8 入口 |
| 排序 | 14px 独立图标，三态，`aria-sort` 在 th | 标签+图标，24px 高，三态 | 整段标签按钮，28px 高，三态 | 窄屏下拉排序 | 实况视觉，命中区不小于 24px |
| Display | 173px、33px 行、12px Reset，列显隐 + Reset；未观察到密度/列宽重置 | 列显隐/密度/编辑方式/重置列宽 | 304px，列显隐/密度/编辑方式/重置列宽 | 列显隐/紧凑 | 实况紧凑几何 + fable/sonnet 的密度/重置扩展 |
| 卡片 | 752–760px 视口/约720–728px 内容宽；摘要+展开编辑 | 视口 640 断点；堆叠字段 | 容器 ≤700（非视口）；堆叠字段 | 容器 ≤640 仍表格，加窄屏排序/全选 | 实况摘要卡 + 本地等价控件 |
| 选择/批量 | 表内联选择条；无全选于卡片 | 底部固定条 | 底部 sticky 批量条 | 表尾选择操作 | 底部浮动默认；内联仅在行位置不变时使用 |
| 勾选列粘左 | 否 | 否 | 是 | — | 保留 sonnet/本地增强 |

实况还暴露了若干不应照搬的缺口：列宽无键盘、无持久化、无拖动替代；卡片模式隐藏排序和 Display；勾选列不粘左；内联选择条会推动行；移动卡整卡按钮妨碍文本选择。目标实现应按 [表格](tables.md) 补齐，而不是为了“像 Cloudflare”删掉。

## 如何选择与维护

新建/改版先确定fable或用户指定整体基底，按需补模块；仅修单项则只读其来源与依赖。目标中验证采用的行为，不为每次工作全跑三个原型。

更新素材时一并归档源码、配置与产物，更新manifest；旧截图保留历史标签或重拍，不能仅覆盖index仍说所有图最新。维护的是可核对的当前解释，不是“本页只增不改”的过时规则。
